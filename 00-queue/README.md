# 수집 큐

저장할 글을 **파일 하나에 하나씩** 이 폴더에 넣어 두면 `/inbox-batch`가 한 번에 노트로 만든다.
폰 공유 시트나 `research-agent`에서 자동으로 넣을 때도 같은 형식을 쓴다.

## 파일 형식

- 파일명: `YYYYMMDD-HHMMSS.md` (수집 시각. 겹치지만 않으면 된다)
- 내용: 첫 줄에 URL, 한 줄 띄우고 본문

```markdown
https://www.threads.com/share/XXXXXXXX

(작성자 본문과 댓글을 그대로 붙여넣는다.
GitHub·블로그 링크가 본문에 있으면 그 링크만 있어도 원문에서 내용을 채운다.)
```

- Threads 글은 URL 한 줄만 넣어도 된다. 본문, 작성자가 이어 쓴 댓글, 첨부 이미지를 직접 읽는다. 영상은 첫 화면만 읽는다.
- URL만 있고 본문이 없어도 된다. 원문을 읽을 수 있으면 채우고, 못 읽으면 처리 결과에 "본문 필요"로 표시된다.
- 이 폴더의 파일은 frontmatter가 없어도 된다 (`README.md` 제외).

## 처리된 파일

노트로 저장된 큐 파일은 삭제된다. 원본은 git 기록에 남는다.
저장하지 못한 파일(본문 필요, 중복 확인 대기)은 그대로 남는다.
