# /card 스킬

노트 하나(또는 다이제스트의 묶음 하나)를 카드뉴스로 만든다.
결과는 카드 여러 장이 세로로 이어진 HTML 파일 하나이고, 카드 한 장은 1080×1350(4:5)이다.

---

## 입력

- `/card <노트 파일명>` — 그 노트로 만든다
- `/card` — 최근 저장한 노트 5개를 보여주고 고르게 한다
- 다이제스트 묶음을 고르면 묶음에 속한 노트들을 함께 읽고 한 벌로 만든다

---

## 실행 절차

### 1단계 — 노트 읽고 구성안 제시

노트를 읽고 카드 구성을 먼저 보여준다. **5~8장**으로 잡는다.

```
카드 구성안 (6장):

1. 표지 — (제목) / (한 줄 설명)
2. (소제목) — 목록
3. (소제목) — 문장
4. (소제목) — 목록
5. 핵심 — "(인용문)"
6. 정리 — (한 문장 결론) + 출처

이대로 만들까? (Y / 고칠 번호)
```

구성 원칙:

- **카드 한 장에 요점 하나.** 소제목만 읽어도 흐름이 이어져야 한다.
- 표지 제목은 노트 제목을 그대로 쓰지 않는다. 읽는 사람이 얻는 것을 짧게 쓴다 (2줄 이내).
- 목록은 한 장에 3~4개, 한 항목은 2줄 이내. 넘치면 카드를 나눈다.
- 문장형은 2~3문장.
- 인용 카드는 원문에 실제로 있는 문장만 쓴다. 없으면 인용 카드를 뺀다.
- 노트에 없는 내용을 지어내지 않는다. 숫자·이름은 노트에 있는 그대로 쓴다.
- 마지막 장에는 노트의 `source`를 적는다.

### 2단계 — HTML 작성

`99-meta/templates/card-template.html`을 읽고 그 구조와 스타일을 그대로 써서 새 파일을 만든다.

- 저장 경로: `99-meta/cards/<노트 파일명>.html`
- 템플릿의 `{{...}}` 자리를 채우고, 카드 블록(`<div class="frame">…</div>`)을 구성안 장수만큼 복제하거나 지운다
- 쪽 번호(`2 / N`)를 실제 장수로 맞춘다
- 스타일(`<style>`)과 맨 아래 스크립트는 고치지 않는다. 색을 바꿔 달라는 요청이 있을 때만 `:root`의 변수 값을 바꾼다
- 본문에 `<`, `>`, `&`가 있으면 HTML 엔티티로 바꾼다

### 3단계 — 확인

만든 파일을 다시 읽어 다음을 확인한다:

- `{{`가 하나도 남아 있지 않다
- 쪽 번호가 1부터 끝까지 맞다
- 목록 항목과 제목 길이가 구성 원칙 안에 있다 (길면 줄이거나 카드를 나눈다)

브라우저를 쓸 수 있는 환경이면 파일을 열어 글자가 카드 밖으로 넘치는지 본다.

### 4단계 — 보고

```
카드 완성: 99-meta/cards/<파일명>.html (N장)

브라우저에서 열면 카드가 세로로 이어져 보인다.
이미지로 쓰려면 카드별로 화면을 캡처한다.
```

원본 노트는 고치지 않는다.
