# /deep-dive 스킬

특정 노트의 주제를 대화를 통해 깊이 탐구하고, 결과를 원본 노트에 추가한다.

---

## 실행 절차

### 1단계 — 노트 읽기 & 주제 제안

대상 노트를 읽고 탐구할 만한 주제 2-4개를 추출해서 제안한다.

**주제 선정 기준:**
- 노트에서 핵심 개념이지만 충분히 설명되지 않은 부분
- 실제로 적용할 때 궁금해질 법한 것
- 다른 개념과 연결되는 흥미로운 접점

**출력 형식:**
```
어떤 주제를 탐구할까?

1. [주제 A] — 한 줄 설명
2. [주제 B] — 한 줄 설명
3. [주제 C] — 한 줄 설명
4. [주제 D] — 한 줄 설명

번호를 고르거나, 직접 주제를 입력해도 된다.
```

### 2단계 — 주제 설명 & 첫 질문

사용자가 고른 주제에 대해 핵심 내용을 2-3문단으로 설명한다.
설명 후 이해를 확인하거나 생각을 유도하는 질문 1개로 마무리한다.

**질문 유형 (돌아가며 사용):**
- 이해 확인: "이 개념에서 가장 낯선 부분이 어디야?"
- 적용: "네 상황에 적용하면 어떻게 될 것 같아?"
- 비교: "기존에 알던 [X]랑 어떻게 다른 것 같아?"
- 확장: "이걸 알면 다음에 뭘 더 알고 싶어져?"

### 3단계 — 3-4회 심화 대화

사용자의 답변을 바탕으로 대화를 이어간다.

**대화 원칙:**
- 답변마다 새로운 시각이나 관련 개념을 1개 추가한다
- 매 답변 끝에 질문 1개로 마무리한다
- 사용자가 모호하게 답하면 구체적인 예시를 요청한다
- 3-4회가 지나면 자연스럽게 정리 단계로 넘어간다:
  > "꽤 깊이 들어왔네. 이쯤에서 대화를 정리해볼까?"

### 4단계 — Deep Dive 섹션 추가

대화 내용을 요약해서 원본 노트 하단에 `## Deep Dive` 섹션으로 추가한다.

**섹션 형식:**
```markdown
## Deep Dive

> 탐구 주제: [주제명]
> 탐구 날짜: YYYY-MM-DD

### 핵심 인사이트

- (대화에서 나온 핵심 포인트 3-5개)

### 새롭게 알게 된 것

(대화 전과 후의 이해 변화를 2-3문장으로 요약)

### 남은 질문

- (아직 답을 못 찾은 것, 다음에 탐구할 것)
```

### 5단계 — 관련 노트 연결 제안

볼트 전체를 검색해서 이번 탐구 주제와 연관된 노트 2-5개를 찾는다.
관련 노트가 있으면 아래 형식으로 제안한다:

```
관련 노트:
- [[파일명|노트 제목]] — 연결 이유 한 줄
- [[파일명|노트 제목]] — 연결 이유 한 줄
```

연결을 원하는 노트가 있으면 원본 노트의 `## 관련 노트` 섹션에 추가한다.

### 6단계 — "내 생각" 기록

대화를 마치며 사용자의 생각을 묻는다:

```
마지막으로, 이 주제에 대한 네 생각이 궁금해.
오늘 탐구하면서 가장 인상적이었던 것, 또는 아직 잘 모르겠는 것은?
```

답변을 받으면 원본 노트에 `## 내 생각` 섹션으로 추가한다:

```markdown
## 내 생각

> YYYY-MM-DD

(사용자 답변을 그대로 또는 정제해서 기록)
```

---

## 전체 흐름 요약

```
노트 읽기
  → 탐구 주제 2-4개 제안
  → 사용자 선택
  → 설명 + 질문
  → 심화 대화 3-4회
  → Deep Dive 섹션 작성 & 원본 노트에 추가
  → 관련 노트 연결 제안
  → "내 생각" 기록
```

---

## 주의사항

- 한 번에 질문을 여러 개 하지 않는다. 질문은 항상 1개.
- 설명이 너무 길어지면 사용자가 지친다. 핵심만 담고 대화로 채운다.
- 사용자가 "됐어" 또는 "여기까지"라고 하면 즉시 정리 단계로 넘어간다.
- 대상 노트가 없으면 주제를 직접 입력받아 동일하게 진행한 뒤, 새 노트로 저장한다 (`/save` 절차 참고).
