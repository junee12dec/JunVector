# /scout 소스 목록

`/scout`가 읽는 소스와 카테고리. 직접 고쳐서 쓴다.

## 카테고리

카테고리 이름은 `99-meta/taxonomy.md`의 태그를 쓴다. 검색어는 Threads 검색에, 키워드는 논문 고르기에 쓴다.

| 카테고리 | Threads 검색어 | 논문 키워드 |
|----------|----------------|-------------|
| `ai/claude-code` | `claude code`, `클로드 코드` | coding agent, software engineering agent, code generation, agentic coding |
| `ai/agent` | `AI 에이전트`, `agent harness` | agent, multi-agent, tool use, agent memory, planning |
| `design/ui` | `웹 디자인 AI`, `UI 디자인` | GUI, user interface, web design, UI generation, design |
