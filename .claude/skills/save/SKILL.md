# /save 스킬

사용자가 제공한 콘텐츠(URL 또는 텍스트)를 노트로 변환해 `01-inbox/`에 저장한다.

---

## 실행 절차

### 1단계 — 입력 타입 감지

입력값을 확인해서 아래 네 가지 중 하나로 분류한다:

| 타입 | 판별 기준 | 처리 방법 |
|------|-----------|-----------|
| YouTube URL | `youtube.com` 또는 `youtu.be` 포함 | 자막(transcript) 추출 → 텍스트로 변환 |
| Threads URL | `threads.com` 또는 `threads.net` 포함 | `node .claude/skills/save/threads.js <URL>` 실행 → 본문과 작성자 댓글 추출, 첨부 이미지 내려받기 |
| 웹 URL | `http://` 또는 `https://`로 시작 | 본문 크롤링 → 핵심 텍스트 추출 |
| 일반 텍스트 | URL이 아닌 경우 | 그대로 사용 |

- YouTube 자막이 없을 경우: 사용자에게 알리고 URL과 제목만으로 노트를 생성한다.
- Threads 스크립트가 실패하면: 사용자에게 알리고 본문을 붙여넣어 달라고 한다.
- Threads 출력에 `[이미지] <경로>`가 있으면: 그 파일을 읽어 이미지에 담긴 내용을 노트에 반영한다.
- Threads 출력에 `[영상 첫 화면] <경로>`가 있으면: 첫 화면 한 장만 읽을 수 있다. 영상 내용은 읽지 못했다고 사용자에게 알린다.
- Threads 출력에 `[읽지 못한 첨부]`가 있으면: 그 첨부는 읽지 못했다고 괄호 안의 서버 이름과 함께 사용자에게 알린다. 추측으로 채우지 않는다.
- Threads 출력의 `[링크]`나 본문에 GitHub·블로그 등 원문 링크가 있으면: 원문도 읽어 내용을 보강한다.
- 웹 크롤링 실패 시: 사용자에게 알리고 URL만으로 노트를 생성한다.

### 2단계 — 한국어 번역

추출한 텍스트가 영어(또는 한국어가 아닌 언어)면 한국어로 번역한다.
이미 한국어면 그대로 사용한다.

### 2.5단계 — 중복 확인

노트를 만들기 전에 볼트 전체에서 같은 자료가 이미 있는지 찾는다:

- 입력 URL, 그리고 본문에 나온 원문 링크(GitHub 저장소, 블로그 글 등)를 각각 검색한다
- 제품·저장소 이름으로도 한 번 검색한다 (같은 자료를 다른 사람이 소개한 글일 수 있다)

이미 있으면 새 노트를 만들지 않고 사용자에게 알린 뒤 고르게 한다:

```
이미 저장된 자료입니다: [[기존-노트]] (YYYY-MM-DD)

A. 기존 노트에 새 내용만 추가
B. 별도 노트로 저장
C. 저장 안 함
```

### 3단계 — 노트 생성

아래 형식으로 노트를 작성한다:

```markdown
---
title: "노트 제목"
date: YYYY-MM-DD
tags: [카테고리/소주제]
description: "핵심 내용 요약 (한국어 1-2문장)"
source: "https://..."   # URL 입력일 때만 포함
---

# 노트 제목

(본문 내용)
```

**파일명 규칙**
- 영어 소문자 kebab-case
- 공백·언더스코어 금지
- 예: `my-first-note.md`, `claude-api-guide.md`

**tags 규칙**
- `99-meta/taxonomy.md`를 읽고 **허용 태그 표에 있는 태그만** 쓴다
- 노트당 1~4개. 고르는 순서와 헷갈리는 경우는 taxonomy 문서를 따른다
- 맞는 태그가 없어도 새로 만들지 않는다. 필요하면 사용자에게 taxonomy에 추가할지 묻는다

**description 규칙**
- 한국어 1-2문장
- 이 노트가 왜 유용한지 핵심을 담는다

### 4단계 — 01-inbox에 저장

- 저장 경로: `01-inbox/<파일명>.md`
- 저장 후 `01-inbox/MOC.md`의 "노트 목록" 섹션에 링크를 추가한다:
  ```markdown
  - [[<파일명>|노트 제목]] — 날짜
  ```

### 5단계 — 관련 노트 연결 제안

볼트 전체를 검색해서 내용·태그·키워드가 겹치는 노트를 2-5개 찾는다.
관련 노트가 있으면 아래 형식으로 사용자에게 제안한다:

```
관련 노트:
- [[파일명|노트 제목]] — 연결 이유 한 줄
- [[파일명|노트 제목]] — 연결 이유 한 줄
```

관련 노트가 없으면 이 단계를 건너뛴다.

### 6단계 — 다음 행동 제안

저장 완료 후 아래 옵션을 제안한다:

```
저장 완료: [[<파일명>]]

다음으로 무엇을 할까?
A. 딥다이브 — 이 주제를 더 깊이 탐구하는 노트 작성 (/deep-dive)
B. 폴더 정리 — 적절한 PARA 폴더로 이동 (/organize)
C. 삭제 — 이 노트가 필요 없으면 삭제
```
