# /save 스킬

사용자가 제공한 콘텐츠(URL 또는 텍스트)를 노트로 변환해 `01-inbox/`에 저장한다.

---

## 실행 절차

### 1단계 — 입력 타입 감지

입력값을 확인해서 아래 세 가지 중 하나로 분류한다:

| 타입 | 판별 기준 | 처리 방법 |
|------|-----------|-----------|
| YouTube URL | `youtube.com` 또는 `youtu.be` 포함 | 자막(transcript) 추출 → 텍스트로 변환 |
| 웹 URL | `http://` 또는 `https://`로 시작 | 본문 크롤링 → 핵심 텍스트 추출 |
| 일반 텍스트 | URL이 아닌 경우 | 그대로 사용 |

- YouTube 자막이 없을 경우: 사용자에게 알리고 URL과 제목만으로 노트를 생성한다.
- 웹 크롤링 실패 시: 사용자에게 알리고 URL만으로 노트를 생성한다.

### 2단계 — 한국어 번역

추출한 텍스트가 영어(또는 한국어가 아닌 언어)면 한국어로 번역한다.
이미 한국어면 그대로 사용한다.

### 3단계 — 노트 생성

아래 형식으로 노트를 작성한다:

```markdown
---
title: "노트 제목"
date: YYYY-MM-DD
tags: [카테고리/소주제]
description: "핵심 내용 요약 (한국어 1-2문장)"
source: "https://..."   # URL 입력일 때만 포함
---

# 노트 제목

(본문 내용)
```

**파일명 규칙**
- 영어 소문자 kebab-case
- 공백·언더스코어 금지
- 예: `my-first-note.md`, `claude-api-guide.md`

**tags 규칙**
- `카테고리/소주제` 형태
- 예: `ai/claude`, `productivity/automation`, `dev/python`
- 콘텐츠에서 주제를 추론해 자동 생성한다

**description 규칙**
- 한국어 1-2문장
- 이 노트가 왜 유용한지 핵심을 담는다

### 4단계 — 01-inbox에 저장

- 저장 경로: `01-inbox/<파일명>.md`
- 저장 후 `01-inbox/MOC.md`의 "노트 목록" 섹션에 링크를 추가한다:
  ```markdown
  - [[<파일명>|노트 제목]] — 날짜
  ```

### 5단계 — 관련 노트 연결 제안

볼트 전체를 검색해서 내용·태그·키워드가 겹치는 노트를 2-5개 찾는다.
관련 노트가 있으면 아래 형식으로 사용자에게 제안한다:

```
관련 노트:
- [[파일명|노트 제목]] — 연결 이유 한 줄
- [[파일명|노트 제목]] — 연결 이유 한 줄
```

관련 노트가 없으면 이 단계를 건너뛴다.

### 6단계 — 다음 행동 제안

저장 완료 후 아래 옵션을 제안한다:

```
저장 완료: [[<파일명>]]

다음으로 무엇을 할까?
A. 딥다이브 — 이 주제를 더 깊이 탐구하는 노트 작성 (/deep-dive)
B. 폴더 정리 — 적절한 PARA 폴더로 이동 (/organize)
C. 삭제 — 이 노트가 필요 없으면 삭제
```
