# Overture — AI 에이전트 오케스트레이션 전에 '무엇을 시킬지' 설계하는 도구

> 출처: Threads @and__yc
> "악기는 넘치는데 악보가 없다" — 전략기획자가 만든 AI 워크플로우 설계 도구.

## 문제 의식

AI에게 일을 시키는 건 쉬워졌다. 어려운 건 **무슨 일을 시킬지 정하는 것**이다.

- 에이전트에게 뭘 시켜야 할지 모를 때
- 여러 에이전트의 결과물이 서로 다른 이야기를 할 때
- 전체 워크플로우에서 어디까지 맡기고 어디서 직접 판단해야 할지를 설계할 때

코딩 에이전트, 리서치 에이전트, 요약 에이전트 — 기능별로 세우는 건 이미 많이 한다. 정작 막히는 건 도구가 아니라 **도구 이전의 판단**이다.

## Overture란

서곡(Overture)은 오케스트라에서 본 공연 전에 전체 음악의 주제를 미리 제시하고 방향을 잡아주는 곡.

**Overture 도구** = AI라는 본 공연이 시작되기 전에, 무엇을 왜 어떤 순서로 할지를 설계하는 4단계 프레임워크.
