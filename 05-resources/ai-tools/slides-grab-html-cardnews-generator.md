## 개요

단순 프롬프트가 아닌 **프롬프트 + 자동 검증 + 에디터**가 합쳐진 하나의 시스템.  
이미지 모델 대신 **HTML 디자인** 방식으로 카드뉴스 생성 → Claude Design 대용으로 활용 가능.

## 특징

| 항목 | 내용 |
|------|------|
| **생성 방식** | HTML 디자인 (이미지 모델도 선택 가능) |
| **시스템 구성** | 프롬프트 + 자동 검증 + 에디터 |
| **카드뉴스 지원** | 2026-04-19 추가 |
| **라이선스** | 오픈소스 (무료) |
