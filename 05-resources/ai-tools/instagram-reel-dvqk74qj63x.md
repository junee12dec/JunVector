# Kimi Claw — 핸드폰으로 AI 비서 자동화 시스템

## 핵심 내용

핸드폰으로 명령 한 번 보내면 AI가 24시간 자료조사하고 파일까지 만들어주는 시스템.
도구: **Kimi Claw** (@kimiai.official)

## 동작 방식

카톡 보내듯 명령만 하면 된다:

> "Gemini 3.1 조사해서 엑셀로 정리해줘"

AI가 자동으로 처리하는 것:
- 자료 조사
- 엑셀 정리
- 데이터 정리

## 명령어 프리셋

미리 세팅해두면 한마디로 여러 작업 자동화 가능:

> "아이디어 내놔" → 콘텐츠 아이디어 생성 + 주식 시장 뉴스 정리 + 데이터 시각화

## 기존 대비 장점

- 기존: 70만원짜리 맥미니 + 복잡한 설정 필요
- 현재: 핸드폰으로 명령만 보내면 AI 비서가 대신 처리
