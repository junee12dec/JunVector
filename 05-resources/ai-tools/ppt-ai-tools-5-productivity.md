# PPT 퀄리티 3배, 작업 시간 3배 단축해주는 AI 툴 5가지

## 한눈에 보기

| 도구 | 문제 상황 | 핵심 기능 | URL |
|------|-----------|-----------|-----|
| **Felo** | 자료 조사 + PPT 동시에 하기 귀찮을 때 | 검색 → PPT 자동 생성 | https://felo.ai/search |
| **Canva** | 디자인 감각 없을 때 | 수천 개 템플릿 + Magic Design | https://www.canva.com/templates |
| **Gamma** | 내용은 있는데 구성·디자인 모를 때 | 텍스트 → 완성형 슬라이드 | https://gamma.app |
| **Ideogram** | 슬라이드용 이미지 직접 만들고 싶을 때 | 텍스트 → AI 이미지 생성 | https://ideogram.ai |
| **MyMap AI** | 복잡한 데이터를 인포그래픽으로 | 텍스트 → 마인드맵·차트·인포그래픽 | https://www.mymap.ai |

---

## 1. Felo — 조사 + PPT 한 번에

- 키워드 검색 → PPT 자동 생성
- AI가 자료 조사부터 구성까지 한 번에 처리
- 무료 크레딧 제공, 마인드맵도 생성 가능

**사용 프롬프트 예시**
> "2026년 한국 스킨케어 신제품 마케팅 전략 PPT 중 '시장 분석' 슬라이드 하나만 만들어줘. 그래프 포함하고, 실제 회사 보고서처럼 신뢰감 있게, 디자인은 깔끔하고 세련되게."

---

## 2. Canva — 디자인 감각 없어도 OK

- 수천 개의 PPT 템플릿
- AI 자동 디자인 추천 (Magic Design)
- 드래그 & 드롭으로 누구나 편집 가능
- 기획자, 마케터, 취준생 모두 추천

---

## 3. Gamma — 내용만 있으면 구성은 자동

- 텍스트 입력 → 완성형 슬라이드 자동 생성
- 깔끔한 디자인 템플릿 자동 적용
- 무료 크레딧 제공
- 보고서, 제안서, 발표자료 모두 OK
- ⚠️ 프롬프트가 모호하면 무난한 교과서 PPT로 나올 수 있음 → 구체적으로 입력할 것

---

## 4. Ideogram — 슬라이드용 이미지 생성

- 텍스트 입력 → AI 이미지·로고 자동 생성
- 무료 플랜: 20 slow 크레딧 (단, 무료 플랜 이미지는 공개됨)
- 구글 계정으로 즉시 시작 가능

**사용 프롬프트 예시**
> "minimal skincare product on clean surface, soft natural sunlight, shadow play, neutral tones, aesthetic lifestyle mood, calm and fresh atmosphere, modern beauty brand style, high resolution"

---

## 5. MyMap AI — 복잡한 데이터를 인포그래픽으로

- 텍스트 입력 → 인포그래픽 자동 완성
- 마인드맵, 차트, 시각화 자료 생성
- 디자인 지식 없이 바로 사용 가능
- 기획서·보고서·제안서에 바로 삽입 가능
