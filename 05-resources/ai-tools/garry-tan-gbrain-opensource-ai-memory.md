# GBrain — YC CEO 개리 탄의 AI 메모리 시스템 오픈소스 공개

Y Combinator의 CEO **개리 탄(Garry Tan)**이 실제 업무에 쓰던 AI 기억 시스템 **GBrain**을 전격 오픈소스화했다.

## 핵심 내용

- **OpenClaw**나 **Hermes** 에이전트와 연동해 방대한 개인 데이터를 오차 없이 기억하고 꺼내 쓸 수 있는 강력한 인프라
- 그동안 많은 사람들이 에이전트 메모리 시스템을 바닥부터 만드느라 고전했는데, 프로덕션급의 튼튼한 뼈대가 무료로 제공됨
- 에이전트 메모리 생태계 구축 속도가 크게 앞당겨질 것으로 예상

## 개리 탄의 말

> "이제 VSCode를 직접 열지 않는 것처럼 파일도 직접 보지 않는다"

파일 탐색기가 아닌 AI와 대화하며 일하는 것이 당연해지는 시대의 도래를 시사한다.
