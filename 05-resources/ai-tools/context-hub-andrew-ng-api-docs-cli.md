# Context Hub — 앤드류 응의 AI 코딩 에이전트용 최신 API 문서 CLI 도구

## 개요

앤드류 응(Andrew Ng) 교수가 만든 오픈소스 CLI 도구.
AI 코딩 에이전트가 최신 API 문서를 검색하고 활용하도록 돕는다.

## 해결하는 문제 — Agent Drift

AI 코딩 에이전트를 쓰다 보면:
- 이미 폐기된 파라미터를 사용하거나
- 오래된 API를 호출하는 문제가 발생한다

원인: LLM의 학습 데이터가 고정되어 있기 때문.

Context Hub는 이 **Agent Drift** 문제를 정면으로 해결한다.
