# Oh My Prompt — AI 프롬프트 자동 기록 & 품질 스코어링 도구

## 문제 인식

하루에 프롬프트를 300개 이상 보내도, **어떤 프롬프트가 좋은 결과를 냈는지** 기억하거나 추적하기 어렵다.
프롬프트 히스토리가 쌓이지 않으면 매번 같은 시행착오를 반복하게 된다.

## Oh My Prompt란

- **자동 기록**: AI 코딩 에이전트에 보낸 모든 프롬프트를 자동으로 저장
- **품질 스코어링**: 각 프롬프트의 결과 품질을 자동으로 평가
- **셀프 호스팅**: 로컬 또는 자체 서버에서 운영 — 데이터 외부 전송 없음
- **오픈소스**: 무료 사용 가능, 커스터마이징 가능
