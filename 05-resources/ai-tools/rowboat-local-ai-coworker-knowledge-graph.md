# Rowboat — Gmail·회의 노트를 지식 그래프로 만드는 로컬 AI 코워커

**GitHub**: https://github.com/rowboatlabs/rowboat  
**⭐ 14.5k stars** / Apache-2.0  
**100% 오픈소스 / 100% 로컬 실행**

> "Open-source AI coworker that turns work into a knowledge graph and acts on it"

Claude Cowork의 **무료 로컬 대안**. 데이터는 기기 밖으로 나가지 않는다.

---

## 핵심 기능

| 기능 | 설명 |
|------|------|
| **지식 그래프** | Gmail·캘린더·회의 노트 → 개인 지식 그래프 자동 구축 |
| **음성 지원** | 음성 입력(Deepgram) + 음성 출력(ElevenLabs) |
| **임의 LLM** | 로컬 모델(Ollama·LM Studio) 또는 호스팅 API 모두 사용 |
| **MCP 확장** | MCP 도구로 기능 무한 확장 |
| **백그라운드 에이전트** | 웹 검색(Exa) 포함 자율 실행 |
| **Obsidian 호환** | 로컬 Markdown 볼트로 저장 — Obsidian에서 바로 열림 |

---

## 연동 서비스

**필수**:
- Google 계정 (Gmail, Google Calendar, Google Drive)

**선택 (기능 확장)**:
- **Deepgram** — 음성 입력
- **ElevenLabs** — 음성 출력
- **Exa** — 웹 검색

---

## 사용 사례

- 회의 준비 요약 자동 생성
- PDF 생성
- 음성 메모 → 구조화된 노트 변환
- 이메일·캘린더 기반 업무 컨텍스트 파악

---

## 설치

Mac / Windows / Linux 데스크톱 앱 다운로드 제공.  
모델을 바꿔도 데이터는 로컬 Markdown에 그대로 유지.
