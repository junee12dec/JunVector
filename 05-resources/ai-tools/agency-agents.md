# The Agency — 역할 기반 AI 에이전트 조직 템플릿 라이브러리

> 제네릭 프롬프트가 아닌, **뚜렷한 퍼소나·검증된 워크플로우·측정 가능한 성과물**을 갖춘 AI 에이전트 모음.
> ⭐ 53.3K GitHub 스타 · GitHub 트렌딩 1위 (2026-03-18 기준) · MIT 라이선스

## 한 줄 요약

**Claude Code를 원형으로 하는 역할 기반 에이전트 조직 템플릿 라이브러리.**
개발·마케팅·커뮤니티 빌더(레딧, X, 인스타 등)·디자인 UX 에이전트 역할 포함.

## 개요

- **150+ 에이전트**, 15+ 부서로 구성 (기존 61개 → 대폭 확장)
- 10,000줄 이상의 퍼소나·프로세스 문서
- 실제 업무 수개월 반복을 통해 검증된 워크플로우
- 8개 에이전트 병렬 실행 예시 포함

## 15개 부서 & 주요 에이전트

| 부서 | 주요 에이전트 |
|------|--------------|
| **Engineering** (22) | Frontend Developer, Backend Architect, AI Engineer, DevOps, Security Engineer 등 |
| **Design** (8) | UI Designer, UX Researcher, Brand Guardian, Accessibility Specialist 등 |
| **Marketing** (27) | Growth Hacker, Content Creator, SNS 전문가 (TikTok·Instagram·LinkedIn·Weibo·Douyin) 등 |
| **Sales** (8) | Outbound Strategist, Discovery Coach, Deal Strategist, Sales Engineer 등 |
| **Product / PM** | Sprint Prioritizer, Trend Researcher, Feedback Synthesizer, Senior PM 등 |
| **Testing** | Evidence Collector, Performance Benchmarker, Accessibility Auditor 등 |
| **Spatial Computing** | XR Interface Architect, visionOS Spatial Engineer 등 |
| **Specialized** | Agents Orchestrator, Blockchain Security Auditor, AI Data Remediation Engineer 등 |

## 멀티 에이전트 병렬 실행 예시 (스타트업 킬러 기능)

8개 에이전트를 동시에 돌려 아래를 한 번에 생성:

1. 시장 조사
2. 시스템 설계
3. 브랜드 전략
4. GTM(Go-to-Market) 전략
5. UX 설계
6. PM 계획
7. 커뮤니티 빌딩 전략
8. 보안 감사

→ **스타트업에서 팀 없이 에이전트 조직만으로 사업 전반을 커버 가능**

## 각 에이전트 구성 요소

- 강한 퍼소나와 커뮤니케이션 스타일
- 코드 예시 포함 도메인 특화 전문성
- 검증된 워크플로우 프로세스
- 명확한 성공 지표(KPI)
- 패턴 인식을 위한 학습 메모리

## 지원 툴 (설치 스크립트 제공)

- **Claude Code** (네이티브 지원)
- Cursor, Aider, Windsurf, Gemini CLI, OpenCode

## 활용 포인트

- Claude Code에서 역할(예: Security Engineer, UX Researcher)로 에이전트를 전환해 작업
- Agents Orchestrator로 여러 에이전트를 조율하는 멀티 에이전트 워크플로우 구성
- 중국 플랫폼(더우인, 빌리빌리, 위챗) 전문 에이전트도 포함 — 글로벌 마케팅에 유용
