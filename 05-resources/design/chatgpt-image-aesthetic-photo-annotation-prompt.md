# ChatGPT 이미지 감성 손그림 주석 프롬프트

> "중간 내용 수정해서 쓰시면 됩니다"

사진을 업로드하고 아래 프롬프트를 그대로 붙여넣으면 감성 이미지로 변환.

---

## 프롬프트 (복붙용)

```
업로드한 사진을 메인 기준 이미지로 사용해줘. 아이 모습을 보고, 사진 속 실제 요소에 맞는 감성적인 결과물을 만들어줘.

그리고 사진에 보이는 각 요소를 관찰한 뒤, 대상에 어울리는 손그림 주석을 추가해줘.

- 흰 펜으로 그린 듯한 손그림 선, 러프하고 약간 불균일한 느낌
- 인물 외곽선, 화살표, 시선 흐름 표현
- 한글 귀여운 손글씨로 짧은 메모처럼 작성, 혼잣말·감성적인 톤
- 아이는 날씨좋은날, 배경은 한강감성, 전체는 한마디 요약
- 김, 반짝임, 하트, 작은 이모티콘은 은은하게만 추가
- 여백을 살린 인스타그램 스토리풍, 잡지 메모풍의 자연스럽고 힘 뺀 분위기
- 결과물은 "업로드한 사진을 감성적으로 꾸민 버전"처럼 보여야 하며, 멘트는 네개정도.
```

## 프롬프트 — 사물·카페 버전 (복붙용)

```
업로드한 사진을 메인 기준 이미지로 사용해줘.
테이블 위에 놓인 커피, 음료, 디저트, 접시, 소품, 테이블 분위기와 구도를 바탕으로, 사진 속 실제 요소에 맞는 감성적인 결과물을 만들어줘. 인물은 추가하지 말고, 업로드한 사진에 보이는 음식과 음료의 종류, 배치, 분위기를 최대한 자연스럽게 반영해줘.

그리고 사진에 보이는 각 요소를 관찰한 뒤, 그 대상에 어울리는 손그림 주석을 추가해줘.

- 흰 펜으로 그린 듯한 손그림 선, 러프하고 약간 불균일한 느낌

- 한글 손글씨로 짧은 메모처럼 작성, 혼잣말·감성적인 톤
- 음료는 맛·온도·기분, 디저트는 식감·맛, 공간은 분위기, 전체는 한마디 요약
- 김, 반짝임, 하트, 작은 이모티콘은 은은하게만 추가
- 여백을 살린 인스타그램 스토리풍, 잡지 메모풍의 자연스럽고 힘 뺀 분위기
- 결과물은 "업로드한 사진을 감성적으로 꾸민 버전"처럼 보여야 하며, 사진과 어울리지 않는 요소는 억지로 추가하지 말 것
```

## 프롬프트 — 만능 범용 버전 (복붙용)

어떤 사진에도 적용 가능한 고급 버전. 피사체 종류에 따라 주석 내용을 자동으로 맞춤 적용.

```
업로드한 사진을 메인 기준 이미지로 사용해줘.
사진 속에 실제로 보이는 피사체, 배치, 분위기, 색감, 구도, 공간감을 바탕으로, 원본 사진의 매력을 살린 감성적인 꾸민 버전을 만들어줘.
중요한 것은 사진에 없는 요소를 억지로 추가하지 않고, 업로드한 사진에 실제로 보이는 대상과 장면을 최대한 자연스럽게 반영하는 것이다.

그리고 사진 속 각 요소를 관찰한 뒤, 그 대상에 어울리는 손그림 주석을 추가해줘.

## 표현 방식
- 사진 위에 손으로 덧그린 듯한 자연스러운 꾸밈
- 흰 펜으로 그린 듯한 러프한 손그림 선
- 선은 너무 두껍지 않게, 가늘지만 가독성 있게
- 약간 불균일하고 손맛이 느껴지는 드로잉
- 사물이나 피사체의 외곽선, 화살표, 점선, 동그라미 등으로 시선 흐름을 표현
- 전체적으로 힘을 뺀 자연스러운 감성
- 인스타그램 스토리풍 + 잡지 메모풍의 여백 있는 레이아웃

## 텍스트 구성
- 사진 전체 분위기를 담는 대표 타이틀을 반드시 넣어줘
- 대표 타이틀은 화면에서 가장 먼저 보이도록 배치
- 대표 타이틀은 다른 주석보다 더 크게
- 손으로 쓴 크레용 글씨 느낌으로 표현
- 크레용 손글씨 특유의 가볍고 따뜻한 질감이 느껴지게
- 가늘지만 또렷하고 읽기 쉽게
- 대표 타이틀 아래 또는 주변에는 짧은 손글씨 메모를 자연스럽게 배치

## 글씨 스타일
- 한글 크레용 손글씨 느낌
- 가늘지만 가독성 있게
- 너무 정갈한 폰트 느낌보다 손맛이 느껴지게
- 짧은 메모처럼 자연스럽게 배치
- 문장은 감성적이고 사적인 혼잣말 톤
- 과하게 설명적이지 않고, 짧고 여운 있게

## 주석 내용 가이드
사진 속 대상의 종류에 따라 어울리는 메모를 붙여줘.
- 인물 사진: 표정, 분위기, 감정, 순간의 느낌
- 동물 사진: 행동, 표정, 귀여운 포인트, 성격이 느껴지는 요소
- 풍경 사진: 날씨, 공기감, 빛, 계절감, 장면의 정서
- 정물/사물 사진: 질감, 색감, 형태, 작은 디테일
- 음식/음료 사진: 맛, 온도, 식감, 향, 기분
- 공간 사진: 무드, 조용함, 따뜻함, 편안함, 현장감
- 전체 장면: 사진 전체를 아우르는 짧은 한마디 요약

## 장식 요소
- 김, 반짝임, 하트, 작은 별, 작은 이모티콘 등은 필요할 때만 은은하게 추가
- 과하지 않게, 사진의 분위기를 해치지 않는 수준으로만 사용
- 사진과 어울리지 않는 장식은 넣지 말 것

## 중요한 규칙
- 업로드한 사진의 구도와 실제 요소를 최대한 존중할 것
- 사진에 없는 피사체나 소품을 임의로 추가하지 말 것
- 원본 사진이 가진 분위기를 해치지 말 것
- 결과물은 "업로드한 사진을 감성적으로 꾸민 버전"처럼 보여야 함
- 억지스럽거나 과한 디자인보다, 자연스럽고 센스 있게 꾸민 느낌이 중요함
- 대표 타이틀은 항상 포함하되, 사진 분위기와 자연스럽게 어울리게 넣을 것
```

## 커스터마이징 포인트

| 요소 | 원본 | 변경 예시 |
|------|------|-----------|
| 피사체 | 아이 | 강아지, 친구, 풍경 등 |
| 배경 감성 | 한강감성 | 제주감성, 카페감성 등 |
| 날씨 | 날씨좋은날 | 비오는날, 저녁노을 등 |
| 스타일 | 인스타 스토리풍 | 폴라로이드풍, 필름감성 등 |

## 스타일 키워드

- 흰 펜 손그림 선 (러프, 불균일)
- 한글 손글씨 + 혼잣말 톤
- 여백 활용 + 힘 뺀 분위기
- 은은한 이모티콘 (김, 반짝임, 하트)
