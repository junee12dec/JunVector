# 리소그라프 인쇄풍 미니멀 일러스트 프롬프트

주제와 색상만 바꾸면 어디에나 적용되는 감성 일러스트 GPT 프롬프트.

---

## 프롬프트

```
[인물/상황/장면/배경/공간/계절], 리소그라프 인쇄풍 미니멀 일러스트. 판화 같은 또렷한 스타일, 굵은 윤곽선, 자연스러운 데포르메. 파스텔톤 색감, 빈티지 인쇄 질감, 살짝 어긋난 잉크 레이어, 거친 종이 텍스처. 화면을 꽉 채우지 않고 여백을 넓게 남긴 차분한 포스터 구성. 소품과 배경은 최소화. 색 테마: [색상 2~3개].
```

---

## 입력 변수

| 변수 | 예시 |
|------|------|
| **주제** | 창가에 앉은 여자 / 비 오는 골목 / 여름 바다 / 겨울 카페 |
| **색 테마** | 크림 + 테라코타 / 민트 + 네이비 / 라벤더 + 베이지 |

---

## 스타일 키워드 요약

- **인쇄 기법**: 리소그라프 / 판화 / 살짝 어긋난 잉크 레이어
- **질감**: 빈티지 인쇄 질감 / 거친 종이 텍스처
- **선**: 굵은 윤곽선 / 또렷한 스타일
- **형태**: 자연스러운 데포르메 (캐릭터 변형)
- **구성**: 넓은 여백 / 소품·배경 최소화 / 차분한 포스터 레이아웃
- **색감**: 파스텔톤 2~3색 제한
