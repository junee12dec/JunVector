- 복잡한 디테일 묘사 / 포토리얼 스타일
- Rainbow palette / 과한 gradient / neon / 너무 깨끗한 AI 벡터 느낌
- 너무 안전한 레이아웃 / 고정 문구 반복

## 프롬프트 전문

### ABSTRACT FOOD TRANSFORMATION

AI는 업로드한 음식 이미지를 분석하여 반드시:
- 핵심 silhouette 유지 / 음식의 형태적 특징 유지
- 대표 색감 유지 / 음식 identity 유지

하면서도 음식을:
- 단순화된 유기적 shape / flat graphic object
- abstract cutout form / oversized color mass / bold minimal illustration

느낌으로 재해석하라.

음식 질감: 벡터 느낌 / 종이 cutout 느낌 / 실크스크린 포스터 느낌 / matte graphic texture / hand-cut abstract form

### COLOR SYSTEM

2~4개 메인 컬러만. 가능한 조합:
- vivid blue + tomato red + cream white
- warm gray + red + black
- off-white + cobalt blue + green
- ivory + scarlet + dark green
- butter yellow + forest green + charcoal black
- dusty pink + espresso brown + warm beige
- sage green + burgundy + soft ivory
- terracotta orange + faded navy + sand cream
- smoky teal + burnt orange + ivory
- deep wine + blush beige + soft black

### TYPOGRAPHY SYSTEM

- oversized typography / bold sans-serif headline / elegant serif contrast
- cropped typography / modular type composition / edge-aligned / brutal minimal layout
- 텍스트는 잘리거나 화면 밖으로 나가도 됨 — 그래픽 composition의 일부처럼

### POSTER COMPOSITION

- giant negative space / intentional imbalance / floating abstract objects
- modular visual rhythm / asymmetrical hierarchy / clean breathing zones
- AI 자동 판단: 어떤 오브젝트 크게 확대 / 어디 과감히 비울지 / 긴장감 위치

### GRAPHIC OBJECT ARRANGEMENT

- 랜덤 배치 금지 — 의도적 리듬감 필요
- 크기 대비 강하게 (extreme oversized + tiny accent)
- 일부는 화면 밖 overflow
- typography와 충돌하는 배치 가능

### TEXTURE SYSTEM

- matte print texture / premium paper grain / subtle ink bleed
- soft silkscreen imperfection / slightly tactile poster finish
- 미세한 종이 질감 + 약한 grain + 잉크 번짐 느낌

### AUTO TYPOGRAPHY CONTENT

음식 이미지를 분석해 자동 생성:
- 음식 이름 기반 headline / 재료 기반 키워드
- 맛·감정 표현 / abstract branding text / gallery exhibition 문구

예시 무드: SWEET / JUICY / FRESH / CRISP / BLOOM / RAW / SOFT / BITTER / SLOW / FORM / SHAPE / TASTE / OBJECT
