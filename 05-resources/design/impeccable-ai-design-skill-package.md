# Impeccable — AI 에이전트에 디자인 판단 기준을 주입하는 스킬 패키지

AI로 UI를 만들면 기능은 동작하지만 간격, 폰트 크기, 색상 조합이 어설픈 경우가 많다. 감각적 판단을 AI가 일관되게 내리기 어렵기 때문이다. **Impeccable**은 이 문제를 "프롬프트 반복" 대신 "스킬에 기준 내장"으로 해결한다.

GitHub: https://github.com/pbakaus/impeccable

---

## 핵심 개념

프롬프트에 "예쁘게 만들어줘"를 반복하는 대신, 스킬 자체에 디자인 규칙을 정의해두는 방식이다. Anthropic의 `frontend-design` 스킬을 기반으로 확장한 오픈소스라 직접 수정도 가능하다.

---

## 7개 디자인 영역

| 영역 | 내용 |
|------|------|
| 타이포그래피 | 폰트 시스템, 글자 짝짓기, 모듈식 스케일 |
| 색상과 명도대비 | OKLCH, 접근성, 다크모드 |
| 공간 설계 | 간격 시스템, 그리드, 시각 계층 |
| 모션 설계 | 이징 곡선, 스태거링 |
| 상호작용 설계 | 폼, 포커스 상태, 로딩 패턴 |
| 반응형 설계 | 모바일 우선, 유동적 레이아웃 |
| UX 라이팅 | 버튼 레이블, 에러 메시지 |

---

## 사용 방법

20개의 슬래시 명령어로 제어한다:

- `/audit` — 디자인 문제 점검
- `/normalize` — 디자인 시스템 정렬
- `/polish` — 최종 시각 검수

**지원 도구**: Cursor, Claude Code, OpenCode 등

---

## 왜 유용한가

AI 코딩 도구를 쓰면서 결과물의 시각적 완성도가 아쉬웠다면, 매번 프롬프트로 설명하는 대신 이 스킬을 한 번 설치해두면 된다. 디자인 어휘와 판단 기준을 AI에게 미리 알려주는 구조다.
