# Shadcn CLI v4 — AI 친화적 디자인 시스템 프리셋

> Shadcn이 cli v4를 공개했습니다. 디자인 시스템 테마 중 하나를 골라 적용하면 AI 티 안 나는 웹사이트 디자인이 가능합니다.
> 1. 웹에서 프리셋 코드 복사 → 2. 터미널에 붙여넣기 → 3. "Shadcn 컴포넌트들로 디자인해줘"
> — @jinsolisme1 (Threads)

## 핵심 변경사항 (2026-03)

### 🎨 디자인 프리셋 (`--preset`)

전체 디자인 시스템 설정(색상, 테마, 아이콘, 폰트, 반경)을 **단 하나의 코드**로 패키징.

- `shadcn/create`에서 프리셋 미리보기 → 코드 복사
- 터미널에서 `init --preset <코드>` 실행 → 전체 설정 자동 적용
- 팀과 공유하거나 레지스트리에 게시 가능
- **AI 프롬프트에 넣으면 에이전트가 디자인 시스템을 이해하고 시작** (Claude, Codex, v0, Replit 호환)

**프리셋 교체도 간단:**
```bash
shadcn init --preset <새-프리셋-코드>
```
컴포넌트 재구성까지 CLI가 자동 처리.

### 🤖 shadcn/skills — AI 에이전트 지원

코딩 에이전트에게 **프로젝트별 컨텍스트**를 제공하는 에이전트 인식 스킬 시스템.
- AI 환각·실수 감소
- 에이전트가 컴포넌트·레지스트리를 이해하고 디자인 시스템에 맞는 코드 생성

### 🛠️ 새 CLI 플래그

| 플래그 | 기능 |
|--------|------|
| `--dry-run` | 변경 시뮬레이션 (실제 적용 없음) |
| `--diff` | 레지스트리 업데이트 확인 |
| `--view` | 레지스트리가 추가할 페이로드 미리 보기 |

### 🏗️ 새로 만든 shadcn/create

- 컴포넌트에 색상·폰트·반경이 어떻게 적용되는지 **빌드 전에 라이브 미리보기**

### 📦 프레임워크·템플릿 확장

`shadcn init --template`으로 풀 프로젝트 스캐폴딩 지원:
- Next.js, Vite, Laravel, React Router, Astro, TanStack Start
- 다크모드: Next.js, Vite 포함
- `--base radix` 또는 `--base radix-ui`로 기반 UI 라이브러리 선택

### 🗂️ registry:base — 디자인 시스템 단일 페이로드

레지스트리가 전체 디자인 시스템(컴포넌트, 의존성, CSS 변수, 폰트, 설정)을 **한 번에** 배포 가능.

### 🔤 폰트 퍼스트클래스 지원

폰트를 컴포넌트 설치와 동일한 방식으로 설치·설정.

### 📚 CLI에서 직접 문서 접근

```bash
shadcn docs [컴포넌트명]
```
레지스트리에서 공식 문서 링크·코드 스니펫 즉시 가져오기 (사람+에이전트 모두 활용 가능).

## 바이브코딩 활용법 (빠른 시작)

```bash
# 1. shadcn/create에서 프리셋 코드 선택
# 2. 프로젝트에 적용
npx shadcn@latest init --preset <프리셋-코드>

# 3. AI에게 지시
# "Shadcn 컴포넌트들로 랜딩페이지 디자인해줘"
```

15분 안에 AI 티 안 나는 웹사이트 완성.

## 왜 중요한가

- **바이브코딩 + 디자인 시스템**: AI가 컴포넌트 스펙을 알고 코드를 생성 → 일관성 유지
- **에이전트 에라 최적화**: shadcn/skills가 AI 환각을 줄이고 디자인 시스템을 프로덕션 UI로 빠르게 연결
- **팀 단위 공유**: 프리셋 한 코드로 신규 팀원도 동일한 디자인 환경 즉시 구성
