# 도시 여행 가이드 인포그래픽 포스터 프롬프트 템플릿

소년잡지풍 애니메이션 + 프리미엄 여행 포스터 하이브리드 스타일.  
도시명·분위기·색감을 입력하면 저장하고 공유하고 싶은 실용적 여행 가이드 이미지가 완성된다.

---

## 프롬프트 전문

아래 입력값을 바탕으로, [CITY NAME] 전용의 매우 디테일하고 몰입감 있는 인포그래픽 스타일 여행 가이드를 제작한다.  
결과물은 프리미엄 디자이너 여행 포스터와 소년잡지풍 애니메이션 일러스트가 결합된 느낌이어야 한다.

---

### 입력값

```
도시명: [CITY NAME]
국가/지역: [COUNTRY / REGION] (선택)
전체 분위기 키워드: [예: 활기찬 / 낭만적인 / 역사적인 / 야경이 아름다운 / 로컬 감성 / 미식 중심]
색감 포인트: [예: 블루 + 오렌지 / 민트 + 레드 / 파스텔 + 선명한 원색]
강조할 여행 성격: [예: 첫 여행자용 / 미식 여행 / 감성 산책 / 로컬 탐방 / 혼행 / 커플 여행]
```

---

### 핵심 목표

- 전체 텍스트는 모두 한국어로 작성한다
- 단순한 소개 포스터가 아니라, 사람들이 저장하고 공유하고 실제로 참고하고 싶어지는 실용적인 여행 가이드처럼 만든다
- generic한 표현은 피하고, 반드시 [CITY NAME]의 개성이 강하게 느껴지도록 구성한다
- 실제 여행에 도움이 되는 구체적이고 선별된 정보만 사용한다
- 비주얼은 화려하지만, 정보 구조는 명확하고 읽기 쉬워야 한다

---

### 필수 콘텐츠 구성 (9가지)

**1. 메인 타이틀**
- 도시명이 한눈에 들어오게 크고 강렬하게 배치
- 예: "[CITY NAME]", "[CITY NAME] 여행 가이드", "[CITY NAME] 완전정복"

**2. 서브타이틀**
- 짧고 인상적으로 — 도시의 분위기와 매력을 압축해 표현
- 예: "골목, 풍경, 미식, 밤까지 한 번에 즐기는 도시"

**3. 꼭 가봐야 할 곳**
- 추상적 표현 금지 — 실제 장소명을 구체적으로 표기
- 대표 명소 + 분위기 있는 장소를 균형 있게 포함
- 각 장소마다 짧고 센스 있는 설명 추가

**4. 꼭 먹어야 할 음식**
- 현지 음식의 실제 이름을 표기
- "길거리 음식"처럼 뭉뚱그리지 말고 구체적으로 소개
- 음식별 특징, 추천 상황, 맛의 인상 등을 짧게 정리

**5. 꼭 해봐야 할 것**
- 관광객용 체험 + 현지인이 즐기는 활동 + 이 도시만의 독특한 경험을 적절히 섞는다
- 단순 방문이 아니라 "무엇을 하면 좋은지"가 보이게 작성

**6. 현지 분위기 / 로컬 바이브**
- 문화, 사람들의 행동, 거리 분위기, 리듬감, 에티켓, 동네별 성격 등을 짧고 센스 있게 정리
- 실제로 가면 느껴질 법한 인상을 담는다

**7. 빠른 실전 팁**
- 교통 / 예산 감각 / 실수하기 쉬운 점 / 여행자가 바로 써먹을 수 있는 요령
- 짧고 실용적으로 작성

**8. 여행자 공감 코믹 장면 3~5개**
- 이 도시에서 여행자들이 실제로 겪을 법한 짧고 재밌는 상황
- 문화적으로도 그 도시답고, 공감되며, 너무 과장되지 않게 표현
- 예: 길 찾기, 주문 실수, 환승, 인기 메뉴 구매, 사진 스팟 탐색, 줄 서기, 현지식 예절 적응

**9. 미니 맵**
- 도시의 주요 구역 또는 핵심 동선을 작게 정리
- 대표 지역명, 랜드마크, 강/공원/중심지 등을 보기 쉽게 표시
- 정보 전달용이면서도 귀엽고 직관적이어야 한다

---

### 문체 가이드

- 똑똑하고 약간 위트 있는 톤
- 과장된 여행 홍보 문구, 뻔한 카피, 텅 빈 감탄사는 피한다
- 설명은 짧지만 밀도 있게
- 친절하지만 교과서처럼 딱딱하지 않게
- 도시의 결을 살리는 구체적인 표현을 사용한다

---

### 비주얼 스타일 가이드

- 세로형 4:5 비율
- 소년잡지풍 애니메이션 스타일
- 깔끔하고 산뜻한 컬러 / 선명하고 정돈된 라인아트 / 생기 있고 밝은 분위기
- 지나치게 유아틱하지 않고, 잡지 편집물처럼 세련되게 구성
- 인포그래픽 + 만화 하이브리드 스타일
- 캐릭터들이 랜드마크, 음식, 거리, 교통수단과 자연스럽게 상호작용하는 장면 포함
- 아이콘, 화살표, 말풍선, 강조 박스, 체크포인트형 팁 박스, 작은 지도 등을 적극 활용
- 복잡해 보여도 실제로는 매우 잘 정돈된 편집 레이아웃

---

### 타이포그래피 / 편집 가이드

- 모든 텍스트는 한국어
- 메인 타이틀 / 중제목 / 소제목 / 본문이 명확하게 구분되도록 크기와 스타일 차이
- 가독성이 매우 좋아야 한다
- 표지처럼 인상적이면서도, 잡지 특집 페이지처럼 정보가 잘 읽혀야 한다

---

### 필수 디자인 요소

랜드마크 일러스트 / 대표 음식 일러스트 / 도시 아이콘 / 미니 맵 / 말풍선 / 작은 코믹 컷 / 정보 박스 / 체크포인트형 팁 박스 / 컬러 포인트를 활용한 섹션 구분

---

### 사용 예시

```
도시명: 서울
국가/지역: 대한민국
전체 분위기 키워드: 궁궐, 골목, 한강, 카페, 야경, 로컬 감성
색감 포인트: 블루 + 레드 + 크림 화이트
강조할 여행 성격: 첫 여행자용 + 감성 산책 + 미식 탐방
```
