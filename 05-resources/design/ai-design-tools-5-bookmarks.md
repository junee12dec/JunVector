# AI·디자인 유용 웹사이트 5개 북마크

> @adventure__dori 큐레이션 — AI·디자인 꿀팁 모음

## 도구 목록

| 사이트 | URL | 설명 |
|--------|-----|------|
| **Dither Garden** | https://dithergarden.com | 이미지 디더링 전문 도구. Floyd-Steinberg, Atkinson, Blue-Noise 알고리즘으로 이미지를 수학적으로 변환 |
| **The App Fuel** | https://theappfuel.com | 200개 이상의 앱 UX·그로스·디자인 레퍼런스. 600장 이상의 스크린샷 라이브러리, 앱 빌더 원스톱 인스피레이션 |
| **Super Color Palette** | https://supercolorpalette.com | 무료 컬러 팔레트 생성기. 색조·채도·밝기 조절로 고유 배색 생성, 무제한 저장·내보내기 가능 |
| **Mosaic Media** | https://mosaicmedia.ai | 소셜 미디어 그래픽을 아트월처럼 만드는 플랫폼 |
| **Media Cheat Sheet** | https://mediacheatsheet.com | SNS·디지털 광고의 이미지·영상 사이즈 스펙 모음. 최신 규격을 한눈에 확인 |

## 용도별 선택 가이드

- **이미지 효과·픽셀아트 스타일** → Dither Garden
- **앱 UI/UX 레퍼런스·벤치마킹** → The App Fuel
- **컬러 팔레트 생성** → Super Color Palette
- **소셜 미디어 그래픽 제작** → Mosaic Media
- **광고·SNS 이미지 사이즈 확인** → Media Cheat Sheet
