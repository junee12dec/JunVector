# 인터랙티브 UI 트렌드 레퍼런스 모음

## 플랫폼 목록

| 플랫폼 | URL | 특징 |
|--------|-----|------|
| **Awwwards** | http://awwwards.com | 글로벌 웹 디자인 트렌드와 높은 완성도 기준 확인 가능 |
| **CSS Design Awards (CSSDA)** | http://cssdesignawards.com | 디자인·기술·UX를 종합 평가하는 수상 플랫폼 |
| **CSS Winner** | http://csswinner.com | 매일 선정된 사이트와 점수 공개로 트렌드 파악 용이 |
| **Webby Awards** | http://webbyawards.com | 브랜드 중심의 상업적 웹 트렌드 참고 가능 |
| **Supahero** | https://www.supahero.io/ | 웹 디자인 사례를 모아 영감 얻기 좋은 플랫폼 |

## 용도별 선택 가이드

- **최신 트렌드 + 완성도 기준** → Awwwards
- **기술적 구현 + UX 종합 평가** → CSSDA
- **빠른 일간 트렌드 파악** → CSS Winner
- **상업·브랜드 사이트 레퍼런스** → Webby Awards
- **영감 수집·케이스 스터디** → Supahero
