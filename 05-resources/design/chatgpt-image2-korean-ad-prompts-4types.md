# ChatGPT Image2 실전 프롬프트 4종

**도구**: ChatGPT Image2 (GPT-4o Image Generation)  
**특이사항**: 아주 작은 텍스트는 해상도 때문에 깨짐 — 텍스트 크기 여유 있게 설정 권장

---

## 프롬프트 1 — 한국어 광고 이미지 4종 비교

```
한국어로 된 가상의 광고 이미지를 다양한 장르에서 4종류를 나란히 이미지로 생성하고. 
잘 조사해서 프로 디자이너가 만든 최신 트렌드 디자인으로 만들어. ar=4:5
```

**활용**: 광고 레퍼런스 탐색, 디자인 방향 비교

---

## 프롬프트 2 — 매거진 스타일 서비스 광고

```
아이 돌봄 매칭서비스 광고를 고품질 매거진 스타일로 만들어줘. 
타겟 고객인 젊은 부부층에 소구할 수있도록 이미지와 내용을 잘 구성해줘. 
어필할 수있는 자세한 정보를 많이 넣어줘
```

**활용**: 특정 서비스의 타겟 맞춤 광고 이미지 초안

---

## 프롬프트 3 — 건축 계획서 자료 이미지

```
여의도에 새롭게 구상중인 880m의 「jhAi 타워」의 건설 계획서 자료를 이미지로 만들어
```

**활용**: 가상 건축 프로젝트 기획서, 프레젠테이션 자료

---

## 프롬프트 4 — 기술 해설 인포그래픽

```
Claude Code의 매우 상세한 해설 자료를 만들어
```

**활용**: 기술 개념 시각화, 발표 자료, 교육 콘텐츠

---

## 패턴 정리

| 유형 | 핵심 키워드 |
|------|------------|
| 광고 비교 | "다양한 장르 N종 나란히", "최신 트렌드", `ar=4:5` |
| 매거진 광고 | "고품질 매거진 스타일", "타겟 고객에 소구", "자세한 정보 많이" |
| 계획서/문서 | "계획서 자료를 이미지로" |
| 해설 자료 | "매우 상세한 해설 자료" |
