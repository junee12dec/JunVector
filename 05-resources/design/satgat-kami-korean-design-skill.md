# satgat — KAMI 기반 한국형 문서 디자인 스킬

**GitHub**: https://github.com/unclejobs-ai/satgat  
**⭐ 5 stars** (신규 오픈소스)  
**기반**: tw93의 KAMI 디자인 스킬

> "한지 위에 먹글씨. AI가 옮겨 적는 한국형 문서 디자인 시스템"

---

## 탄생 배경

> "좋은 도구도 언어가 맞지 않으면 멀어집니다. 기능이 좋아도, 우리 언어가 아닌 README 첫 문장부터 멈추게 됩니다."

KAMI를 대체하려는 게 아니라, **한국어 사용자도 쉽게 시작할 수 있도록** 만든 한국어 입구.

---

## 주요 기능

- **13종 문서 자동 생성**: 이력서, 명함, 청첩장, IR 덱, 뉴스레터 등
- **AI 에이전트 연동**: Claude, GPT, Gemini 통합
- **자연어 한 문장으로 문서 생성**

---

## 한국형 디자인 체계

| 요소 | 특징 |
|------|------|
| 캔버스 | 백자지(白磁紙) 질감 |
| 색상 | 단청(丹靑) 색상 체계 |
| 타이포 | 명조 타이포그래피 |
| 포맷 | A4, 엽서, 16:9 슬라이드 |

---

## 설치

```bash
npx satgat init my-satgat
cd my-satgat && npm install
```

---

## satgat이 말하는 한국식 미

> "화려한 장식이 아닙니다. 바로 읽히는 제목. 막히지 않는 설치 흐름. 처음 쓰는 사람이 덜 헤매는 설명. 작게 정리된 친절함입니다."
