# tufte.ai — ASCII 차트 생성 도구

**사이트**: https://tufte.ai  
**제작자**: @arvindang

> "Shipped a silly thing, ASCII Charts"

---

## 개요

Edward Tufte의 데이터 시각화 원칙에서 이름을 딴 ASCII 차트 생성 도구.

**Tufte 철학의 핵심**: 데이터-잉크 비율 최대화, 차트정크(chartjunk) 제거, 명확성 우선.

ASCII 형식의 장점:
- 의존성 없이 어디서나 렌더링
- 터미널·마크다운·코드 주석에 바로 삽입
- AI 코드 생성에서도 활용 가능 (ASCII 구조가 코드 생성 품질 향상에 도움)
