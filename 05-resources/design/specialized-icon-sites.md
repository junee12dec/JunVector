# 도메인 특화 아이콘 사이트 7선

범용 아이콘이 아니라 도메인에 딱 맞춘 전문 아이콘 모음. 상황별로 바로 꺼내 쓸 수 있다.

## 의료 / 헬스케어

**[Health Icons](https://healthicons.org)**
- 의료·헬스케어 전용 870개+
- 혈액형·장기·의약품·진단 도구 등 세부 카테고리
- Filled·Outline 두 스타일, SVG·PNG 무료 / 출처 표기 불필요

## 날씨

**[Weather Icons](https://erikflowers.github.io/weather-icons)**
- 날씨 전용 222개, 달의 위상 28종 포함
- 풍력·해양 기상 경보 등 기상 특화
- CSS로 색상·크기 자유롭게 커스터마이징 가능

## 게임 / 판타지

**[Game Icons](https://game-icons.net)**
- 게임·판타지·RPG 전용 4,000개+
- 매주 새 아이콘 추가, 카테고리별 직관적 탐색
- SVG·PNG 무료 / 컬러·배경 커스터마이징 지원

## 지도 / 위치

**[Maki Icons (Mapbox)](https://labs.mapbox.com/maki-icons)**
- 지도·위치 핀 전용, POI·교통·장소 카테고리 특화
- 지도 기반 서비스·인포그래픽에 바로 사용 가능
- SVG 무료 / 오픈소스 라이선스

## 이모지 기반

**[OpenMoji](https://openmoji.org)**
- 이모지 기반 4,000개+, 컬러·아웃라인 두 버전
- 사람·음식·동물·사물·기술 등 폭넓은 카테고리
- SVG·PNG 무료 / CC BY-SA (출처 표기 필요)

## UI / 대시보드

**[Phosphor Icons](https://phosphoricons.com)**
- Regular·Bold·Fill·Duotone 등 6가지 스타일
- 1,200개+, SVG·PNG·React·Vue 등 다양한 형태
- 노션·대시보드 UI에 어울리는 클린한 감성

## 브랜드 / 기술 스택 로고

**[Simple Icons](https://simpleicons.org)**
- 브랜드·기술 스택 로고 전용 3,000개+
- Figma·Notion 등 툴 로고도 포함
- HEX 컬러 정보 제공으로 브랜드 색상 적용 편리
