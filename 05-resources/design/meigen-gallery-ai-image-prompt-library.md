# MeiGen Gallery — AI 이미지·영상 프롬프트 Pinterest

**웹사이트**: https://meigenai.io  
**무료 / 가입 불필요**

> "AI 이미지 프롬프트계의 Pinterest"

GPT Image, Midjourney, Seedance, Veo, Nano Banana 등에서 실제로 잘 나온 바이럴 프롬프트 1,000개 이상을 모아둔 무료 갤러리. 프롬프트 복사 → 원클릭 생성까지 한 화면에서 가능.

---

## 지원 모델

GPT Image / Midjourney / Seedance 2.0 / Veo 3.1 / Nano Banana 2

신규 모델 지속 추가 중.

---

## 주요 기능

| 기능 | 설명 |
|------|------|
| **프롬프트 갤러리** | 검증된 바이럴 프롬프트 1,000개+ 브라우징 |
| **원클릭 생성** | 프롬프트 복사 → 즉시 이미지·영상 생성 |
| **멀티 모델** | GPT Image·Midjourney·Seedance·Veo·Nano Banana |
| **무료·가입 불필요** | 바로 사용 가능 |

## 활용 팁

- **프롬프트 공부**: 잘 된 프롬프트가 어떻게 구성됐는지 분석
- **콘셉트 레퍼런스**: 이미지·영상 방향성 잡을 때 시각적 레퍼런스
- **즉시 생성**: 마음에 드는 프롬프트 클릭 → 바로 내 이미지로
