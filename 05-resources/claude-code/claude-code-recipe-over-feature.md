# Claude Code 가이드가 GitHub 1위 — 진짜 가치는 '복붙 템플릿'

Claude Code 커뮤니티 가이드가 GitHub 트렌딩 1위.
별 1.4만 개, 포크 1,600개 넘게 찍혔다.

공식 문서가 아니라 누군가 만든 **복붙 템플릿 모음**이 이 정도 반응을 얻었다는 게 핵심이다.

기본 개념부터 멀티 에이전트 구성까지, 바로 붙여넣고 돌릴 수 있는 예제 중심.

> AI 코딩 도구는 이제 '기능'이 아니라 '레시피'로 경쟁하는 단계에 들어갔다.
