# Claude Code 실전 가이드 — 에이전트·스킬·워크플로우·디버깅 총정리

**GitHub**: https://github.com/shanraisshan/claude-code-best-practice

`practice makes claude perfect` — Claude Code 중심으로 에이전트, 스킬, 워크플로우, 디버깅 팁까지 모아둔 실전형 가이드.

## 핵심 구조

```
Plan Mode → Command → Agent → Skill
```

단계별로 흐름을 잡고 올라가는 방식이 핵심.

## 좋은 점

- **Plan mode부터 시작하는 흐름** — 바로 실행하지 않고 설계 먼저
- **command → agent → skill 구조 정리** — Claude Code의 3계층 구조를 명확히 구분
- **실제로 많이 쓰는 팁** 촘촘하게 수록
- 웹에서 바로 접근 가능하고, 레퍼런스 링크 풍부

## 활용 방법

기능 소개보다 "어떻게 써야 진짜 잘 써먹는지"에 집중된 자료이므로,
자신의 워크플로우와 비교해서 부족한 부분 찾기에 적합.
