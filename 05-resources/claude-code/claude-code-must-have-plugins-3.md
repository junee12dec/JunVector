# Claude Code 필수 플러그인 3가지

## 1. Superpowers (`obra/superpowers`)

클로드가 단순히 코드를 짜는 것을 넘어 **계획 → 구현 → 코드 리뷰**까지 자동으로 돌아간다.

- TDD, 디버깅, 브레인스토밍 스킬이 내장
- 바이브코딩 시 삽질이 눈에 띄게 줄어듦

## 2. Oh My Claude Code (`oh-my-claudecode`)

여러 AI 에이전트가 동시에 움직이는 **멀티 에이전트 오케스트레이션**.

- 기획하는 에이전트
- 코드 짜는 에이전트
- 리뷰하는 에이전트

혼자 다 하던 것을 팀처럼 돌려주는 구조.

## 3. BKIT

한국 개발자가 만든 플러그인. **PDCA(계획-실행-점검-개선)** 방법론 기반.

- 기획부터 배포까지 전 과정 자동 문서화
- 바이브코딩을 체계적인 개발 프로세스로 전환
