# 디자이너를 위한 Claude Skills 6가지 — AI 티 없는 UI 만드는 법

Claude로 만든 UI, 아직도 AI 티 나지 않나요?
Claude Code, Codex 등 어디든 적용 가능한 디자인 특화 Skills 6가지 정리.

---

## 스킬 목록

| # | 스킬명 | 설명 |
|---|--------|------|
| ① | **ui-ux-pro-max** | 67 UI 스타일, 161 컬러 팔레트, 57 폰트 페어링, 99 UX 가이드라인 담긴 디자인 인텔리전스 DB. 프로젝트 타입에 맞는 디자인 시스템 자동 생성. (⭐ 59.3k) |
| ② | **frontend-design** | AI slop 탈피. 타이포, 컬러, 레이아웃, 모션까지 깊은 가이드로 템플릿 느낌 없는 결과물 생성. |
| ③ | **polish** | 기능 완성 후 최종 점검용. 시각 정렬, 마이크로 애니메이션, 엣지 케이스까지 세심하게 잡아주는 마무리 스킬. |
| ④ | **sleek-design-mobile-apps** | 말로 설명하면 프로덕션용 모바일 화면 바로 렌더링. 빠른 UI 프로토타이핑에 최적. |
| ⑤ | **tailwind-design-system** | Tailwind v4용 CSS-first 디자인 시스템 프레임워크. 토큰, OKLCH 컬러, CVA 변형, 다크 모드 포함. |
| ⑥ | **canvas-design** | Claude를 비주얼 아티스트로 변신. 미적 운동 생성, 박물관 품질 PDF/PNG 출력. |

---

## 설치 명령어

```bash
# ① ui-ux-pro-max
npm install -g uipro-cli
uipro init --ai claude

# ② frontend-design
npx skills add pbakaus/impeccable@frontend-design

# ③ polish
npx skills add pbakaus/impeccable@polish

# ④ sleek-design-mobile-apps
npx skills add sleekdotdesign/agent-skills@sleek-design-mobile-apps

# ⑤ tailwind-design-system
npx skills add wshobson/agents@tailwind-design-system

# ⑥ canvas-design
npx skills add anthropics/skills@canvas-design
```

한 줄이면 설치 끝! 결과물 퀄리티 차이를 바로 체감할 수 있다.
