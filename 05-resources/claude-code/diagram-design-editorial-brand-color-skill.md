# diagram-design — 웹사이트 컬러 추출해 에디토리얼 퀄리티 다이어그램 생성하는 스킬

**GitHub**: https://github.com/cathrynlavery/diagram-design

---

## 핵심 기능

텍스트 설명 → 13가지 유형의 다이어그램 → HTML + SVG 출력

기존 AI 다이어그램과의 차이: 투박한 기본 박스 형태 ✕  
→ 테크 블로그·프레젠테이션에 바로 써도 손색없는 **에디토리얼 디자인** ✓

## 지원 다이어그램 유형 (13가지)

- 시스템 아키텍처
- 흐름도 (Flowchart)
- 시퀀스 다이어그램
- 타임라인
- 플로우차트
- 그 외 총 13가지

## 킬러 기능: 웹사이트 컬러 자동 추출

웹사이트나 블로그 URL만 알려주면:
1. AI가 직접 사이트 방문
2. 배경색·폰트·강조 색상 추출
3. 디자인 가이드 자동 세팅
4. 브랜드 컬러와 일치하는 다이어그램 생성

→ 별도 디자인 작업 없이 **내 브랜드에 맞는 전문가 수준** 구조도·플로우차트·타임라인 완성
