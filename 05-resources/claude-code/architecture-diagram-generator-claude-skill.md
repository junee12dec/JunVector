# architecture-diagram-generator — 코드베이스 아키텍처 다이어그램 자동 생성 스킬

**GitHub**: https://github.com/Cocoon-AI/architecture-diagram-generator

---

## 핵심 기능

코드베이스를 분석해 아키텍처 다이어그램을 자동으로 생성하는 Claude Code 스킬.

아래 이미지처럼 컴포넌트 간 관계, 데이터 흐름, 레이어 구조를 시각화해 준다.

## 사용법

**Claude Code 스킬로 사용:**
- GitHub에서 스킬 설치 후 `/architecture-diagram` 실행

**Hermes에서 사용:**
- Hermes에 스킬을 추가하면 `/architecture-diagram` 프롬프트로 바로 실행 가능
