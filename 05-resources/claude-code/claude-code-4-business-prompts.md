# Claude Code로 비즈니스를 실행하는 4가지 프롬프트

> 대부분의 사람들은 Claude Code를 챗봇처럼 쓴다. 심지어 더 나쁜 경우, Claude 웹만 계속 쓴다.
> 전임 직원을 고용해놓고 구글 검색만 시키는 것과 같다.

## 4가지 프롬프트 시스템

### 1. 메모리 시스템
- 세션을 넘어 모든 **결정, 선호, 사람**을 기억
- Claude Code가 컨텍스트를 유지하며 장기 협업 가능

### 2. 의사결정 로그
- 내가 내린 결정을 기록하고, **30일 후 검토 플래그** 자동 설정
- 과거 결정의 품질을 회고적으로 평가 가능

### 3. 이메일 인박스 관리자
- 수신 메일 **분류, 라벨링, 답장 초안** 자동 작성
- 내 말투(tone)에 맞게 답장 문체 매칭

### 4. 자율 작업 처리 시스템
- **자는 동안** 할 일 목록을 자율적으로 처리
- 태스크 목록을 주면 Claude Code가 순서대로 실행

## 핵심 메시지

이 4가지는 가상의 아이디어가 아니라 실제로 사용 중인 시스템이다.
Claude Code를 단순 코딩 보조가 아닌 **비즈니스 운영 에이전트**로 활용하는 방향을 제시한다.
