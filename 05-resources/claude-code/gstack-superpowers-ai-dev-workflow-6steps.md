# G-Stack + SuperPowers 조합 AI 개발 워크플로우

> "AI 개발의 핵심은 도구가 아니라 도구가 제대로 움직일 수 있는 구조다."

Claude Code·Codex에서 G-Stack Skill + SuperPowers Skill 조합으로 구성한 단계별 워크플로우.

---

## 6단계 워크플로우

```
요구사항 정리 → 아이디어 보강 → 실행 계획 작성 → 리뷰 검증 → 작업 공간 분리 → 서브 에이전트 개발
```

| 단계 | 내용 | 담당 스킬 |
|------|------|-----------|
| 1. 요구사항 정리 | 뭘 만들지 명확히 정의 | G-Stack (`/office-hours`) |
| 2. 아이디어 보강 | Socratic 질문으로 요구사항 구체화 | SuperPowers (brainstorming) |
| 3. 실행 계획 작성 | 단계별 구현 계획 수립 | SuperPowers (writing-plans) |
| 4. 리뷰 검증 | 제품 가치·가정 검토 | G-Stack (`/plan-ceo-review`) |
| 5. 작업 공간 분리 | 작업 단위로 컨텍스트 분리 | — |
| 6. 서브 에이전트 개발 | 병렬 subagent 실행 | SuperPowers (executing-plans) |

---

## 핵심 인사이트

- 도구보다 구조가 먼저 — AI에게 코딩을 맡기기 전 워크플로우 설계가 선행
- G-Stack은 "무엇을 만들지" 결정, SuperPowers는 "어떻게 만들지" 실행
- 이 흐름을 갖추면 AI가 단순 코드 생성을 넘어 계획·분리·검증까지 수행
