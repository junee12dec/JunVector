# Harness — Claude Code 에이전트 팀 자동 구성 플러그인

> "좋은 하네스를 만들어라. 나머지는 에이전트가 알아서 한다."

- **만든 사람**: 황민호 (@revfactory1) — 카카오 AI Native 전략 팀 리더
- **링크**: [GitHub](https://github.com/revfactory/harness) · [템플릿 100개](https://github.com/revfactory/harness-100) · [홈페이지](https://revfactory.github.io/harness/)
- **라이선스**: 오픈소스, 무료

## 한 줄 요약

Claude Code에서 "하네스 구성해줘"라고 치면 프로젝트를 분석해 에이전트 역할·스킬·팀 구조·조율 규칙을 자동 생성한다.

## 왜 필요한가

Claude Code를 쓰다 보면 한 에이전트에 분석·코드 작성·테스트를 모두 맡기게 된다. 복잡한 작업일수록 역할 분담이 더 나은 결과를 만든다. 하지만 에이전트 정의 파일, 스킬 파일, 팀 조율 규칙을 직접 짜는 건 번거롭다. Harness가 이 과정을 자동화한다.

## 6단계 자동화 과정

1. 프로젝트 분석
2. 팀 구조 설계
3. 에이전트 정의 생성
4. 스킬 생성
5. 팀 조율 연결
6. 검증 및 테스트

## 6가지 팀 구성 패턴

| 패턴 | 설명 |
|------|------|
| **파이프라인** | 분석 → 구현 → 테스트 순차 흐름 |
| **팬아웃/팬인** | 작업을 여러 에이전트에 동시 분배 후 결과 수집 |
| **전문가 풀** | 작업 유형에 따라 최적 에이전트 자동 배정 |
| **생성-검증** | 한 에이전트가 만들고 다른 에이전트가 검토 |
| **감독자** | 감독 에이전트가 작업 흐름 관리 |
| **계층적 위임** | 상위 에이전트 → 하위 에이전트 단계적 위임 |

프로젝트를 분석해 가장 적합한 패턴을 추천한다.

## 논문 실험 결과

15가지 소프트웨어 엔지니어링 과제 실험:

| 조건 | 평균 품질 점수 |
|------|--------------|
| 하네스 없음 | 49.5 |
| 하네스 사용 | 79.3 |

- **60% 향상**, 15개 과제 전부에서 하네스 우세 (승률 100%)
- 결과 편차 32% 감소 (품질 안정화)

### 난이도별 개선 폭

| 난이도 | 개선 폭 |
|--------|---------|
| 쉬운 작업 | +23.8점 |
| 중급 작업 | +29.6점 |
| 고급 작업 | +36.2점 |

→ **작업이 어려울수록 효과가 더 커진다.**

## harness-100 — 100개 팀 템플릿

별도 리포([harness-100](https://github.com/revfactory/harness-100))에 10개 도메인 × 100개 실전 팀 하네스.

- 한국어 + 영어 = 200개 패키지, 마크다운 1,808개
- 각 하네스: 전문 에이전트 4~5명 + 오케스트레이터 스킬 + 도메인 특화 스킬

**도메인 예시**: 유튜브 콘텐츠 제작, 풀스택 웹개발, 딥 리서치, 웹툰 제작, 비즈니스 전략, 법률, 헬스케어

## "하네스"란?

원래 뜻은 마구(馬具). AI에서는 **모델 주변에 씌우는 운영 구조**를 의미한다.

> "에이전트는 절대 주변 코드가 아니다. 에이전트는 항상 모델이다. 하네스는 모델한테 손과 눈과 작업 공간을 주는 거다."
> — shareAI-lab 분석
