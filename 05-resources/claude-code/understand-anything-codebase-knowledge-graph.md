# Understand Anything — Codebase를 Knowledge Graph로 변환하는 Claude Code 플러그인

## 개요

Claude Code용 플러그인으로, 코드베이스 전체를 Knowledge Graph로 변환해 구조를 시각적으로 파악하게 해준다.

- GitHub: https://github.com/Lum1104/Understand-Anything

## 사용법

설치 후 슬래시 커맨드로 실행:

- `/understand` — 코드베이스 분석 및 Knowledge Graph 생성
- `/understand-dashboard` — 결과 대시보드 확인
