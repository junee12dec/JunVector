# Superpowers — AI 코딩 필수 스킬, LLM 추론을 시스템 액션으로 자동화

LLM의 추론 능력을 실제 시스템의 액션으로 치환하는 스킬. AI 코딩 도구에서 가장 먼저 설치해야 할 필수 스킬로 꼽힌다.

## 핵심 개념

완전히 새로운 기술이 아니라, **숙련된 개발자가 AI를 이용해 개발하던 프로세스를 자동화·규격화**한 것이다. 특정 플랫폼을 넘어 AI 개발 도구의 표준으로 자리잡고 있다.

## 자동화되는 것들

- 코드 분석 및 plan 작성
- 테스트 자동 진행
- 오류 자동 수정

## 효과

- 개발자 개입 대폭 감소
- 코드 수정·구현 시 오류 감소
- 코드 품질 향상
