# YC Office Hours Claude 스킬 — 냉철한 비즈니스 분석 도구

> GitHub: https://github.com/crealwork/yc-office-hours

## 개요

Y Combinator 대표이사 Garry Tan의 gstack의 office-hour 스킬을 기반으로,
유튜브에 존재하는 **모든 YC Office Hours 영상을 분석**해 제작한 Claude 스킬이다.

## 활용 범위

스타트업 전용이 아니라 다양한 상황에 유연하게 적용 가능:

- 비즈니스 플랜 검토
- 마케팅 캠페인 전략
- 제품 의사결정
- 사업 아이디어 검증

## 특징

- **냉철한 분석**: YC 방식으로 현실적이고 날카로운 피드백
- **조언 + 과제**: 분석에 그치지 않고 다음 액션 아이템까지 제시
- **가볍고 유연**: 어떤 비즈니스 맥락에도 적용 가능

## 설치 방법

1. GitHub URL을 Claude Code에 붙여넣고 "설치해달라"고 요청
2. 설치 후 `/yc-office-hours` 입력 → 세션 시작
