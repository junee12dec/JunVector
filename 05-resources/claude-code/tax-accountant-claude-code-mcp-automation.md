# 세무사의 Claude Code + MCP 전사 자동화 — 60곳 장부를 혼자 돌리는 법

> 원문: [@choigpt_ai on Threads](https://www.threads.com/@choigpt_ai/post/DWARHyOkk5V) / 원문 출처: https://x.com/kandmybike

## 사무소 구조

Claude Code가 사령탑. 5개 외부 서비스를 MCP로 연결한다:

- **freee** (일본 클라우드 회계)
- **Gmail**
- **Google Calendar**
- **Notion**
- **Slack**

핵심 가치: "사람이 매번 지시하지 않아도 돌아간다"

---

## 매일 밤 9시 — 60곳 자동 분개

스케줄 태스크가 자동 실행되어 freee 미처리 거래 명세를 60곳 전부 처리한다.

### 계정 과목 판정 2단계

**1단계: 키워드 사전 매칭**

14개 계정 과목 카테고리에 각각 100개 이상의 키워드 등록.

| 키워드 | 계정 과목 |
|--------|----------|
| Suica, JR, 택시 | 교통비 |
| Amazon, 요도바시 | 소모품비 |
| AWS, ChatGPT | 통신비 |
| 음식점 1만엔 이하 | 회의비 |
| 음식점 1만엔 초과 | 접대비 |
| 송금 + 사무소명 | 지급보수 |
| 송금 + 카타카나 인명 | 외주비 (발생일 전월 말로 자동 변경) |

적요란을 전각→반각, 대문자→소문자로 정규화. 일본어·영어·카타카나 전부 대응.
직원 급여 송금은 freee 인사노무 API로 직원명을 가져와 자동 제외.

**2단계: Claude API 폴백**

키워드로 판정 안 되는 것만 Claude API로 처리.
- 신뢰도 high/medium → 자동 등록
- 신뢰도 low → 스킵 후 본인 확인

등록 전 날짜·금액·적요 앞 40자로 중복 체크. 신규 거래처는 API로 마스터 자동 생성.

**처리 시간**: 60곳 전부 직렬 처리로 30~50분 (이전 브라우저 자동화 방식: 5시간)

## 자동화하면 안 되는 것을 자동으로 거른다

7가지 제외 규칙 (계정 과목 판정 전에 필터링):

1. 내용 불명 체크카드 (가맹점명 없는 것)
2. 차입금 상환
3. 사회보험료·세금
4. 급여 지급
5. 투자·자산운용
6. ATM 출금·잔액 조정
7. 공과금

"뭘 자동화하고 뭘 사람이 볼지 선을 명확하게 긋고 있기 때문에 안전하게 60곳을 돌릴 수 있다."

## 보안 — 60곳 데이터 완전 분리

- 처리는 `company_id` 단위로 완전 분리
- 거래 상세(적요·금액)는 로그 파일에만 기록, 화면에는 건수·상태만 표시
- 로그 파일도 사업소별로 독립

---

## 사례: 청구서 130건 → 15분

고객사 의뢰: 1년치 청구서(130건, 약 2.8억원) freee 입력.
Claude Code에 "PDF 읽어서 freee 임포트용 엑셀로 변환해줘" → Python 스크립트 자동 생성 → 15분 완료.
(수작업: 꼬박 하루 / 스크립트는 재사용 가능)

---

## MCP 활용 패턴

| MCP | 활용 |
|-----|------|
| freee MCP | 사업소별 거래 즉시 확인, "지난달 통신비 합계" 즉답 |
| Gmail MCP | 월차 자료 미제출 고객사에 리마인드 메일 일괄 초안 |
| Google Calendar MCP | 다음 주 미팅 목록화, 준비 태스크 자동 생성 |
| Notion MCP | 회의록 → 다음 아젠다 자동 생성, 고객사별 TODO |
| Slack MCP | TODO 파악 및 봇 연동 |

## 핵심 인사이트

> "엔지니어가 AI를 쓰면 '기술적으로 대단한 것'이 만들어진다. 세무사가 AI를 쓰면 '실무적으로 올바른 것'이 만들어진다."

- 직원 0명 → 인건비 절감 → 고문료를 낮춰 고객에게 환원
- AI는 "대단하다"가 아니라 **"빠르다"**가 맞는 표현
