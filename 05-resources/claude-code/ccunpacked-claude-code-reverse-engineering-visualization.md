# CCUnpacked — 클로드 코드 소스 리버스 엔지니어링 인터랙티브 시각화

## 개요

[ccunpacked.dev](https://ccunpacked.dev/)는 Claude Code의 소스 코드를 리버스 엔지니어링하여 인터랙티브하게 시각화한 프로젝트다. Claude Code의 내부 구조, 에이전트 흐름, 동작 원리를 직접 탐색할 수 있는 시각적 인터페이스를 제공한다.

## 주요 특징

- **리버스 엔지니어링**: Claude Code의 번들/빌드된 소스를 분석해 내부 구조를 복원
- **인터랙티브 시각화**: 코드 구조와 에이전트 흐름을 클릭·탐색 가능한 형태로 제공
- **동작 원리 파악**: 블랙박스였던 Claude Code의 내부 로직을 가시적으로 확인

## 활용 가치

- Claude Code를 더 깊이 이해하고 싶은 개발자에게 유용
- 커스텀 훅, 스킬, 에이전트 설계 시 내부 흐름 참고 가능
- 리버스 엔지니어링 + 시각화 기법 자체도 참고할 만한 프로젝트
