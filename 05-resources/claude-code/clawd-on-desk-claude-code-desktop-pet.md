# Clawd on Desk — Claude Code 작업 상태를 12가지 애니메이션으로 보여주는 데스크톱 펫

**GitHub**: https://github.com/rullerzhou-afk/clawd-on-desk  
무료 · 오픈소스

---

## 뭐하는 도구인가

Claude Code 작업 상태를 데스크톱 위에 귀여운 캐릭터 애니메이션으로 실시간 표시해주는 펫.

## 12가지 애니메이션 상태

| 상황 | 애니메이션 |
|------|-----------|
| 생각 중 | 골똘히 고민하는 모습 |
| 코드 작성 중 | 따닥따닥 타이핑 |
| 대기 중 (할 일 없음) | 하품하다 드러눕기 |
| 더블클릭 시 | 깜짝 놀라는 반응 |
| 그 외 | 총 12가지 상태 |

## 특징

- Claude Code와 연동되어 실제 작업 상태를 반영
- 무료로 사용 가능
- GitHub에서 바로 설치 가능

## 설치법 (Claude Code로 바로 설치)

1. Claude Code에 GitHub 링크 붙여넣고 `"설치해줘"` 입력
2. 설치 완료 후 `"실행해줘"` 입력
