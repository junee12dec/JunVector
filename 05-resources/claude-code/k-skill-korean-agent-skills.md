# 케이-스킬 — 한국인을 위한 AI 에이전트 스킬 모음

## 개요

"한국인을 위한 스킬 모음집"으로, AI 에이전트(Claude Code, Codex, OpenCode 등)가 한국 생활의 번거로운 작업을 자동화하도록 지원한다. 추가 API 레이어 없이 프록시 서버로 바로 활용 가능하다.

- GitHub Stars: **1.3k**
- 라이선스: MIT
- 언어: JavaScript 77.2%, Python 22.0%
- 절대 영어 README 없음 — 한국 거주민 전용

## 주요 스킬 목록 (17개)

### 교통 예약
- SRT / KTX 열차 조회 및 예약
- 서울 지하철 도착정보 조회

### 통신
- 카카오톡 Mac CLI로 메시지 관리

### 생활정보
- 미세먼지 조회
- 우편번호 검색
- 배송 추적
- 로또 당첨 확인

### 쇼핑
- 쿠팡 상품 검색 — 쇼핑도 에이전트에게 시켜버리기
- 다이소 상품 검색
- 중고차 가격 및 재고 조회 (현재: SK렌터카 타고BUY)

### 문서·법률
- HWP 파일 처리
- 한국 법령 검색 (korean-law-mcp + 법망 API 활용)

### 엔터테인먼트
- KBO 경기 결과
- K리그 경기 결과
- 블루리본 맛집·술집 조회

### 금융
- 토스증권 계좌 조회

## 시작 방법

1. "설치 방법" 문서에 따라 전체 스킬 설치
2. `k-skill-setup` 스킬 실행으로 인증 정보 확보
3. 각 기능별 문서 참고 후 이용

## 메모

- 중고차 조회는 현재 SK렌터카 타고BUY만 지원. 믿을만한 업체나 공식 API 제공 업체 제보 환영
- 법령 검색은 korean-law-mcp 및 법망 API 기반으로 구현됨
