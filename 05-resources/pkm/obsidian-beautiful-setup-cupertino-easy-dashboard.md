# Obsidian 예쁘게 세팅하기 — Cupertino 테마 + easy-dashboard

아름다운 Obsidian 대시보드를 3단계로 구성하는 빠른 세팅 가이드.

---

## 3단계 세팅

### 1. 테마 설치
- **Cupertino** 테마 설치
- Settings → Appearance → Themes에서 검색

### 2. 커뮤니티 플러그인 활성화
Settings → Community Plugins → Safe mode 해제 후 아래 두 가지 설치·활성화:
- **Dataview** — 노트 데이터베이스 쿼리
- **Templater** — 고급 템플릿 시스템

### 3. easy-dashboard 플러그인 수동 설치
GitHub 릴리스에서 직접 다운로드 (아직 공식 승인 대기 중):
- **다운로드**: https://github.com/AnnaYurevna/easy-dashboard/releases/tag/1.0.1
- `.obsidian/plugins/` 폴더에 압축 해제
- Obsidian 재시작 후 플러그인 활성화
- 폴더 설정 → 페이지 자동 생성

---

## 주의

- easy-dashboard는 공식 커뮤니티 플러그인 스토어에 아직 미등록 (제출 후 승인 대기 중)
- 수동 설치 필요 — GitHub 릴리스 페이지에서 직접 받을 것
