# 프롬프트 레퍼런스 사이트 4가지 북마크

> "실력 있는 사람들은 창작하지 않고 참고한다."

## 사이트 목록

| # | 사이트 | URL | 특징 |
|---|--------|-----|------|
| 1 | **지피테이블 (GPTable)** | https://gptable.net | 국내 최초 프롬프트 커뮤니티. 업무용~재미용 분류 완비, 완전 무료 |
| 2 | **오픈프롬프트 (OpenPrompt)** | https://openprompt.co | 라이브러리 규모 압도적. 미드저니 사용자에게 특히 유용 |
| 3 | **포켓프롬프트 (Pocket Prompt)** | https://pocketprompt.kr | 퀄리티 중심. 검증된 템플릿만 엄선 — 실패 확률 낮추고 싶을 때 |
| 4 | **렉시카 (Lexica)** | https://lexica.art | 이미지 생성 특화. 결과물에서 프롬프트 역추적 가능 |

## 용도별 선택 가이드

- **업무·일상 텍스트 프롬프트** → GPTable
- **대규모 프롬프트 탐색 / 미드저니** → OpenPrompt
- **검증된 고퀄리티 템플릿** → Pocket Prompt
- **AI 이미지 생성 + 역추적** → Lexica
