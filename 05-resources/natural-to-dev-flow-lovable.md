# Natural-to-Dev Flow — Lovable.app 데모

## 핵심 개념

**자연어 → 동작하는 앱** 파이프라인을 보여주는 데모.
Lovable.app 위에서 빌드되었으며, 자연어 프롬프트만으로 풀스택 웹앱을 생성하는 흐름을 시연한다.

## Lovable이란?

- AI 기반 풀스택 앱 빌더
- 자연어로 앱을 묘사하면 → 프론트엔드 + 백엔드 + DB + 인증까지 코드 자동 생성
- 원클릭 배포 지원

## Natural-to-Dev Flow 단계

1. **아이디어 설명** — 만들고 싶은 앱을 자연어로 묘사 (ChatGPT에게 말하듯이)
2. **실시간 코드 생성** — AI가 즉시 코드를 생성하고 라이브 프리뷰 제공
3. **반복 수정** — 개발자에게 말하듯 피드백 → 즉각 반영

## 기술 스택

React, TypeScript, Tailwind CSS, Supabase

## 활용 팁

- 음성 메모로 아이디어 기록 → GPT/Claude로 명확한 PRD로 확장 → Lovable로 프로토타입 제작
- 코딩 경험 없어도 가능; 숙련 개발자도 빠른 프로토타이핑에 유용

## 한계

- 모바일 앱 불가 (반응형 웹앱만 지원, 네이티브 iOS/Android 아님)
- 고급 디자인 커스터마이징 제한적
