# CCAF 자격증 — 지금 잡아야 할 비대칭 기회

Anthropic이 2026년 3월 12일 **Claude Certified Architect – Foundations(CCAF)** 인증을 공식 출시했다. AWS 인증 초기처럼 채용 시장에서 빠르게 자리 잡을 가능성이 높고, 현재 무료 취득 기회가 열려 있다.

---

## 시험 기본 정보

| 항목 | 내용 |
|------|------|
| 문항 수 | 60문항 |
| 시험 시간 | 120분 |
| 합격 기준 | 720 / 1000점 이상 |
| 준비 과정 | Claude Academy 13개 코스 (무료) |
| 외부 도움 | 금지 (실무형 평가) |

- **Agentic Architecture(에이전트 구조)** 비중이 27%로 가장 높음
- 실제 운영 사례 중심 문제 (예: 멀티 에이전트 CI/CD 파이프라인 설계)

---

## 대기업 도입 현황

- **Deloitte**: 15,000명 교육 진행 중
- **Accenture**: 30,000명 규모로 기업 전체 도입 완료

---

## 개인 응시 방법 (무료)

1. [Claude Partner Network](https://claude.com/partners) 무료 가입
2. **Solo Practitioner(솔로 프랙티셔너)** 로 등록
3. 시험 신청: https://anthropic.skilljar.com/claude-certified-architect-foundations-access-request

> 첫 5,000명은 사실상 0원으로 취득 가능.

---

## 현실적 전망

- **긍정**: AWS 인증 초기처럼 채용 시장에서 중요한 자격으로 자리 잡을 가능성 높음
- **주의**: AI 분야 특성상 수명이 짧을 수 있음 — 6~12개월 내 Advanced 트랙 출시 예상
- **결론**: Claude 생태계 관심 + 실무 AI 아키텍처 학습 목표라면 지금이 최적의 타이밍
