## 레슨 구성

각 레슨은 **Learn**(개념 설명) 또는 **Build**(핸즈온 코딩) 타입으로 구성되며, 영상·README·코드 예제·추가 학습 자료를 포함한다.

```
LLM 기초 이해
  → 프롬프트 엔지니어링
  → 챗 애플리케이션 구축
  → Embeddings 기반 검색 (RAG)
  → 파인튜닝
  → AI 에이전트
  → AI 시스템 보안·위협
```
