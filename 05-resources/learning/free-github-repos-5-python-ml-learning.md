# 무료 GitHub 레포 5개 — Python·ML·프로젝트 학습 완전판

## 한 줄 요약

유료 강의보다 낫다는 평가를 받는 무료 GitHub 학습 레포 5개. Python 입문부터 ML·딥러닝·프로젝트 실습까지 커버.

---

## 5개 레포

### 1. 30 Days of Python
- **대상**: 완전 초보자
- **구성**: 하루 단위 구조화된 커리큘럼
- **목표**: 30일 만에 첫 스크립트 작성까지

### 2. Project-based Learning
- **특징**: 실제 프로젝트를 만들며 배우는 튜토리얼 모음
- **내용**: 웹앱, 스크레이퍼, 미니 게임 등 다양한 Python 프로젝트
- **방식**: 단계별 따라 만들기

### 3. Build Your Own X ⭐ 500k+
- **특징**: GitHub 역대 최고 스타 레포 중 하나
- **내용**: 500개 이상의 "직접 만들어보는" 프로젝트
- **범위**: 운영체제, 데이터베이스, 게임 엔진 등 카테고리 망라

### 4. ML for Beginners (Microsoft)
- **출처**: Microsoft 공식
- **구성**: 설명 + 퀴즈 + 코딩 과제
- **대상**: ML 비전공자 입문용

### 5. 500 AI/ML/DL Projects with Code
- **내용**: AI·머신러닝·딥러닝·컴퓨터비전·NLP 프로젝트 500개
- **특징**: 아이디어가 떨어질 때 즉시 참고 가능
- GitHub: https://github.com/ashishpatel26/500-AI-Machine-learning-Deep-learning-Computer-vision-NLP-Projects-with-code

## 왜 유용한가

- 결제·페이월 없음
- 구조화된 커리큘럼(30일 Python)부터 자유 탐색(Build Your Own X)까지 학습 스타일 선택 가능
- 실제 코드가 함께 있어 따라 하기 즉시 가능
