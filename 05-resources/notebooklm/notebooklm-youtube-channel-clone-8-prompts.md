# NotebookLM으로 유튜브 채널 복제하는 8개 프롬프트

Google NotebookLM으로 성공한 유튜브 채널을 분석하고 무료로 복제하는 워크플로우.
조회수 높은 영상 10~15개를 Sources로 넣고, 아래 프롬프트를 순서대로 사용한다.

---

## 준비

당신의 분야에서 이미 수익을 내고 있는 유튜브 채널을 하나 찾는다.
조회수 높은 영상 10~15개 링크를 모아서 NotebookLM에 Sources로 넣는다.

---

## 프롬프트 8개

### 1. 합법적으로 설계도 가져오기

```
이 채널의 스크립트 구조, 훅 방식, 전개 속도, 톤을 분석해서 성공을 만든 핵심 구조를 정리해줘.
```

### 2. 채널 이름 만들기

```
이 자료들의 패턴을 기반으로, 이 타겟에게 신뢰를 줄 수 있는 채널 이름 10개 만들어줘.
```

### 3. 아이디어 무한 생성

```
이 분석을 기반으로, 인기 있는 주제와 아직 비어 있는 틈을 활용해
영상 아이디어 10개와 각각의 제목, 핵심 메시지를 만들어줘.
```

### 4. 실제로 전환되는 스크립트 작성

```
분석된 채널의 톤과 속도를 반영해서
5초 훅, 문제 제시, 가치 전달, CTA까지 포함한 전체 스크립트를 작성해줘.
```

영상 하나당 4~6시간 절약 가능.

### 5. 클릭을 부르는 제목 만들기

```
이 스크립트를 바탕으로 제목 10개를 만들어줘.
호기심을 자극하고, 명확한 이익을 약속하며,
상위 영상 스타일과 일치하도록.
```

### 6. 스크롤을 멈추게 하는 썸네일

```
Canva에서 만들 수 있는 고전환 썸네일 5개 콘셉트를 줘.
텍스트, 색상, 구성 요소까지 구체적으로.
```

### 7. 사람 없이 음성 만들기

```
이 스크립트의 핵심 내용과 감정 흐름을 요약해서
NotebookLM Audio Overview에 넣을 수 있는 음성용 브리프로 만들어줘.
```

Google NotebookLM에 음성 제작 스튜디오(Audio Overview)가 내장되어 있다.

### 8. 수익 구조까지 완성

```
이 채널의 콘텐츠 구조를 기반으로,
가장 자연스럽게 연결되는 수익 모델(디지털 상품, 강의, 커뮤니티, SaaS 등)을 3가지 제안해줘.
각각에 대해 콘텐츠 → 전환 흐름(퍼널), CTA 위치, 실제 판매 구조까지 구체적으로 설계해줘.
```
