# NotebookLM Tools — 클릭 한 번으로 소스 추가하는 크롬 확장

- **크롬 웹스토어**: https://chromewebstore.google.com/detail/notebooklm-tools/hiibkpjljigehlnnecbgehkhfibmahjn
- **설치 방법**: 크롬 웹스토어에서 'NotebookLM Tools' 검색 → 설치

## 핵심 기능

NotebookLM에 소스를 추가할 때마다 URL을 복사해서 붙여넣는 번거로움을 없애준다. 보고 있는 페이지에서 아이콘 클릭 한 번으로 끝.

### 소스 추가

| 기능 | 설명 |
|------|------|
| 현재 페이지 즉시 추가 | 아이콘 클릭 한 번으로 현재 탭 → NotebookLM |
| URL 목록 일괄 추가 | 여러 URL을 붙여넣고 한 번에 모두 추가 |
| 열린 탭 전체 추가 | 브라우저에 열린 모든 탭을 클릭 한 번으로 추가 |
| 웹페이지 내 링크 수집 | 특정 페이지의 모든 링크를 가져오기 |

### 유튜브 특화

- YouTube 재생목록 전체 가져오기
- YouTube 채널 전체 가져오기

### 기타

- RSS 피드 또는 사이트맵에서 모든 기사 가져오기
- 소스를 폴더로 정리
- 커스텀 프롬프트 저장

## 사용 흐름

```
유튜브 영상 / 논문 / 웹페이지 보는 중
  → "NotebookLM에 넣고 싶다"
  → 상단 아이콘 클릭
  → NotebookLM으로 바로 전송 → 질문 시작
```

## 추천 대상

- 직장인 — 업무 자료 빠른 수집
- 학생·연구원 — 논문 소스 관리
- 기획자 — 정보 수집 자동화
