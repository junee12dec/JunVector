# AI PPT·인포그래픽 도구 5선

> 클로드 카드뉴스 가이드 파일: https://www.notion.so/342e43a167208024a291e95cf115b6b5

---

## 1. Felo — 조사 + PPT를 한 번에

**사이트**: https://felo.ai/search  
**추천 대상**: 자료 조사부터 PPT 정리까지 한 번에 끝내고 싶은 분

- 키워드 검색 → PPT 자동 생성
- AI가 자료 조사·구성·디자인 일괄 처리
- 마인드맵 생성 가능
- 무료 크레딧 제공

**실제 사용 프롬프트 예시**:
> "2026년 한국 스킨케어 신제품 마케팅 전략 PPT 중 시장 분석 슬라이드 하나만 만들어줘. 그래프 포함하고, 실제 회사 보고서처럼 신뢰감 있게, 디자인은 깔끔하고 세련되게."

---

## 2. 캔바 (Canva) — 디자인 감각 없어도 전문가급

**사이트**: https://www.canva.com/templates  
**추천 대상**: 기획자, 마케터, 취준생 — 누구에게나

- 수천 개의 PPT 템플릿
- AI 자동 디자인 추천 (Magic Design)
- 드래그 & 드롭으로 편집

---

## 3. 감마 (Gamma) — 글만 넣으면 슬라이드 완성

**사이트**: https://gamma.app  
**추천 대상**: 내용은 있는데 구성이 막막한 분

- 텍스트 입력 → 완성형 슬라이드 자동 생성
- 깔끔한 디자인 템플릿 자동 적용
- 보고서·제안서·발표자료 모두 가능
- 무료 크레딧 제공

---

## 4. Ideogram — 슬라이드 이미지를 직접 생성

**사이트**: https://ideogram.ai  
**추천 대상**: 유료 이미지 사이트 대체 찾는 분

- 텍스트 입력 → AI 이미지·로고 자동 생성
- 20 slow 크레딧 무료 제공 (무료 플랜 이미지는 공개됨 주의)
- 구글 계정으로 바로 시작

**실제 사용 프롬프트 예시**:
> "minimal skincare product on clean surface, soft natural sunlight, shadow play, neutral tones, aesthetic lifestyle mood, calm and fresh atmosphere, modern beauty brand style, high resolution"

---

## 5. MyMap AI — 데이터를 인포그래픽으로

**사이트**: https://www.mymap.ai  
**추천 대상**: 복잡한 데이터를 깔끔하게 시각화하고 싶은 분

- 텍스트 입력 → 인포그래픽 자동 완성
- 마인드맵, 차트, 시각화 자료 생성
- 디자인 지식 없이 바로 사용 가능
- 기획서·보고서·제안서에 바로 붙여넣기

---

## 용도별 선택 가이드

| 상황 | 추천 도구 |
|------|-----------|
| 자료 조사 + PPT 동시에 | Felo |
| 디자인 감각 없이 빠르게 | Canva |
| 텍스트 → 슬라이드 자동화 | Gamma |
| 슬라이드용 이미지 직접 제작 | Ideogram |
| 데이터 시각화·인포그래픽 | MyMap AI |
