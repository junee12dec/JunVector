# awesome-ai-agents — AI 에이전트 전체 지도 큐레이션 레포 (⭐25.8K)

> AI 에이전트 생태계가 너무 빠르게 변해서 이 레포가 곧 나침반.

GitHub: https://github.com/e2b-dev/awesome-ai-agents

## 구성

| 섹션 | 설명 |
|------|------|
| **오픈소스 프로젝트** | 커뮤니티 개발 에이전트 프레임워크·도구 |
| **클로즈드소스 프로젝트·기업** | 상업용·독점 솔루션 |

## 주요 오픈소스 에이전트 (일부)

| 에이전트 | 특징 |
|---------|------|
| **AutoGen** (Microsoft) | 멀티에이전트 협업 프레임워크 |
| **AgentGPT** | 브라우저 기반 노코드, AutoGPT 유사 |
| **Aider** | CLI 기반 AI 코드 편집 (로컬 레포 연동) |
| **AgentForge** | LLM 무관 에이전트 빌드·테스트 플랫폼 |
| **Agents** | 장기 메모리·툴 사용·웹 탐색 지원 멀티에이전트 라이브러리 |
| **AgentVerse** | 태스크 해결·시뮬레이션 에이전트 플랫폼 |
| **Adala** | 자율 데이터 라벨링 에이전트 |
