# Public APIs — 무료 공개 API 종합 목록

> GitHub ⭐ 330k+ | 커뮤니티 큐레이션 무료 공개 API 목록

각 API마다 설명, 인증 방식(apiKey / OAuth / 없음), HTTPS 지원 여부, CORS 지원 여부를 표시한다.

## 주요 카테고리 (50개+)

| 분야 | 예시 |
|------|------|
| 개발 | GitHub, JSONPlaceholder, Random Data |
| AI/ML | OpenAI, Hugging Face |
| 금융 | 주식, 암호화폐, 환율 |
| 지리 | 지오코딩, 날씨, 지도 |
| 미디어 | 음악, 영상, 이미지 |
| 뉴스 | 뉴스 피드, RSS |
| 스포츠 | 경기 결과, 팀 정보 |
| 정부 | 공공 데이터 |
| 건강 | 의약품, 의료 정보 |

## 활용 팁

- 사이드 프로젝트나 프로토타입 제작 시 빠르게 데이터 소스 탐색 가능
- 인증 없이 바로 쓸 수 있는 API (`Auth: No`)만 필터링해서 빠른 MVP 구축
- CORS 지원 여부 확인 → 프론트엔드에서 직접 호출 가능 여부 판단
