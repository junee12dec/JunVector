# OpenClaw Multi-Agent 설정 튜토리얼

**@_petercha** (peters.place) 가 작성한 OpenClaw 튜토리얼 2편.

1편 '시작하기'에 이어, **멀티 에이전트 구성 및 Agent 간 통신 설정**을 다룬다.

## 핵심 내용

### 튜토리얼 콘셉트

스펀지밥 세계관을 테마로 멀티 에이전트 설정을 실습:

- **기존 에이전트**: 스펀지밥 🧽 세계관 구성원들
- **신규 추가**: 보안 담당자(CISO) 역할의 **플랑크톤** 에이전트

### 다루는 내용

1. OpenClaw에서 새 에이전트(플랑크톤) 추가하기
2. 에이전트 역할(CISO/보안) 설정하기
3. **Agent끼리 대화(통신)** 가능하게 설정하는 방법

## 왜 중요한가

멀티 에이전트 설계에서 **역할 분리**는 핵심 원칙.
보안, 영업, 운영 등 전문 역할을 각 에이전트에 위임하면 단일 에이전트보다 훨씬 견고한 자동화가 가능하다.

Agent 간 통신 설정은 워크플로우 자동화의 핵심 — 에이전트가 서로 결과를 주고받아야 복잡한 파이프라인이 작동한다.
