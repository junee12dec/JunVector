# ReClip — 광고 없는 오픈소스 영상·오디오 다운로더

> 10년간 광고 범벅 다운로더 사이트를 쓰던 사람들이 감탄했죠. 며칠 만에 GitHub 스타 수천 개.

- GitHub: https://github.com/averygan/reclip
- 라이선스: 오픈소스 (완전 무료)

## 핵심 특징

- **광고 없음 · 팝업 없음 · 트래커 없음 · 계정 없음**
- **로컬 실행**: 데이터가 외부로 나가지 않음
- **1,000개 이상 사이트** 지원

## 지원 사이트

YouTube, TikTok, Instagram, X(Twitter), Reddit, Facebook, Vimeo, Twitch, SoundCloud, Threads, LinkedIn 등 1,000개 이상

## 사용법

1. 링크 붙여넣기 → 썸네일 자동 표시
2. **MP4**(영상) 또는 **MP3**(오디오) 선택
3. 해상도 선택 후 다운로드

- 여러 링크 동시 입력 → **일괄 다운로드**
- 중복 링크 **자동 필터링**

## 기술 스택

| 항목 | 내용 |
|------|------|
| 백엔드 | Python 150줄 |
| 프론트엔드 | 순수 HTML |
| 의존성 | 2개 |
| 배포 | Docker 지원 |
