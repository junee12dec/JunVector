# Storybook — UI 컴포넌트 격리 개발·문서화·테스트 업계 표준 워크숍

**GitHub**: https://github.com/storybookjs/storybook  
**⭐ ~90,000 stars** / 10,100 forks / 1,799개 릴리스  
**최신 버전**: v10.4.0 (2026-05-14)

> "The industry standard workshop for building, documenting, and testing UI components in isolation."

---

## 핵심 기능

| 용도 | 설명 |
|------|------|
| **UI 개발** | 격리된 환경에서 컴포넌트 구축·검증 |
| **테스팅** | 접근성(a11y) 테스트, 시각적 회귀 테스트 |
| **문서화** | 고품질 컴포넌트 문서 자동 생성 |
| **설계 시스템** | 다중 팀의 UI 일관성 유지 |

---

## 왜 쓰나

- 앱 전체를 실행하지 않고 컴포넌트 단위로 개발·검증
- 컴포넌트의 모든 상태(state)를 스토리로 문서화
- 시각적 테스트로 의도치 않은 UI 변경 감지
- 팀 간 UI 컴포넌트 라이브러리 공유
