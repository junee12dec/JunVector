# 세계 최고 개발자 사고방식을 담은 AI GitHub 저장소 10선

2026년 AI 오픈소스는 코드 공유를 넘어 **전문가의 사고방식 자체를 복제 가능한 형태로 공개**하는 방향으로 진화 중.

---

## 10개 저장소

### 1. andrej-karpathy-skills
Andrej Karpathy의 AI 코딩 철학과 작업 방식을 단일 Markdown 문서로 정리.  
GitHub 역사상 가장 많은 스타를 받은 단일 파일 저장소 중 하나.  
→ https://github.com/forrestchang/andrej-karpathy-skills  
→ 볼트 노트: [[andrej-karpathy-skills-claude-md]]

### 2. MemPalace
배우 Milla Jovovich가 공동 개발 참여한 AI 메모리 시스템.  
Claude Code 기반 제작, LongMemEval 벤치마크 최고 성능 기록.  
→ https://github.com/MemPalace/mempalace

### 3. autoresearch
Andrej Karpathy가 공개한 연구 자동화 프레임워크. AI 기반 리서치 워크플로우 자동화.  
→ https://github.com/karpathy/autoresearch  
→ 볼트 노트: [[karpathy-autoresearch-ai-agent-experiment]]

### 4. awesome-claude-code
Claude Code 활용 전략과 워크플로우를 정리한 대표 저장소.  
→ https://github.com/hesreallyhim/awesome-claude-code

### 5. SuperClaude Framework
Claude Code 활용 방법론 프레임워크. Persona·프롬프트·워크플로우 포함.  
→ https://github.com/SuperClaude-Org/SuperClaude_Framework

### 6. AI-Agents-for-Beginners
Microsoft 공개 AI 에이전트 입문 강의. 실습 중심 12개 레슨.  
→ https://github.com/microsoft/ai-agents-for-beginners

### 7. awesome-llm-apps
실제로 동작하는 LLM 애플리케이션 사례 대규모 모음.  
→ https://github.com/Shubhamsaboo/awesome-llm-apps

### 8. mattpocock/skills
TypeScript 전문가 Matt Pocock의 개발 워크플로우와 코딩 습관.  
→ https://github.com/mattpocock/skills  
→ 볼트 노트: [[mattpocock-skills-real-engineer-claude-code]]

### 9. hermes-agent
대화 과정에서 스스로 능력을 축적하고 진화하는 AI 에이전트.  
→ https://github.com/NousResearch/hermes-agent  
→ 볼트 노트: [[hermes-agent-self-growing-ai-agent-tips]]

### 10. qlib
Microsoft Research 공개 퀀트 투자 플랫폼. 금융 AI 연구와 전략 개발에 활용.  
→ https://github.com/microsoft/qlib
