# ChatGPT 이미지로 나만의 보고서 만들기 — 재미있는 프롬프트 10선

> "지금 당장 챗GPT한테 요청해보세요"

두 가지 입력 방식:
- **대화 내역 기반** — "지금까지 나와의 대화 내역을 기반으로 ~"
- **사진 기반** — "내 사진을 보고 ~"

---

## 프롬프트 10선

| # | 프롬프트 | 입력 |
|---|---------|------|
| 1 | "내 사진을 보고 나의 **퍼스널컬러 보고서**를 이미지로 만들어줘." | 사진 |
| 2 | "내 사진을 보고 나의 **헤어 스타일 추천서**를 이미지로 만들어줘." | 사진 |
| 3 | "지금까지 나와의 대화 내역을 기반으로 나의 **MBTI 보고서**를 이미지로 만들어줘." | 대화 내역 |
| 4 | "내 사진을 보고 나와 어울리는 **연예인 분석 보고서**를 이미지로 만들어줘." | 사진 |
| 5 | "나와 나의 연인 사진을 보고 **궁합 보고서**를 이미지로 만들어줘." | 사진 2장 |
| 6 | "내 사진을 기반으로 **외모 평가 보고서**('내 외모 몇 점?')를 만들어줘." | 사진 |
| 7 | "내 사진을 기반으로 **운세 보고서**(애정, 직장, 금전 등)를 만들어줘." | 사진 |
| 8 | "지금까지 나와의 대화 내역을 기반으로 **CIA 심리 프로파일 보고서**를 이미지로 만들어줘." | 대화 내역 |
| 9 | "지금까지 나와의 대화 내역을 기반으로 **전 애인 입장에서 작성된 평가서**를 이미지로 만들어줘." | 대화 내역 |
| 10 | "지금까지 나와의 대화 내역을 기반으로 **인사팀 내부 평가 보고서**를 이미지로 만들어줘." | 대화 내역 |

보너스:
> "지금까지 나와의 대화 내역을 기반으로 나의 **사주 보고서**를 이미지로 만들어줘."

## 활용 포인트

- SNS 콘텐츠·재미용으로 즉시 활용 가능
- '대화 내역 기반' 프롬프트는 GPT가 대화 맥락을 학습한 상태일수록 결과물이 정교해짐
- 사진 기반 프롬프트는 GPT-4o의 멀티모달 능력 활용
