# NotebookLM 카드뉴스 제작 프롬프트 템플릿

## 슬라이드 검증 규칙

슬라이드 확정 전 아래 항목을 모두 확인:

- 비율 4:5 (세로)인가?
- 세로 흐름인가?
- 내용 overflow 없는가?
- 넓은 요소 없는가?

하나라도 실패하면 재설계하거나 콘텐츠를 분리. 실패한 슬라이드는 출력하지 않음.

## 덱 구성 (20슬라이드)

| 슬라이드 | 역할 |
|----------|------|
| 1 | 커버 |
| 2–5 | 컨텍스트 |
| 6–12 | 프로세스 |
| 13–17 | KPI |
| 18–19 | 요약 |
| 20 | CTA |

## 스타일 가이드

- 배경: 밝은 계열
- 텍스트: 어두운 색
- 강조 컬러: 블루 · 그린 · 오렌지
- 폰트: 굵은 산세리프
- KPI 숫자: 크게 강조
- 아이콘: 아이소메트릭 벡터
- 사실적 사진 사용 금지
