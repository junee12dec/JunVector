# kubai-icons — 호버 애니메이션 아이콘 + Claude Code 스킬

GitHub: [kubai087/kubai-icons](https://github.com/kubai087/kubai-icons)  
아이콘 사이트: [icons.kubai.design/icons](https://icons.kubai.design/icons/)  
라이선스: MIT (상업 이용 가능)

## 특징

호버 시 **물건답게** 움직임:
- 폴더 → 열림
- 봉투 → 뜯김
- 달력 → 다음 날로 넘어감
- 자물쇠 → 튕겨 열림

## 사용법

- **받는 형식**: React · Vue · 웹 · SVG
- **사이트**: 이름으로 검색 → 색 변경 → 코드 또는 PNG 다운로드

## Claude Code 스킬로 새 아이콘 생성

저장소에 없는 아이콘이 필요할 때:

```
"이 저장소 읽고 주요 기능 아이콘 그려 줘"
```

→ 기존 아이콘 옆에 놓고 크기·선·색을 스스로 맞춰 줌.  
스킬로 그린 아이콘도 내 소유 (스킬 규칙 파일 수정·재배포는 불가).
