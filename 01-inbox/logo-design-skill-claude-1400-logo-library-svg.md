# logo-design-skill — 실제 로고를 연구해 SVG 로고를 만드는 에이전트 스킬

- 저장소: https://github.com/kaankiziltug/logo-design-skill (MIT, 저장 시점 약 7,300⭐, 포크 564)
- Claude, Gemini CLI, Codex CLI, Cursor, GitHub Copilot 등 Agent Skills를 지원하는 에이전트에서 쓴다.
- 소개 글: @laeshaai (Threads, 2026-11-17) — "작은 브랜드와 프리랜서가 많이 쓰게 될 것"

## 흐름

1. **브리프**: 질문하거나, 묻지 않을 때는 가정을 밝힌다
2. **조사**: 라이브러리에서 해당 업계의 관례를 찾는다
3. **콘셉트**: 한 줄 아이디어 8~12개 → 그중 3개를 SVG로 만든다
4. **시험과 다듬기**: SVG 점검, 16px, 단색, 경쟁사 진열대 테스트
5. **체크포인트**: 시안을 한 장으로 보여 주고 하나를 추천한 뒤 **멈춘다**
6. **키트**: 방향을 고르고 요청하면 색, 로크업, 발표 보드, 아이콘, 가이드라인을 만든다 (수정을 원하면 3단계로 돌아간다)

키트가 일의 대부분이고 승인된 아이디어에만 의미가 있어서, 고르기 전에는 다른 것을 만들지 않는다.

## 들어 있는 것

- **원칙과 절차**: 디스커버리와 브리프, 단어 매핑, 마크 유형 고르기, 콘셉트, 기하 구성, 시각 보정(오버슈트, bone effect, irradiation 등), 색, 타이포, 로크업, 시험, 발표, 납품, 리디자인, 아이덴티티 시스템.
- **실제 SVG 로고 1,400개 이상의 라이브러리**: 마크 유형·기법·기하·주제·타이포·분위기·업계로 분류돼 있고, 명령줄로 검색하거나 로컬 갤러리로 본다. **구성 연구, 업계 관례 파악, 비슷한 로고 피하기**에만 쓰고 베끼지 않는다.
- **의존성 없는 파이썬 도구**: SVG를 로고 원칙으로 점검, 콘셉트 비교표와 시험표(16px 픽셀 테스트, 단색, 반전, 흐리게 보기, 좌우 반전, 쓰임새, 경쟁사 진열대), 업계별 목업이 든 발표 보드, PNG 렌더링, 파비콘·앱 아이콘·웹 매니페스트 묶음 내보내기.

## 시험이 잡아내는 것

`svg_audit.py`가 디자인 원칙을 검사로 바꾼다. 예:
- 앵커 포인트가 비슷한 로고 95%보다 많으면 경고 (라이브러리 중앙값과 비교)
- 깨끗한 각도에서 0.3~3° 어긋난 직선
- 캔버스의 1/48보다 작은 세부 요소
- 결과로 "production-readiness score"(예: 99/100, 76/100)를 낸다

시험표는 시안을 96px·32px, 단색·반전으로 나란히 놓고 16px까지 크기를 줄여 본다.

## 예시

가상의 브리프 28개를 끝까지 돌린 예가 README에 있다 (커피 로스터, 음식 배달, 명품 패션, 음악 축제, 보안 SaaS, 디지털 뱅킹, 원격 진료 등).
- 붐비는 업계의 뻔한 상징을 피하는 연습: SaaS(말풍선·차트·자물쇠 금지), 금융(동전·돼지저금통·은행 파랑 금지), 헬스(십자가·알약·심전도 금지).
- 10건 중 4건은 클라이언트가 추천과 다른 시안을 골랐고, 스킬이 그 선택을 다듬어 색을 입혔다. 체크포인트가 있는 이유다.
- 예: Zestly(음식 배달) 추천 시안 "Big Grin" — 시트러스 조각을 윙크하는 웃음으로 뒤집은 마스코트. 스킬이 "수박으로 읽힐 수 있다"는 위험도 함께 알렸다.

## 설치

Claude Code (플러그인 마켓플레이스):

```
/plugin marketplace add kaankiziltug/logo-design-skill
/plugin install logo-design@logo-design-skill
```

- Claude.ai / Claude Desktop: Releases의 `logo-design.zip`을 설정 → 기능 → 스킬에 올린다 (용량 제한이 있으면 SVG를 뺀 `logo-design-lite.zip`).
- Gemini CLI·Codex CLI: 저장소를 받아 `skills/logo-design` 폴더를 각 에이전트의 스킬 폴더에 복사.
- 이미지를 볼 수 있는 모델에서 가장 잘 된다. 초안을 PNG로 렌더링해 스스로 확인한 뒤 보여 주기 때문이다.
- 도구는 Python 3.8+ 표준 라이브러리만 쓴다. PNG/ICO 내보내기는 cairosvg, rsvg-convert, Inkscape, 크롬 계열 브라우저 중 있는 것을 쓴다.
