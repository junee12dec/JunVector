# html-anything — 글·표 → AI 디자인 변환 도구

GitHub: [nexu-io/html-anything](https://github.com/nexu-io/html-anything)  
별 8,500

## 사용 방법

1. 글이나 표를 붙여넣기
2. 템플릿 선택
3. AI가 만드는 과정을 화면에서 실시간으로 확인
4. PNG로 저장

## 지원 출력 형식

- 카드뉴스
- 포스터
- 발표자료 (템플릿 20종)

## 특징

- 디자인 지식 없이 텍스트만으로 결과물 생성
- AI가 레이아웃을 직접 구성
- 생성 과정을 화면에서 실시간으로 시각화
- 콘텐츠 제작자·마케터에게 특히 유용
