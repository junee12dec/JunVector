## 1. ip-as-logo-skill — 캐릭터 로고

- https://github.com/s1dashu/ip-as-logo-skill
- "아주 단순하고 둥글며 살짝 입체감 있는 IP 마스코트 로고"를 만드는 에이전트 스킬.
- "동네 빵집 마스코트 만들어 줘" → 방향을 몇 가지 먼저 보여 주고, 고르면 후보를 여러 장 뽑아 준다.
- 선이 굵고 단순해 간판이나 프로필 사진에서도 또렷하다.
- 웹사이트에서 이미 만들어진 로고를 무료로 내려받을 수 있고, 장사에 써도 된다 (작성자 설명).

## 2. guizang-ppt-skill — 잡지형 발표자료

- https://github.com/op7418/guizang-ppt-skill
- 긴 블로그 글을 넘기면 세련된 HTML 슬라이드로 바꾼다. **잡지 감성(editorial)** 과 **깔끔한 격자(Swiss)** 중에서 고른다.
- 파일 하나라 브라우저에서 바로 열리고, 발표자 메모 화면과 레이저 포인터가 들어 있다. 이미지 프롬프트, SNS 표지, WebGL/저전력 발표 런타임도 포함 (GitHub 설명).
- 강연·제품 발표가 잦은 사람에게 맞는다.
- 볼트의 [[open-design-claude-design-95-opensource|Open Design]] 노트에 "덱 모드" 스킬로 한 줄 언급돼 있다.

## 3. Mochi Diffusion — 맥 로컬 이미지 생성

- https://github.com/MochiDiffusion/MochiDiffusion
- 맥에서 Stable Diffusion을 네이티브로 돌린다. "노을 지는 바닷가 카페"라고 쓰면 인터넷이 끊겨 있어도 그림이 나온다.
- 전부 내 컴퓨터 안에서 돌아가 외부로 나갈 걱정이 없고, 만든 그림은 앱 안 갤러리에 쌓인다.
- 앱은 설치 파일로 클릭해 깔지만, 그림 재료인 **모델 파일은 따로 받아야** 한다. 맥 전용.

## 4. guizang-social-card-skill — SNS 카드뉴스·블로그 표지

- https://github.com/op7418/guizang-social-card-skill
- 글 한 편으로 SNS 카드뉴스 묶음과 블로그 표지를 같이 만든다 (원래는 샤오훙수 캐러셀과 위챗 21:9 + 1:1 표지용). 레이아웃 28종, 테마 10종, HTML 한 파일 → PNG.
- 사진 위에 글씨를 얹을 때 얼굴이나 제품을 피해서 자리를 잡는다.
- 직접 찍은 짧은 영상을 넣으면 움직이는 사진 카드로도 만든다.
- 매주 SNS 콘텐츠를 만드는 1인 사업자에게 좋다.

## 5. ian-xiaohei-illustrations — 손그림 설명 그림

- https://github.com/helloianneo/ian-xiaohei-illustrations
- 블로그 글을 넣으면 **까만 꼬마 캐릭터(小黑)** 가 일하는 손그림 설명 그림을 만든다.
- 글 속 핵심 생각 하나를 골라 엉뚱한 비유로 그려 기억에 오래 남게 한다.
- 16:9 흰 바탕, 빨강·주황·파랑 손글씨 메모만 살짝 얹은 그림체. 그림 속 글씨는 짧을수록 잘 나온다.

## 참고

- 다섯 개 모두 무료지만 쓰는 방식에 따라 AI 사용료나 좋은 컴퓨터가 필요할 수 있다.
- 스킬 4개(1·2·4·5)는 Claude Code·Codex 같은 AI 에이전트에 설치가 필요하다. 작성자 팁: 막막하면 GitHub 링크를 ChatGPT나 Claude에 붙여넣고 "왕초보한테 설치 방법 알려 줘"라고 하면 된다.
- 2·4번은 AGPL-3.0이라, 고쳐서 서비스로 공개하면 소스 공개 의무가 생긴다.
