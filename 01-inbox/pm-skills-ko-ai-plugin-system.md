# PM Skills 한국어판 — 제품 의사결정을 위한 AI 스킬 8종 모음

**GitHub**: https://github.com/lucas-flatwhite/pm-skills-ko

Claude Code, Codex, Gemini CLI, Cursor, Kiro 등 주요 AI 코딩 환경에서 동작하는 PM 전용 AI 스킬 모음집.

## 사용 가능한 플러그인 (8종)

| 플러그인 | 포함 내용 | 스킬/커맨드 |
|----------|-----------|-------------|
| `pm-product-discovery` | 아이디에이션, 실험, 가정 테스트, OST, 인터뷰 | 13개 스킬, 5개 커맨드 |
| `pm-product-strategy` | 비전, 비즈니스 모델, 가격 전략, 경쟁 환경 | 12개 스킬, 5개 커맨드 |
| `pm-execution` | PRD, OKR, 로드맵, 스프린트, 레트로, 릴리즈 노트, 이해관계자 관리 | 15개 스킬, 10개 커맨드 |
| `pm-market-research` | 페르소나, 세분화, 여정 맵, 시장 규모, 경쟁사 분석 | 7개 스킬, 3개 커맨드 |
| `pm-data-analytics` | SQL 생성, 코호트 분석, A/B 테스트 분석 | 3개 스킬, 3개 커맨드 |
| `pm-go-to-market` | 비치헤드 세그먼트, ICP, 메시징, 성장 루프, GTM 모션, 배틀카드 | 6개 스킬, 3개 커맨드 |
| `pm-marketing-growth` | 마케팅 아이디어, 포지셔닝, 가치 제안, 네이밍, 노스 스타 메트릭 | 5개 스킬, 2개 커맨드 |
| `pm-toolkit` | 이력서 검토, 법률 문서, 교정 | 4개 스킬, 5개 커맨드 |

## 핵심 포인트

- **한국어로 구성**되어 있어 내용 참고만으로도 유용
- Claude Code / Cowork 환경에서 바로 적용 가능
- Codex, Gemini CLI, Cursor, Kiro 등 다양한 AI 도구에서도 동일하게 동작
- PM 도메인 지식과 분석 프레임워크를 스킬로 패키징한 것이 핵심
