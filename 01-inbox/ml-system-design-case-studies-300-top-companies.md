# ML 시스템 디자인 케이스 스터디 300+

GitHub: [Engineer1999/A-Curated-List-of-ML-System-Design-Case-Studies](https://github.com/Engineer1999/A-Curated-List-of-ML-System-Design-Case-Studies)  
무료 / 탑 기업 실제 사례 300+

## 핵심 메시지

> "토이 프로젝트는 끝났다. 포트폴리오가 실제 비즈니스 문제를 건드리지 않으면 필터링된다."

### 포트폴리오가 죽는 패턴
- "여기 내 모델 있어요"
- "여기 내 차트 있어요"
- "여기 내 노트북 있어요"

### 실제 채용 신호
> **"비즈니스 결과를 만드는 워크플로우를 실제로 배포할 수 있는가?"**

## 이 레포가 유용한 이유

- 실제로 기업에서 만들어지는 ML 시스템 사례 300개 이상
- 탑 기업(Google, Meta, Netflix, Airbnb 등)이 실제로 설계하고 운영한 ML 시스템
- 포트폴리오 프로젝트 아이디어 소스로 활용 가능
- ML 시스템 설계 면접 준비용

## 활용 방법

1. 관심 도메인(추천, 검색, 광고, NLP 등)의 케이스 스터디 읽기
2. 실제 비즈니스 문제가 어떻게 ML 시스템으로 해결됐는지 역추적
3. 유사한 문제를 포트폴리오 프로젝트로 재현
4. "모델 만들기"가 아닌 "비즈니스 워크플로우 배포"로 프레임 바꾸기
