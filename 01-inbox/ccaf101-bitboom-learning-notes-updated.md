# bitboom의 CCAF101 학습 노트 업데이트 — 자격증 개념 총정리

`@rkm1st`의 Threads 포스트에서 공유된 업데이트:

> "Claude Certified Architect - Foundations 자격증을 취득하기 위한 개념들을 업데이트 했습니다."

학습 노트 사이트: https://bitboom.github.io/ccaf101/

---

## CCAF 시험 개요 (복습)

| 항목 | 내용 |
|------|------|
| 문항 수 | 60문항 (4개 시나리오 랜덤 선택) |
| 시험 시간 | 120분 |
| 합격 기준 | 720 / 1000점 이상 |
| 응시료 | USD 99 (초기 무료 취득 기회 있음) |

---

## 5대 핵심 도메인 요약

| 도메인 | 비중 |
|--------|------|
| D1. 에이전트 아키텍처 | 27% |
| D2. 도구 설계 및 MCP | 18% |
| D3. Claude Code 워크플로 | 20% |
| D4. 구조화된 출력 | 20% |
| D5. 문맥 관리 및 신뢰성 | 15% |

> **전략 포인트**: D1 + D3만 합쳐도 47%. 처음 준비한다면 이 두 영역부터.
