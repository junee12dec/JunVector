# GPT 이미지로 디자인 시스템 생성하는 프롬프트

**도구**: ChatGPT 이미지 생성 (GPT-4o Image)

---

## 프롬프트

```
흰색 배경에 엄격한 8px 그리드, 일관된 간격, 타이포그래피 스케일, 컬러 시스템을 모든 이미지가 따르는 다중 페이지 디자인 시스템을 생성해 줘. 완벽한 정렬과 일관성을 갖춘 UI 컴포넌트, 레이아웃, 변형들을 보여줄 것. 이미지 제작
```

## 포함 요소

- 8px 그리드 시스템
- 타이포그래피 스케일
- 컬러 시스템
- UI 컴포넌트
- 레이아웃 패턴
- 컴포넌트 변형(variants)
