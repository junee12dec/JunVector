# PM Skills — AI 기반 PM 업무 자동화 툴킷

## 개요

GitHub 7,000+ 스타를 받은 오픈소스 PM 툴킷. 기획에 필요한 업무 65개를 AI 스킬로 정의해두어, AI가 유명 제품 전략가들의 방법론을 따라 실무에 바로 쓸 수 있는 결과물을 만들어준다.

기획서 작성에 하루 걸리던 작업을 10분으로 줄일 수 있다는 게 핵심 가치.

## 주요 기능

- **스킬(Skills)**: 특정 PM 태스크에 대한 프레임워크와 단계별 워크플로우 제공. 관련 상황에서 자동 로드
- **커맨드(Commands)**: `/discover`, `/strategy`, `/write-prd` 등 여러 스킬을 체이닝한 사용자 트리거 워크플로우
- **플러그인(Plugins)**: 8개 도메인별 설치 가능한 패키지

## 8개 플러그인 도메인

| 플러그인 | 포함 기능 |
|---------|---------|
| Product Discovery | 아이디어 발굴, 실험 설계, 인터뷰 |
| Product Strategy | 비전, 비즈니스 모델, 가격 전략 |
| Execution | PRD 작성, OKR 설정, 로드맵 |
| Market Research | 페르소나, 시장 세분화, 경쟁사 분석 |
| Data Analytics | SQL, 코호트 분석, A/B 테스트 |
| Go-to-Market | GTM 전략, 성장 루프 |
| Marketing & Growth | 포지셔닝, North Star 지표 |
| Toolkit | 이력서 검토, 법률 문서 |

## 설치 방법

- **Claude Cowork**: 비개발자에게 추천 (GUI 기반)
- **Claude Code**: CLI로 바로 설치·사용
- **기타 AI 도구**: 범용 스킬 파일 형식 지원
