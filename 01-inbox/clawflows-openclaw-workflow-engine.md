# ClawFlows — OpenClaw 워크플로우 엔진, 100개+ 사전제작 에이전트 워크플로우

> 출처: Threads @softdaddy_o
> OpenClaw에 워크플로우 엔진이 붙었다. 예전엔 에이전트 워크플로우를 YAML로 직접 짜야 했지만, ClawFlows는 자연어로 "이거 자동화해줘" 하면 워크플로우를 자동 생성한다.

## 한 줄 요약

OpenClaw 에이전트를 위한 워크플로우 자동화 시스템. 100개+ 사전제작 워크플로우를 1클릭으로 활성화하거나 자연어로 새 워크플로우를 생성할 수 있다.

## 핵심 특징

- **자연어 워크플로우 생성**: "Run my morning briefing" 같은 명령으로 즉시 실행
- **100+ 커뮤니티 워크플로우**: 1클릭 활성화, 카테고리별 분류
- **Lobster Shell 내장 엔진**: 에이전트 간 협업 조율
- **플레인 텍스트 기반**: 읽기 쉽고, 공유 쉽고, 버전 관리 가능
- **신뢰성**: Reliable & Deterministic 설계

## 워크플로우 카테고리

| 카테고리 | 예시 |
|----------|------|
| Smart Home | 수면 모드, 모닝 루틴, 집중 모드 (조명·온도·스피커 제어) |
| Daily Routines | 아침 브리핑, 캘린더 확인, 저널링, 취침 알림 |
| Health & Wellness | 습관 트래킹, 수분 섭취 알림, 운동 계획, 기분 체크인 |
| Finance | 청구서 추적, 구독 감사, 예산 트래킹, 지출 리포트 |
| Productivity | 태스크 트리아지, 주간 계획, 딥워크 블로킹 |
| Dev Tools | PR 리뷰, 의존성 모니터링, Docker 정리 |
