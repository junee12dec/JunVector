# oh-my-agent — 실전 회사원이 만든 하네스 워크플로우 오픈소스

**GitHub**: https://github.com/first-fluke/oh-my-agent  
**작성자**: Claude Max 5x 유저 (현직 회사원)

---

## 배경

oh-my 하네스 시리즈에 대한 논쟁이 많은 상황에서, 실제로 잘 활용 중인 사용자가 자신의 워크플로우를 오픈소스로 공개.

> "이런 식으로 옵시디언에 HTML로 정리해서 쓰는데 실패한 적 없음."

## 사용 방식

- **Obsidian + HTML** 조합으로 하네스 정보 정리
- oh-my 시리즈 기반의 코딩 워크플로우
- 완성도 > 토큰 절약 철학

## 핵심 관점

| 항목 | 입장 |
|------|------|
| 토큰 소모 | "완성도가 더 중요" — 토큰 걱정보다 결과물 퀄리티 우선 |
| 사용 규모 | Max 5x (10x 멀티 계정 아님) |
| 하네스 회의론자에게 | "제대로 써보지 않고 복잡도만 늘린다고 단정짓는 건 아쉬움" |
