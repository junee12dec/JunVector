# Flowise — 드래그 앤 드롭 AI 에이전트 빌더

**GitHub**: https://github.com/FlowiseAI/Flowise  
52,500+ stars / Apache 2.0 / "Build AI Agents, Visually"

---

## 핵심 기능

| 항목 | 내용 |
|------|------|
| **빌드 방식** | 드래그 앤 드롭 시각적 인터페이스 |
| **대상** | AI 에이전트, 챗봇, 워크플로우 자동화 |
| **코딩 수준** | 노코드/로우코드 |
| **배포** | Docker + 다양한 클라우드 지원 |
| **라이선스** | Apache 2.0 오픈소스 |

---

## 통합 지원

- **LLM**: OpenAI / ChatGPT + 다양한 LLM
- **프레임워크**: LangChain
- **검색**: RAG 기술 통합
- **확장**: 써드파티 커스텀 노드 추가 가능

---

## 구조

모노레포 3모듈:
- **Server** — 백엔드 API
- **UI** — 드래그 앤 드롭 프론트엔드
- **Components** — 노드/컴포넌트 라이브러리
