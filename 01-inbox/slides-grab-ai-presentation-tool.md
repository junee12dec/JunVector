# slides-grab — AI 에이전트 + 드래그 편집 슬라이드 도구

> GitHub: https://github.com/vkehfdl1/slides-grab

## 핵심 기능

- AI가 슬라이드를 **HTML로 자동 생성**
- 브라우저에서 **마우스 드래그**로 직접 수정
- AI에게 자연어로 지시 → 알아서 수정
- **PDF, PPTX**로 내보내기 가능

## 왜 신선한가

### 기존 도구의 문제
- 슬라이드가 복잡한 포맷 (PPTX, PDF)
- AI가 수정하기 어려움
- 결국 수동 클릭 작업

### slides-grab의 접근
- 슬라이드를 **HTML/CSS**로 관리
- AI 에이전트(Claude Code, Codex)가 쉽게 수정 가능
- 비개발자도 드래그로 직관적 편집

## 워크플로우

```
토픽 입력 → AI 아웃라인 생성 → 디자인 → AI 반복 수정 → 내보내기
```

"토픽만 던지면 슬라이드가 나온다"는 경험이 가능한 구조.
