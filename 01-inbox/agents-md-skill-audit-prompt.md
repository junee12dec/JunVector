# AGENTS.md·Skill 파일 감사 프롬프트

> AGENTS.md와 Skill 파일을 오랫동안 정리하지 않았다면, 새 대화를 열고 아래 프롬프트를 실행해볼 것.

## 감사 프롬프트

```
내 AGENTS.md 파일과 Skill을 검토하여, 불명확하거나 충돌되거나 중복된 지침을 찾아라.
이러한 지침들은 불필요하게 멈추게 하거나, 불필요한 확인을 요구하거나, 작업을 불완전하게 만들 수 있다.

특히 자율성, 명확화, 승인 및 작업 완료에 관한 규칙에 주의하라.
의도적으로 설정된 안전 장치를, 일상적인 작업에 예기치 않게 확인을 요구하는 표현과 구분하라.

각 문제에 대해:
- 관련 지침을 인용하고
- 파일을 식별하며
- 그것들이 어떻게 행동에 영향을 미칠 수 있는지 설명하고
- 구체적인 편집 제안을 제시하라

명확한 승인 요구는 유지하고, 어떠한 제안된 변경도 권한을 확장할 것임을 지적하라.
가장 큰 실질적 차이를 가져올 변경을 우선시하라.
어떠한 파일도 변경하기 전에, 검토를 위한 편집 제안을 제시하라.
```

## 언제 실행하면 좋은가

- AI 코딩 도구(Claude Code, OpenCode 등)를 새로 바꾸거나 업그레이드했을 때
- 스킬·에이전트 파일을 오랫동안 손대지 않았을 때
- AI가 불필요하게 자주 멈추거나 확인을 요구한다고 느껴질 때

## 핵심 원칙

| 유지할 것 | 줄일 것 |
|-----------|---------|
| 명시적 승인이 필요한 안전 장치 | 일상 작업에서의 불필요한 확인 요청 |
| 권한 범위를 제한하는 규칙 | 모호해서 해석이 엇갈리는 표현 |
| 의도적 중단점 | 실수로 생긴 중복 지침 |
