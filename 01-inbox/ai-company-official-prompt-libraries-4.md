# AI 회사 공식 프롬프트 모음 4곳

## 1. OpenAI Academy — 직장인용 팩

링크: [academy.openai.com](http://academy.openai.com/ko/public/clubs/work-users-ynjqu/resources/chatgpt-for-any-role)

- 직장인용 역할별 프롬프트 팩
- 챗GPT에서 바로 실행 가능

## 2. 구글 Gemini 프롬프트 가이드

링크: [workspace.google.com](http://workspace.google.com/intl/ko/resources/ai/writing-effective-prompts)

- 전부 한국어
- 직군 **11개** 분류
- 복사 버튼 제공

## 3. MS Copilot 프롬프트 갤러리

링크: [adoption.microsoft.com](http://adoption.microsoft.com/ko-kr/copilot/prompt-gallery)

- 한국어
- 로그인 없이 바로 열람
- 업무용 **60개 이상**

## 4. Claude Code 프롬프트 라이브러리

링크: [code.claude.com/docs/ko/prompt-library](http://code.claude.com/docs/ko/prompt-library)

- Anthropic 공식 **52개**
- 한국어 지원
- 코딩 중심이지만 마케팅 태그도 포함
