# 프론트엔드 개발자를 위한 디자인 도구 3선

---

## 1. Developer Icons

**링크**: http://github.com/xandemon/developer-icons

- 단순 SVG 모음이 아닌 **하나의 아이콘 디자인 시스템**
- 크기·색상·스타일 등 커스터마이징 가능
- 개발자/기술 스택 아이콘 특화

---

## 2. Impeccable

**링크**: https://impeccable.style/

- **반복적인 UI 실수를 줄여주는 디자인 지침 모음**
- Claude Code·Cursor 등 AI 코딩 툴에 바로 적용 가능
- AI가 생성한 UI의 품질을 높이는 체크리스트 역할

---

## 3. bg.layers

**링크**: https://bg-layers.vercel.app/

- 복잡한 **CSS 배경을 시각적으로 편집**할 수 있는 도구
- 프리뷰 확인하며 코드 수정 → 바로 복사
- 그라디언트, 패턴, 레이어 조합을 GUI로 생성
