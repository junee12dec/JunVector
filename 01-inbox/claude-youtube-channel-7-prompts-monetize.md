# Claude로 AI 유튜브 채널 운영하는 프롬프트 7종 — 90일 수익화 로드맵

## 1. 니치 & 포지셔닝

```
상위 CPM·낮은 경쟁·강한 에버그린 수요를 가진 유튜브 니치 10개를 분석해줘.
각 니치마다: 평균 CPM, 콘텐츠 난이도, AdSense 외 수익화 경로, 채널 컨셉 3단어 요약을 알려줘.
```

## 2. 채널 아이덴티티

```
[NICHE] 주제로 유튜브 채널을 시작하려 해. 채널 전체 아이덴티티를 만들어줘:
채널 이름 5개 옵션, 태그라인, 타깃 청중 페르소나, 콘텐츠 필러 4개,
그리고 기존 크리에이터와 나를 차별화하는 '고유 메커니즘'.
```

## 3. 90일 콘텐츠 로드맵

```
[NICHE] 신규 채널을 위한 90일 유튜브 콘텐츠 캘린더를 만들어줘.
검색 최적화된 영상 제목 12개, 업로드 스케줄,
SEO용 vs. 바이럴용 영상 우선순위, 시간이 지날수록 권위가 쌓이는 콘텐츠 진행 방식을 포함해줘.
```

## 4. 영상 스크립트 시스템

```
'[VIDEO TITLE]' 유튜브 영상의 전체 스크립트를 써줘.
구성: 훅(스크롤을 멈추게 하는 첫 30초), 문제 자극, 솔루션 설명, 핵심 인사이트 3가지,
CTA, 다음 영상을 예고하는 엔드스크린 멘트.
```

## 5. SEO & 썸네일 전략

```
'[TITLE]' 영상에 대해 다음을 제공해줘:
텍스트 오버레이가 포함된 썸네일 컨셉 3개, 60자 이하 SEO 최적화 제목,
타임스탬프·키워드·링크가 담긴 설명란, 태그 10개.
썸네일 A/B 테스트 변형안도 제안해줘.
```

## 6. 수익화 스택

```
[NICHE] 유튜브 채널, 구독자 [X]명이야. AdSense 이외의 전체 수익화 로드맵을 만들어줘:
제휴 마케팅 기회, 디지털 상품 아이디어, 스폰서십 제안 템플릿,
이메일 리스트 구축을 위한 리드 마그넷.
```

## 7. 성장 & 콘텐츠 재활용 엔진

```
이 유튜브 영상 스크립트/트랜스크립트를 다음 형태로 재활용해줘:
트위터/X 스레드, 링크드인 포스트, 유튜브 쇼츠 훅 3개, 이메일 뉴스레터, 핀터레스트 설명.
또한 내 니치를 기준으로 어떤 플랫폼을 우선할지 추천해줘.
```
