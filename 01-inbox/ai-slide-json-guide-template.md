# AI 슬라이드 JSON 가이드 코드 — 회사 PPT 양식을 한 번만 세팅하면 끝

## 핵심 문제

AI로 슬라이드를 만들면 색상·폰트·레이아웃이 매번 미세하게 달라진다. 원인은 단순하다. AI가 회사 템플릿의 정확한 디자인 규칙을 모르기 때문이다.

**해결법: JSON 슬라이드 가이드 코드**

회사 PPT 템플릿의 HEX 코드, 폰트, 여백, 레이아웃 규칙을 JSON으로 구조화한 파일 하나면 된다. AI는 이 파일을 읽고 규칙대로 슬라이드를 생성한다.

---

## 4단계 워크플로

### 1단계 — JSON 가이드 코드 생성

회사 PPT 템플릿을 NotebookLM에 올리고 프롬프트를 입력한다:

> "이 PPT 템플릿의 디자인 규칙을 JSON 슬라이드 가이드 코드로 만들어줘."

**핵심**: "JSON 형태로"라고 명시해야 한다. 그냥 "분석해줘"라고 하면 텍스트 설명만 나온다.

출력 결과에는 다음이 포함된다:
- 색상 팔레트 (HEX 코드)
- 폰트 규칙
- 슬라이드 유형별 레이아웃

### 2단계 — JSON 검증 및 저장

실제 템플릿과 대조해서 검증하고, 틀린 부분을 수정한다. 완성된 JSON을 NotebookLM에서 **메모 저장 → 소스 변환**으로 등록한다. 소스 이름을 `+슬라이드 가이드 코드`로 바꿔두면 이후 참조가 편하다.

### 3단계 — AI 도구에 JSON 적용

| 도구 | 적용 방법 |
|------|-----------|
| NotebookLM | JSON을 소스로 등록 |
| Gemini 캔버스 | 프롬프트에 JSON 직접 붙여넣기 |
| Jamspark | 프롬프트에 JSON 삽입 |

### 4단계 — 반복 생성

세팅 이후에는 3~4단계만 반복한다. 주간 보고, 월간 리뷰, 프로젝트 발표 모두 10분 안에 완성.

## 고급 팁

- **부서별 JSON 분리**: 마케팅팀용, 개발팀용, 경영지원팀용 가이드를 따로 만들어 부서 특화 슬라이드 자동 생성
- **슬라이드 유형별 구성 포함**: 표지, 데이터 슬라이드, 마무리 등 유형별 레이아웃을 JSON에 정의하면 AI가 자동으로 적절한 레이아웃을 선택
- **NotebookLM 목차 소스 워크플로와 결합**: 구성(목차)과 디자인(JSON)을 동시에 통제 가능
