## 저장소 설명이 보태는 것 (GitHub 설명 기준)

- **Remocn**: Remotion용 애니메이션·전환·배경·장면 모음. 글이 말한 "브라우저에서 영상"은 Remotion(React로 영상 제작) 위에 얹힌 구성이다.
- **Awesome Motion Design**: GSAP, Motion, Remotion, Lottie, Rive를 다루는 큐레이션. 웹 애니메이션, 프로그램 영상, 모션 품질 검증용. Claude Code·Codex·Copilot에 설치할 수 있다.
- **Spotkit**: 기능 설명을 주면 **하나의 디자인 시스템에 속하는** 최소·추상 SVG 제품 일러스트로 바꾼다.
- **Better Design**: 아트 디렉션, DESIGN.md, 디자인 토큰, 모션, 접근성, 실제 화면 검증까지 다룬다. Codex·Claude Code·Cursor용.
- **extract-design-system**: 공개 웹사이트에서 색·타이포·간격·모서리·그림자를 뽑아 JSON과 CSS 변수로 만든다.
- **Logo Design**: 원칙·과정·SVG 작업법·테스트 도구와 1,400개 이상 로고 레퍼런스 라이브러리.
- **PPT Agent**: 스타일 26종, 차트 18종. 한 문장으로 덱을 만들고 Linear·Anthropic·Stripe·Apple·NYT를 기준으로 벤치마크했다고 소개한다.

## 참고

- 별 수가 많은 것은 Logo Design과 make-interfaces-feel-better이고 나머지는 수백 개 이하다. 작은 저장소는 아직 검증이 덜 된 것으로 보고 설치 전에 SKILL.md를 읽어 보는 편이 안전하다 (내 판단).
- 각 저장소의 SKILL.md는 열어 보지 않았다. 설명은 글과 GitHub 설명문 기준이다.
