# 학습도 AI화 — Gemini로 Claude 마스터 가이드북 빠르게 파악하기

> 이제 학습도 AI화 하자. 이제 그럴 때 됐잖아...

## 핵심 아이디어

클로드 마스터 가이드북이 나왔는데, 이걸 직접 한땀한땀 읽는 대신:

1. **Gemini 켜기**
2. **가이드북 PDF 업로드**
3. **"그래서 뭐부터 시작하면 됨?"** 질문 → AI가 요약·안내

→ AI로 학습 자체를 가속화하는 메타 접근법

- Gemini의 긴 컨텍스트 윈도우를 활용해 PDF 전체를 한 번에 처리
- 단순 요약 대신 "내 상황에서 뭐가 제일 유용한가?" 식으로 질문하면 효과적
- NotebookLM에 올려서 인터랙티브하게 탐구하는 것도 동일한 전략
