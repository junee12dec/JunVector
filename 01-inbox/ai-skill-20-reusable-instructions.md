# AI 스킬 20개 — 반복 지시를 파일 하나로 끝내는 법

## 핵심 개념

반복하는 지시를 `.md` 파일 하나에 정리해두면, AI가 매번 그걸 읽고 따르는 구조.

- **Claude**: `.claude/skills/` 폴더에 넣으면 자동 인식
- **ChatGPT**: Custom Instructions 또는 대화 시작 시 붙여넣기
- **Gemini**: 프롬프트에 포함

> AI를 잘 쓰는 사람과 못 쓰는 사람의 차이는 프롬프트 실력이 아니라, 반복되는 좋은 지시를 **재사용 가능한 시스템으로 만들었느냐**의 차이다.

## 글쓰기·콘텐츠 스킬 (5개)

| 스킬 | 역할 |
|------|------|
| **SCQA 글쓰기 프레임워크** | 상황→문제→질문→답변 구조로 논리적 스토리텔링. 스레드·아티클·보고서 전용 |
| **콘텐츠 재가공 엔진** | 블로그 글 1개 → 소셜 스레드·숏폼 스크립트·요약본으로 변환 |
| **톤·스타일 유지 스킬** | 브랜드 톤 또는 개인 문체 가이드 준수. 여러 글 사이 톤 일관성 유지 |
| **긴 글 요약 압축기** | 핵심 포인트 추출, 중복 제거, 문단/불릿 출력 |
| **구조화 카피라이팅 스킬** | 강한 훅 → 섹션별 본론 → CTA 구조로 마케팅·소셜 카피 생성 |
