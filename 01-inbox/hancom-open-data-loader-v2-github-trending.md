# 한컴 open-data-loader v2.0 — GitHub 트렌딩 1위

## 한눈에 보기

- **제작사:** 한글과컴퓨터 (한컴)
- **출시 후 일주일:** 7,000+ GitHub 스타, 전체 트렌딩 1위
- **핵심 기능:** PDF를 AI가 읽을 수 있는 데이터로 변환
- **라이선스:** Apache 2.0 (상업적 사용 무료)
- **GitHub:** [hancomio/open-data-loader](https://github.com/hancomio/open-data-loader)

## 특징

동종 오픈소스 대비 **전 항목 최고 정확도**를 기록한 PDF 구조화 데이터 추출 도구. 한국 기업이 만든 오픈소스가 GitHub 글로벌 트렌딩 1위를 기록한 사례로 주목받음.
