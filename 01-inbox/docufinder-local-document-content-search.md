# Docufinder v2.5.0 — 파일 내용으로 PC 문서 전체를 검색하는 로컬 도구

**GitHub**: http://github.com/chrisryugj/Docufinder  
**릴리즈**: http://github.com/chrisryugj/Docufinder/releases/tag/v2.5.0

---

## 핵심 기능

파일명을 몰라도, 열어보지 않아도 **내용으로** 찾아준다.

## 지원 포맷

- HWP(X) — 한글 문서
- 워드 (.docx)
- PDF
- 엑셀 (.xlsx)
- 스캔 이미지 (OCR)

## v2.5.0 주요 변경사항

| 기능 | 내용 |
|------|------|
| OneDrive 차단 | 클라우드 파일 자동 다운로드 사고 방지 |
| 네트워크 공유 폴더 | 정식 지원 추가 |
| 오프라인 OCR | 회사망·오프라인에서 첫 실행부터 OCR 작동 (번들 포함) |

→ 회사 PC에 설치해도 이제 실사용 가능.
