# Higgsfield AI 영상 프롬프트 구조 공개

커뮤니티: https://higgsfield.ai/community

## 핵심 인사이트

> **"퀄리티 차이는 모델이 아니라 프롬프트 구조에서 나온다"**

Higgsfield가 실제 런칭 영상 제작에 사용한 프롬프트·레퍼런스 파일·설정값을 전부 무료로 공개.

## 고퀄리티 영상 프롬프트 구조 (seedance 2.0 실제 사례)

| 요소 | 내용 |
|------|------|
| **스타일 락** | 35mm 필름, ARRI ALEXA 룩, 필름 그레인 지정 |
| **카메라** | Paul Greengrass 스타일 핸드헬드, 돌리·크레인 금지 |
| **캐릭터 고정** | 얼굴·헤어·의상·소품까지 일관성 유지 |
| **사운드** | 현장음 + 립싱크 대사 명시 |
| **샷별 연출** | 샷1 와이드 → 샷2 입 클로즈업, 스냅 컷 순서 지정 |
| **네거티브** | 워터마크, 립싱크 밀림, 왜곡 명시적 차단 |

## 활용 방법

1. https://higgsfield.ai/community 에서 원하는 영상 프롬프트 선택
2. 레퍼런스 파일·설정값 그대로 복사
3. 브랜드 영상에 적용
