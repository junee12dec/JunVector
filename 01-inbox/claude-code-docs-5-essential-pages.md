# Claude Code 공식 문서, 이 5쪽만 저장해 두기

@gpt_park (Threads, 2026-11-20): "클로드 코드 문서, 처음부터 다 읽을 필요 없다. 이 5쪽만 저장해 두면 막힐 때 바로 찾는다."
각 페이지의 목차는 글에 첨부된 문서 화면 캡처 5장에서 옮겼다.

| # | 페이지 | 언제 보나 | 링크 |
|---|--------|-----------|------|
| 1 | 빠른 시작 (Quickstart) | 설치부터 첫 질문, 첫 수정까지 | https://code.claude.com/docs/en/quickstart |
| 2 | 모범 사례 (Best practices) | 구체적으로 시키기, 지침 파일은 짧게 | https://code.claude.com/docs/en/best-practices |
| 3 | 대화 모드 (Interactive mode) | 단축키, 여러 줄 입력, 작업 중 다음 지시 넣기 | https://code.claude.com/docs/en/interactive-mode |
| 4 | 비용 관리 (Costs) | `/usage`로 사용량 보기, 토큰 줄이기 | https://code.claude.com/docs/en/costs |
| 5 | 문제 해결 (Troubleshooting) | CPU·메모리 과다, 멈춤, 터미널 글자 깨짐 | https://code.claude.com/docs/en/troubleshooting |

작성자 팁: 영어라면 브라우저 번역을 켜 둔다. 토큰이 빨리 닳거나 노트북이 버거우면 4·5번부터 본다.

## 페이지별 목차 (캡처 기준)

**1. 빠른 시작** — 터미널에 설치하고 로그인해, 코드베이스를 탐색하고 첫 수정을 한다.
- 준비물: 터미널, 작업할 코드 프로젝트, Claude 구독(Pro·Max·Ultra·Team·Enterprise) 또는 Claude Console 계정이나 지원 클라우드 제공자
- 7단계: 설치 → 첫 세션 시작 → 첫 질문 → 첫 코드 수정 → Git과 함께 쓰기 → 버그 수정·기능 추가 → 다른 흔한 작업 해 보기
- 그 밖에: 필수 명령(셸 명령, 세션 명령), 초보자 팁

**2. 모범 사례** — "Claude가 볼 수 없는 것을 알려 주고, 돌릴 검사를 주고, 예외 없는 규칙은 강제하라."
- 기본값으로 이미 되는 것: 새 세션은 auto mode로 시작해 명령마다 승인하지 않아도 되고, 독립 작업은 서브에이전트에 맡기며, 긴 대화는 컨텍스트가 차기 전에 자동으로 압축된다.
- Claude가 못 보는 것 알려 주기: 구체적인 프롬프트, 먼저 Claude와 브레인스토밍, CLAUDE.md는 짧게, 규칙은 코드베이스 일부에만 범위 지정, 팀 절차는 스킬로, 필요한 도구 연결
- 돌릴 검사 주기: 명세와 대조해 리뷰, Stop 훅으로 검사 강제
- 예외 없는 규칙 강제: 훅으로 단계 강제, 권한 규칙과 샌드박스로 접근 제한, 규칙의 적용 대상 정하기
- 기본값 바꾸기: 권한 모드, 모델과 effort, 서브에이전트 비용, 비용·컨텍스트 줄이기
- 세션 조종하기, Claude를 혼자 돌리기 (스크립트로 실행)

**3. 대화 모드** — 단축키, 입력 모드, 대화형 기능의 전체 참고서.
- 단축키: 일반 조작, 텍스트 편집, 테마·표시, 여러 줄 입력, 빠른 명령, 대화 기록 보기, 음성 입력
- 예: `Ctrl+C` — 실행 중이면 중단, 아무것도 안 돌고 있으면 첫 번째는 입력 지우기, 두 번째는 종료
- macOS: Option/Alt 단축키(`Alt+B`, `Alt+F` 등)는 터미널에서 Option을 Meta로 설정해야 동작
- 명령, Vim 편집 모드, 명령 기록(`Ctrl+R` 역검색, 지운 초안 되살리기), 백그라운드 Bash 명령(`!` 접두어 셸 모드), **Claude가 일하는 동안 메시지 대기열에 넣기**

**4. 비용 관리** — 토큰 사용량 추적, 팀 지출 한도, 컨텍스트 관리·모델 선택·extended thinking 설정·전처리 훅으로 비용 줄이기.
- 기업 배포 평균: 활동일 하루 개발자당 약 $13, 월 개발자당 $150~250, 사용자 90%는 하루 $30 미만
- 비용 추적: `/usage` 명령(프롬프트 캐시 통계, 플랜 사용량 내역, 추천 적용 단축키), 스피너 옆 토큰 수 읽기, 사용 패턴 분석
- 조직 비용 관리: 팀·엔터프라이즈, Console, 클라우드 제공자, 에이전트 팀 토큰 비용
- 토큰 줄이기: 컨텍스트를 미리 관리, 맞는 모델 고르기, MCP 서버 부담 줄이기, 코드 인텔리전스 플러그인 설치

**5. 문제 해결** — Claude Code가 돌아가는 중의 성능·안정성·검색 문제.
- 높은 CPU·메모리, 터미널에서 큰 표가 잘림, 자동 압축이 반복 오류로 멈춤, 명령이 멈추거나 얼어붙음, 에디터 내장 터미널에서 글자 깨짐, 클립보드·SSH 복사 문제, 검색이 느리거나 결과가 빠짐(WSL)
- 설치·로그인 문제(`command not found`, PATH, `EACCES`, TLS 오류, 로그인 반복, `403 Forbidden`)는 "설치·로그인 문제 해결" 페이지로, 설정·훅·MCP가 안 먹으면 "설정 디버그" 페이지로 안내

## 참고

- 문서 페이지는 직접 열지 않았다. 목차는 첨부 캡처에 보이는 부분까지만 옮겼다.
