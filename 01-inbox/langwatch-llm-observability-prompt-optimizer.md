# LangWatch — LLM 사용량 분석 및 프롬프트 최적화 오픈소스 플랫폼

GitHub: [langwatch/langwatch](https://github.com/langwatch/langwatch) ⭐ 3.4k

## 개요

LangWatch는 개발자가 LLM 사용을 분석하고 프롬프트를 최적화할 수 있는 **오픈소스 LLMOps 플랫폼**이다.

## 주요 기능

- **LLM 사용량 분석** — 비용·토큰·레이턴시 등 프로덕션 지표 추적
- **프롬프트 최적화** — 실제 사용 데이터 기반으로 프롬프트 개선
- **관측 가능성(Observability)** — LLM 호출 로그·트레이스 시각화
- **오픈소스** — 자체 호스팅 가능, 데이터 외부 유출 없음

## 활용 시점

- LLM 앱을 프로덕션에 배포한 후 품질·비용을 모니터링할 때
- 프롬프트를 데이터 기반으로 체계적으로 개선하고 싶을 때
- LangChain, OpenAI SDK 등과 연동해 트레이싱을 추가할 때
