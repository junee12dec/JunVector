# ego-lite — AI 에이전트용 경량 브라우저 자동화

GitHub: [citrolabs/ego-lite](https://github.com/citrolabs/ego-lite)  
GitHub 트렌딩 1위 기록

## 핵심 특징

- **속도**: 기존 Playwright 스타일 대비 훨씬 빠름
- **인증 세션**: 로그인해 두면 인증 상태 그대로 브라우저 테스트 가능
- **안정성**: 최신 업데이트로 더 빠르고 안정적

## 추천 맥락

> "대충 쓰다가 추천하는 게 아니고, 진짜 AI 에이전트에 물려서 사용 중 — 정말 좋다."
