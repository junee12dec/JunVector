# Claude Code에 레퍼런스 사이트 링크 던지고 웹 모션 구현하기

## 핵심 워크플로우

```
레퍼런스 사이트 URL → Claude Code → "이 사이트 느낌으로 구현해줘"
→ 결과 확인 → 분위기·방향 피드백 → 반복
```

## 기존 방식 vs 이 방식

| 기존 | 이 방식 |
|------|---------|
| 타이밍·속도·이징값 하나씩 수동 조정 | 레퍼런스 URL 한 줄 입력 |
| 수치부터 시작 | 분위기·방향부터 시작 |
| 노가다 반복 | AI랑 결과 보며 수정 |

## 사용할 수 있는 레퍼런스 사이트 예시

- **Anime.js** — JavaScript 애니메이션 라이브러리 공식 사이트
- **Motion (구 Framer Motion)** — React 모션 라이브러리 공식 사이트
- 원하는 모션 느낌이 있는 실제 웹사이트도 가능

## 핵심 인사이트

> 수치를 먼저 정하는 게 아니라, 원하는 **분위기와 방향**을 먼저 정한다.

세부 값(타이밍, 이징, 딜레이)은 AI가 레퍼런스를 분석해서 잡아준다. 사람은 "더 빠르게", "더 부드럽게" 같은 방향만 피드백하면 됨.
