# AITMPL — Claude Code 컴포넌트 대규모 오픈소스 모음

> Claude Code를 쓴다면 워크플로우에 스테로이드를 맞은 것 같은 경험을 하게 될 것.

## 포함 컴포넌트 카테고리

| 종류 | 설명 |
|------|------|
| **Skills** | 에이전트가 자동으로 발견하는 워크플로우 정의 |
| **Agents** | 커스텀 에이전트 설정 |
| **Commands** | 슬래시 명령어 |
| **Hooks** | 이벤트 트리거 자동화 |
| **MCPs** | MCP 서버 통합 |
| **Plugins** | JS/TS 플러그인 |
| **Loops** | 반복 실행 루프 |
| **Settings** | 설정 파일 템플릿 |

## 특징

- 카테고리별로 깔끔하게 정리된 구조
- Claude Code 사용자라면 바로 가져다 쓸 수 있는 실용적 모음
- AI 개발자 생산성 향상에 직접적으로 기여하는 컴포넌트들
