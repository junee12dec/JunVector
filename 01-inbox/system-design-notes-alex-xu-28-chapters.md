# System Design Notes — Alex Xu 책 챕터별 무료 정리 노트 (28개 시스템)

## 한 줄 요약

Alex Xu의 System Design Interview 1·2권 전체를 챕터별로 GitHub에 공개한 노트. FAANG 면접에서 나오는 28개 시스템 설계를 무료로 학습.

---

## 다루는 시스템 (28챕터)

### 기초
- 수백만 사용자로 스케일링하는 방법
- 백오브엔벨로프 추정

### 핵심 서비스 설계
- URL 단축기, 웹 크롤러, 채팅 시스템, 뉴스피드, 검색 자동완성

### 대형 플랫폼
- YouTube, Google Drive, Google Maps
- 주변 친구(Nearby Friends), 근접 서비스(Proximity Service)

### 인프라 & 데이터
- 분산 메시지 큐, 메트릭 모니터링, 광고 클릭 집계

### 금융 & 커머스
- 결제 시스템, 디지털 지갑, 주식 거래소
- S3 유사 오브젝트 스토리지, 호텔 예약

### 기타
- 실시간 게임 리더보드, 분산 이메일
- 속도 제한기(Rate Limiter), 일관 해싱, 키-값 저장소, 유일 ID 생성기

---

## 구성

각 챕터에 포함된 것:
- **설계 프레임워크** — 단계별 접근법
- **트레이드오프** — 기술 선택의 장단점
- **다이어그램** — 시스템 구조도
- **원본 논문 링크** — Amazon Dynamo, Google BigTable, Discord Elixir 스케일링, Netflix 영상 인코딩, Slack 엣지 캐싱 등 실제 엔지니어링 레퍼런스

---

## 왜 유용한가

유료 강의에서 가르치는 수준의 시스템 설계 준비 자료.
각 챕터 말미에 실제 빅테크 엔지니어링 블로그·논문이 연결되어 있어
개념 이해에서 심화 학습까지 이어진다.
