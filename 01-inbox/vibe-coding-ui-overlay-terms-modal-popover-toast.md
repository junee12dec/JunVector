# 바이브 코딩 화면 용어 6개

@hi.claude0 (Threads, 2026-11-18, cc. gabriell_lab). 카드 이미지의 출처 표기: shadcn/ui 컴포넌트 문서.

> 같은 "팝업"도 이름이 다 다르다. 이 여섯 개만 알면 원하는 창을 정확히 시킬 수 있다.

| 이름 | 영어 | 무엇인가 | 예 |
|------|------|----------|-----|
| 모달 | Modal | 화면 위에 뜨는 창. 뒤 화면은 누를 수 없다 | "삭제할까요?" 확인 창 |
| 팝오버 | Popover | 버튼을 누르면 바로 옆에 붙어 뜨는 작은 창 | |
| 툴팁 | Tooltip | 마우스를 올리면 나오는 짧은 설명 | |
| 토스트 | Toast | 잠깐 떴다 사라지는 알림 | "저장됐어요" |
| 시트 | Sheet | 화면 옆에서 밀려 나오는 패널 | |
| 드로어 | Drawer | 모바일에서 아래에서 끌어올리는 서랍 | |

## 쓰는 법

Claude Code 채팅에 이 이름을 그대로 쓴다.

```text
저장 누르면 토스트로 알려줘
```

이름으로 말하면 엉뚱한 창이 덜 나온다.
