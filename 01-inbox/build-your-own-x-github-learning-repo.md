# Build Your Own X — 직접 만들며 배우는 개발 학습 오픈소스 모음

GitHub: [codecrafters-io/build-your-own-x](https://github.com/codecrafters-io/build-your-own-x)

## 핵심 개념

단순히 라이브러리 **사용법**을 배우는 것이 아니라, **직접 구현**하면서 내부 원리를 이해하는 방식.

> "직접 만들어보는 경험이 라이브러리 사용법보다 훨씬 큰 실력을 만든다"

## 다룰 수 있는 주제

| 분야 | 예시 |
|------|------|
| AI | LLM, RAG |
| 시스템 | 운영체제(OS), 데이터베이스, Git, Docker |
| 네트워크 | 웹 브라우저, 웹 서버, 검색 엔진, BitTorrent |
| 언어·그래픽 | 프로그래밍 언어, 블록체인, 게임 엔진, 3D 렌더러 |

수십 가지 주제를 **C, C++, Rust, Go, Python, JavaScript** 등 다양한 언어의 단계별 튜토리얼로 제공한다.

## 학습 대상

- 개발자로 성장하고 싶은 사람
- CS 기초·원리를 실습으로 다지고 싶은 사람
- 기술 면접 대비로 내부 구현을 이해하고 싶은 사람
