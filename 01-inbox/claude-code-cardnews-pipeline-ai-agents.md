# AI 에이전트 파이프라인으로 카드뉴스 자동 생성하기

명령어 한 줄로 카드뉴스 10장을 생성한 사례.

```
카드뉴스 만들어줘: Claude Code 슬래시 명령어 총정리
```

---

## 파이프라인 개념

회사 업무 흐름과 동일한 구조다:

```
기획팀 → 카피팀 → 디자인팀 → 검수팀 → 발행 (탈락 시 수정)
```

각 팀 자리에 AI 에이전트를 배치하고, 앞 단계 결과를 다음 단계 입력으로 연결한다.

---

## 파이프라인 구성 파일 3종

| 파일 | 역할 |
|------|------|
| **역할 파일** | 에이전트의 업무 매뉴얼. "너는 카피라이터다. 제목은 20자 이내로 써라." |
| **규칙 파일** | 모든 에이전트가 지킬 품질 기준표. 글자 크기, 여백, 배경색 등 |
| **스킬 파일** | 실행 순서를 정하는 작업 지시서. "1번이 끝나면 2번, 2번이 끝나면 3번." |

예시 구성: 역할 파일 5개 + 규칙 파일 3개 + 스킬 파일 1개 = 텍스트 파일 총 9개.

---

## 역할 파일 예시

**카피라이터 에이전트:**
- 이름: 카피라이터
- 도구: 읽기, 쓰기
- 규칙:
  - 제목 20자 이내, 본문 90자 이내
  - 한 슬라이드에 메시지 하나만
  - 앞에서 만든 기획 문서를 읽고 작성
  - 결과를 카피 문서로 저장

**디자이너:** 여백 고정, 글자 크기 최소값 지정, 빈 공간 없이 꽉 채워라

**검수자:** 글자 크기 기준 미달이면 탈락. 하단이 비면 탈락.

핵심: **"너는 누구고, 뭘 하고, 어떤 규칙을 지켜라."** — 이걸 역할마다 하나씩 만들면 팀원 완성.

---

## 스킬 파일 구조 (실행 순서)

1. 기획자 실행 → 기획 문서 저장
2. 카피라이터가 기획 문서 읽고 → 카피 문서 저장
3. 디자이너가 기획 + 카피 읽고 → 디자인 생성
4. 검수자가 전체 확인 → 탈락 시 해당 에이전트로 돌아가 자동 수정 (최대 n회)
5. 캡션 작성
6. 디자인을 이미지 파일로 변환

> **핵심: "앞 단계 결과 = 다음 단계 입력"**
> 기획 위에 카피가 쌓이고, 카피 위에 디자인이 쌓인다.

---

## Claude Code로 파이프라인 자동 생성

파일을 직접 작성할 필요 없다. Claude Code에 이렇게 지시하면 된다:

```
카드뉴스 파이프라인을 만들어줘.
기획 → 카피 → 디자인 → 검수 4단계.

기획자는 웹 검색으로 데이터 수집하고 구조 설계,
카피라이터는 제목 20자 본문 90자 이내로 작성,
디자이너는 인스타 정사각형 사이즈로 제작,
검수자는 기준 미달이면 돌려보내 자동 수정.

명령어 하나로 실행되게 만들어줘.
```

→ 역할 파일, 규칙 파일, 스킬 파일 전부 자동 생성.

---

## 파이프라인 개선 루프

파이프라인은 만들고 나서 반복 개선이 핵심이다. Claude Code에게 말로 수정 지시하면 된다:

- `"카드뉴스 글자가 너무 작아. 카피라이터 규칙에 '제목 15자 이내, 줄당 8자' 추가해줘."`
- `"배경색이 슬라이드마다 달라서 산만해. 디자이너 규칙에 '본문은 밝은 배경 통일' 추가해줘."`
- `"검수를 너무 쉽게 통과시켜. 검수자에 '하단 20%가 비면 탈락' 기준 추가해줘."`
- `"스토리 흐름이 없어. 기획자에 '커버에서 호기심 → 본문에서 전개 → 마지막에 정리' 원칙 추가해줘."`

**돌려보고 → 부족한 점 찾고 → 규칙 추가 지시 → 다시 돌려보고.**
이 반복이 70점을 100점으로 만든다.
