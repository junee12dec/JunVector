# 9개 에이전트로 일상 99% 자동화 — 멀티 에이전트 설계 원칙

AI 스타트업 ChatPRD의 **클레어 보**가 공개한 OpenClaw 활용기.
단순 AI 도구 사용을 넘어 **9개 에이전트로 일상을 99% 자동화**.

## 핵심 설계 원칙

**한 명에게 모든 걸 시키지 않는다.**

각 에이전트에 명확한 페르소나와 역할을 분리:
- **Sam** — 영업 담당
- **Finn** — 가정 관리
- **Howie** — 팟캐스트 보조

→ 에이전트를 잘 다루는 능력 = 사람을 잘 관리하는 매니징 역량

## 실용 팁

- **실행 환경**: 메인 컴퓨터 대신 맥미니 같은 별도 기기나 클라우드에서 실행
- **Soul 파일**: 강력한 가이드라인을 넣어 보안과 권한을 단계적으로 관리

## 시사점

1인 개발자에게 멀티 에이전트는 진짜 레버리지.
실행 시간보다 **자동화 설계 시간**에 더 투자하는 것이 장기적으로 유리.
