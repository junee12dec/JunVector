# prompts.chat — 오픈소스 Prompt Library

웹사이트: [prompts.chat](https://prompts.chat)  
GitHub: [f/prompts.chat](https://github.com/f/prompts.chat)

## 특징

- 전 세계 사용자들이 공유한 프롬프트 모음
- **검색** — 원하는 유형의 프롬프트 빠르게 찾기
- **복사** — 바로 사용 가능한 형태로 복사
- **직접 추가** — 커뮤니티에 내 프롬프트 기여 가능
- 오픈소스 — 누구나 참여·수정 가능

## 언제 유용한가

- X(Twitter)나 Reddit에서 프롬프트를 하나씩 찾아 저장하는 대신
- 역할·페르소나·태스크 유형별로 검증된 프롬프트를 한 곳에서 탐색할 때
