# AI slop을 없애는 UI 라이브러리 5곳

@marcelodesignxh (Threads, 2026-11-18)의 "AI slop을 없애는 라이브러리 5곳". 글에는 이름과 주소만 있고 각 사이트의 설명은 없다.

1. **HorizonX** — https://horizonx.so
2. **Grainient** — https://grainient.supply
3. **Arc UI** — https://uiarc.dev
4. **uberdesigner** — https://uberdesigner.ai
5. **Bencho** — https://bencho.dev

## 첨부 영상 첫 화면

어느 사이트의 화면인지는 표시돼 있지 않다. 다크 배경의 컴포넌트 갤러리로, 이름이 붙은 카드들이 격자로 놓여 있다.

- 영화 티켓 (Neon Harbor, 07 IMAX — "점선을 따라 당겨 찢기", "모서리를 넘겨 예고편 보기")
- Thermostat (원형 다이얼로 24℃ 조절, Cool·Auto·Heat)
- SleepTracker (수면 단계 그래프)
- PlasmaOrb (빛나는 구체)
- AssistantPill ("Ask anything..." 입력 알약)
- RevenueChart ($48,215, 요일별 막대)
- ActivityRings, RiseTooltip, WindCompass, ON/OFF 토글

## 참고

- 다섯 사이트 모두 저장할 때 네트워크 정책에 막혀 읽지 못했다. 각 사이트가 무엇을 제공하는지(컴포넌트, 그라데이션, 프롬프트 등)와 가격·라이선스는 확인하지 않았다.
- 영상 내용은 첫 화면 외에는 읽지 못했다.
