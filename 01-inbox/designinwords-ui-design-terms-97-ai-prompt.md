# DesignInWords — UI 디자인 용어로 AI에게 정확히 요청하기

- 사이트: https://tuilders.com/apps/designinwords (로그인 없이 사용)
- 만든 사람: 욱동스 — 틸더스(tuilders)에서 그 주 1위 앱
- 소개 글: @cubric007 (Threads, 2026-11-20)

## 무엇을 하나

AI로 웹앱이나 발표 슬라이드를 만들 때 "좀 답답해 보여요", "예쁘게 해 줘" 대신 **딱 맞는 용어로** 요청하게 돕는다.

- **용어 97개를 적용 전후로 비교**해서 볼 수 있다.
- **말로 검색**: "글씨가 잘 안 읽혀요"처럼 증상을 쓰면 어울리는 용어와 그 이유를 찾아 준다.
- **프롬프트 조립**: 블록을 조립하면 AI에게 바로 붙여넣을 **한국어 프롬프트 문장**을 만들어 준다.
