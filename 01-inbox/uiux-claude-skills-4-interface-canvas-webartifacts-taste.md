# UI/UX 엔지니어를 위한 Claude 스킬 4선

---

## 스킬 목록

### 🎨 interface-design
**GitHub**: https://github.com/Dammyjay93/interface-design

대시보드, 어드민 패널, SaaS 앱 등 **엔터프라이즈 UI** 전용 디자인 엔지니어링 스킬.

- Jony Ive 수준의 정밀함을 목표
- 디자인 원칙을 기억하고 컴포넌트 간 일관성을 강제

---

### 🖼️ canvas-design _(Anthropic 공식)_
**GitHub**: https://github.com/anthropics/skills/blob/main/skills/canvas-design/SKILL.md

**PNG/PDF 형식**의 시각적 그래픽을 직접 생성하는 Anthropic 공식 스킬.

- 코드 결과물이 아닌 **인쇄/출판용** 결과물 제작에 활용

---

### 🌐 web-artifacts-builder _(Anthropic 공식)_
**GitHub**: https://github.com/anthropics/skills/blob/main/skills/web-artifacts-builder/SKILL.md

**React + Tailwind CSS + shadcn/ui**를 활용해 복잡한 Claude HTML 아티팩트를 빌드하는 Anthropic 공식 스킬.

- 상태 관리, 라우팅이 필요한 인터랙티브 아티팩트를 **단일 파일**로 패키징

---

### ✨ taste-skill
**GitHub**: https://github.com/Leonxlnx/taste-skill

AI가 생성하는 **뻔한 UI를 방지**하는 고수준 프론트엔드 스킬.

- 3가지 다이얼로 디자인 수준을 세밀하게 조정
- Claude Code, Cursor, Codex 등 주요 AI 코딩 에이전트 지원
