# 옛날 사진 복원·컬러화 프롬프트

인물 얼굴·의상 원본을 100% 유지하면서 해상도 향상 + 컬러화.  
AI 이미지 편집 시 얼굴이 바뀌는 문제를 막는 핵심 제약 조건 포함.

---

## 프롬프트 전문

업로드된 사진은 원본을 절대 변경하지 않는다. 특히 인물의 얼굴(이목구비, 윤곽, 피부 질감, 표정)과 의상(디자인, 색상, 주름, 로고 등)은 완전히 고정된 불변 영역으로 간주하여 어떠한 형태로도 수정, 보정, 재해석, 스타일 변경을 하지 않는다.

이미지는 초고해상도로 업스케일링하며 전체적인 선명도와 디테일만 향상시킨다. 노이즈, 흐림, 입자, 흠집, 압축 아티팩트를 제거하되, 인물의 얼굴과 의상에는 영향을 주지 않는다.

자연스러운 질감을 유지하면서 배경 및 비인물 영역의 디테일을 개선하고, 바랜 색상과 노출을 균형 있게 보정한다. 선명도와 대비를 향상시키되 과도한 HDR 효과나 인공적인 느낌은 배제한다.

손상되거나 누락된 디테일은 배경 및 비핵심 영역에서만 복구하며, 인물의 정체성과 원본 특징은 100% 유지한다.

원본유지 하고, 컬러만 변경한다.

## 핵심 원칙 요약

| 영역 | 처리 방식 |
|------|-----------|
| 인물 얼굴·의상 | 절대 불변 — 수정·보정·재해석 전부 금지 |
| 전체 해상도 | 초고해상도 업스케일링 |
| 노이즈·흠집·아티팩트 | 제거 (얼굴·의상 제외) |
| 배경·비인물 영역 | 디테일 개선, 손상 복구 가능 |
| 색상 | 바랜 색 보정 + 흑백→컬러화 |
| 분위기 | 자연스러운 질감 유지, 과도한 HDR 금지 |
