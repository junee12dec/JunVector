## 활용 팁: Claude Code를 학원 선생님처럼

VSCode에 Claude Code 익스텐션을 붙이면 혼자 공부할 때 완전히 다른 경험이 된다:

- **환경 설정**: Claude Code가 자동으로 세팅
- **한국어 번역**: 영어 수업 자료를 한글로 번역해서 이해
- **실습 지원**: 실습 진행 중 즉시 질문·답변
- **쉬운 설명**: IT 용어가 어려울 때 "쉽게 설명해줘" 한 마디면 충분
- **에러 해결**: 오류 화면 긁어서 붙여넣으면 바로 해결

> "설명은 일타강사보다 더 잘하네요"

## 커리큘럼 철학

> "84%의 학생이 AI 도구를 이미 사용하지만, 전문적으로 활용할 준비가 됐다고 느끼는 비율은 18%뿐이다."

각 레슨의 루프:
```
문제 읽기 → 수학 유도 → 코드 작성 → 테스트 실행 → 산출물 보존
```

핵심 원칙: **프레임워크 사용(Use It) 전에 직접 구현(Build It)을 먼저.**

---

## 20단계 진행 흐름

```
수학 기초
  → 고전 ML
  → 딥러닝
  → 특화 도메인 (비전·NLP·오디오)
  → 트랜스포머
  → LLM
  → 프로덕션 시스템
  → 멀티 에이전트 스웜
  → 윤리·안전
```
