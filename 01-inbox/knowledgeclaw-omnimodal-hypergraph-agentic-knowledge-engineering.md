# KnowledgeClaw — 여러 형식의 지식 베이스를 하이퍼그래프로 엮어 계속 최신으로 유지하는 에이전트

- 논문: *KnowledgeClaw: Towards Agentic Knowledge Engineering via Omnimodal Hypergraphs* (arXiv 2611.24294, 2026-11-18)
- 저자: Haoran Luo, Jiapu Wang, Linhao Luo, Luu Anh Tuan
- 코드·데이터: https://github.com/LHRLAB/KnowledgeClaw
- 소개 글: @ax_central (Threads, 2026-11-20) — "사내 지식 베이스는 한 번 만들고 끝나지 않는다. 문서·이미지·영상이 섞이고, 계속 바뀌고, 질문마다 필요한 깊이도 다르다."

## 풀려는 문제

지식 엔지니어링(KE)은 원본 파일을 추론에 쓸 수 있는 지식 베이스로 바꾸는 일이고, 이제 LLM 에이전트가 할 수 있는 범위에 들어왔다. 발전 흐름은 청크·그래프 RAG → 메모리 에이전트 → 에이전트형 KE → 멀티모달 KE.

그런데 **살아 있는 지식 베이스**에는 세 가지가 동시에 필요하다.
1. **전체 모달리티(omnimodality)**: 문서·이미지·영상 등 여러 형식
2. **닫힌 고리의 생애주기**: 원본이 바뀌면 지식도 계속 갱신
3. **여러 단위의 활용**: 질문마다 필요한 깊이(세부 사실 ↔ 큰 그림)가 다름

기존 시스템은 많아야 둘을 갖추고, 셋을 함께 재는 벤치마크도 없었다.

## 기여

- **OmniKE 정의**와 **OmniKE-Bench** 공개: 과제 6개, 모델 없이 채점하는 문항 1,829개, 다섯 가지 형식의 실제 파일 3,960개.
- **KnowledgeClaw** 제안:
  - 여러 형식을 담는 **타입이 있는 하이퍼그래프**를 만든다 (선 하나가 셋 이상의 대상을 한꺼번에 잇는 그래프)
  - **생애주기 에이전트**가 닫힌 고리로 계속 최신 상태를 유지한다
  - 질문마다 **필요한 단위로 라우팅**한다

## 결과

- 비교 방식 30개와 견줘 **과제 6개 모두 1위**
- 종합 점수(OKE) 55.9, 가장 강한 비교 방식보다 **+14.6**
- 벤치마크는 연구진이 직접 만든 것이다.
