# NotebookLM 생산성 10배 올리는 크롬 확장 프로그램 6가지

| 확장 프로그램 | 기능 |
|---|---|
| **NotebookLM Tools** | 소스를 50개까지 한 번에 추가 |
| **Kortex** | ChatGPT 대화를 원클릭으로 저장 |
| **Web Importer** | 웹페이지를 클릭 한 번으로 소스에 추가 |
| **Mindmap Extractor** | 마인드맵을 XMind에서 직접 편집 가능 |
| **YouTube to NotebookLM** | 유튜브 채널을 통째로 분석 |
| **Ultra Exporter** | PDF, CSV, PPT로 내보내기 |

## 언제 유용한가

소스를 하나씩 복붙하거나, 마인드맵을 이미지로만 저장하고 있다면 이 확장 프로그램들을 활용하면 된다.
