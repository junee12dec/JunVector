# 한국 도시 미니멀 라인아트 여행 포스터 프롬프트

지역명만 바꾸면 어느 도시든 세련된 프리미엄 여행 포스터 완성.  
관광 엽서 아님 — 실제 일상 거리를 담은 스위스 모더니스트 스타일.

---

## 색상 조합 예시 (지역별 자동 선택)

| 지역 | 잉크 색상 | 배경 색상 |
|------|-----------|-----------|
| 부산 | 딥 네이비 | 웜 샌드 |
| 전주 | 다크 브라운 | 한지 아이보리 |
| 서울 | 차콜 블랙 | 소프트 웜그레이 |
| 제주 | 딥 그린 | 라이트 크림 |

---

## 프롬프트 전문

**[지역명]** = 원하는 도시명으로 교체 (예: 부산, BUSAN)

[지역명]을 위한 미니멀한 초고해상도 여행 포스터를 라인 아트 스타일로 제작하세요. 관광 엽서가 아닌 세련된 일상 도시 장면으로 도시를 묘사하세요.

**주요 구성:**

중앙 구성은 [지역명]의 가장 상징적인 일상 거리 장면, 교차로, 골목길, 부모와 같이 걷는 아이들, 또는 횡단보도를 특징으로 합니다.

전경에는 현지 주민, 통근자, 자전거 이용자, 여행자, 쇼핑객, 학생, 카페 방문자가 포함됩니다.

지역을 대표하는 이미지의 캐릭터가 오른쪽 하단에 자연스럽게 포함되어야 합니다.

사람들은 [지역명] 거리 패션, 현지 생활 방식, 현대 도시 문화를 자연스럽게 반영해야 합니다.

배경은 실제 [지역 언어] 간판, 카페, 디저트 가게, 편의점, 교통 표지판, 상점 전면, 자판기, 건축 디테일로 채워집니다.

랜드마크는 구성 전체를 지배하기보다 일상 생활 속에 자연스럽고 은은하게 녹아들어야 합니다.

실제 [지역 언어] 타이포그래피와 문화적으로 인식 가능한 시각 요소를 사용하세요.

상단 중앙에 큰 제목: "[지역명 영문명]"  
하단에 한국어 부제목: "[지역명 한글명]"

**스타일:**
- 초정밀 벡터 일러스트레이션
- 스위스 모더니스트 여행 포스터 미학
- 미니멀 라인 아트 / 모노라인 드로잉
- 미드센추리 에디토리얼 일러스트레이션 스타일
- 건축 일러스트레이션 / 한국 그래픽 포스터 디자인
- 선명한 기하학적 원근법 / 극도로 깨끗한 네거티브 스페이스

**라인 스타일:**
- 단색 라인 일러스트레이션만
- 얇고 고도로 정밀한 선 / 최소한의 채우기 영역
- 복잡한 도시 지도 수준의 디테일
- 간판, 건물, 창문, 케이블, 거리 오브젝트의 리드미컬한 배열
- 시각적으로 밀도 있지만 매우 정돈된 구성

**컬러 시스템 — 매우 중요:**
- 하나의 주요 잉크 색상 + 하나의 배경 색상만 사용
- [지역명]의 분위기를 가장 잘 나타내는 색상 조합을 자동 선택
- 단색 실크스크린 포스터 미학 / 무지개 팔레트 금지 / 과도한 네온 금지

**구성:**
- 세로 포스터 레이아웃
- 정면 거리 수준 원근법
- 보행자들이 자연스럽게 거리를 이동하는 장면
- 균형 잡힌 도시 리듬과 시각적 흐름

**텍스트 품질 — 극도로 중요:**
- 모든 타이포그래피는 깨끗하고 읽기 쉽고 전문적
- 무작위 기호·깨진 글자 금지 / 간판은 실제처럼 자연스럽게

**출력:**
- 세로 포스터 / 초상세 8K 해상도 / 인쇄 준비 완료

Avoid dominant franchise branding. Prioritize independent cafés, local bakeries, bookstores, and understated storefront typography.
