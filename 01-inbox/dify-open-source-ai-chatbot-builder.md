# Dify — 코드 없이 사업용 AI 챗봇 만드는 오픈소스 (140k⭐)

## 한 줄 요약

개발자 없이 드래그&드롭으로 AI 챗봇·워크플로우를 만드는 오픈소스 플랫폼. GitHub 스타 140k.

---

## 핵심 기능

| 기능 | 설명 |
|------|------|
| **비주얼 워크플로우** | 캔버스에서 블록을 끌어다 붙여 AI 흐름 구성 |
| **RAG 파이프라인** | PDF, PPT 등 내 문서를 올리면 그 내용으로 답변 |
| **에이전트** | 함수 호출·ReAct 기반, 50개+ 내장 도구 |
| **프롬프트 IDE** | 모델 성능 비교, 텍스트-음성 변환 |
| **LLMOps** | 앱 로그·성능 모니터링 |
| **백엔드 API** | REST API로 외부 서비스 연동 |

---

## 지원 LLM

GPT-4, Claude, Mistral, Meta Llama, 기타 OpenAI API 호환 모델 수백 개.

---

## 사용 사례

- **상담봇**: 내 FAQs·제품 문서로 자동 답변
- **예약봇**: 예약 흐름을 워크플로우로 구성
- **1인 기업 자동화**: 반복 업무를 AI 에이전트로 처리
- **사내 지식베이스 챗봇**: 사내 문서 업로드 → 직원 Q&A 봇

---

## 설치

```bash
# Docker Compose로 빠른 시작
docker compose up -d
# 이후 http://localhost/install 접속
```

**최소 사양**: CPU 2코어, RAM 4GB

### 세 가지 버전

| 버전 | 특징 |
|------|------|
| **Dify Cloud** | 즉시 사용, 유료 |
| **커뮤니티 에디션** | 셀프호스팅, 무료 |
| **엔터프라이즈** | 대규모 조직용, 커스텀 |

---

## 왜 주목받나

코딩 없이 RAG + 에이전트 + 워크플로우를 한 플랫폼에서 구성할 수 있다.
1인 기업·소상공인이 ChatGPT API를 직접 붙이는 대신 Dify로 시작하면 UI·관리·로깅까지 한 번에 해결.
