# dashi-ppt-skill — AI가 짜고 브라우저에서 직접 고치는 발표자료 도구

GitHub 별: 5,879

## 기존 AI 발표자료 도구의 문제

AI가 만든 슬라이드는 보기엔 그럴듯하지만, 한 줄 고치려고 열어보면 손댈 데가 없어 결국 처음부터 다시 만들게 됨.

## dashi-ppt-skill의 차이점

문서를 AI 에이전트에 던지면 슬라이드를 짜주는데, **페이지마다 편집 콘솔이 같이 붙어서** 나온다.

- 브라우저에서 마음에 안 드는 부분 직접 수정
- 진짜로 편집이 되는 **PPTX 파일로 내보내기** 가능

## 설치 및 사용

```bash
npx dashi-ppt-skill@latest
```

- 설치와 업데이트가 같은 명령 — 다시 실행하면 그 자리에서 최신으로 올라감
- 기존에 깔린 의존성은 그대로 유지
- 설치 후 에이전트가 테마 미리보기를 띄워 선택하게 해줌
- 중간에 테마를 통째로 바꿔달라고 요청해도 됨

## 전제 조건

- **Node.js 20 이상** + npm
- PPTX·PDF 내보내기: 로컬에 Chrome 또는 Edge 필요
- AI 코딩 도구(Claude Code 등)에 붙여 쓰는 도구 — 웹 챗봇 전용으로는 해당 없음
