# DeepTutor — 문서를 맞춤형 인터랙티브 학습 코스로 변환하는 오픈소스

## 개요

수백 페이지짜리 논문이나 매뉴얼을 직접 읽지 않아도 된다. 문서를 던져주면 AI가 알아서 **맞춤형 인터랙티브 학습 코스**로 만들어주는 오픈소스 툴 **DeepTutor**가 나왔다.

단순한 텍스트 요약이 아니다. 여러 AI 에이전트가 협업해서 학습 플랜을 짜고, **다이어그램과 퀴즈가 포함된 웹페이지**를 직접 생성한다.

## 주요 기능

- **RAG + 지식 그래프 기반** 답변 출처 제공
- **단계별 진도**에 맞춘 실시간 Q&A 기능
- **OpenAI, DeepSeek 등 API 호환** (100% 오픈소스)
- 멀티 에이전트 협업으로 학습 플랜 자동 설계
- 다이어그램·퀴즈 포함 웹페이지 생성

## 활용 시나리오

- 방대한 연구 논문을 빠르게 습득할 때
- 기술 매뉴얼·API 문서를 팀원에게 교육할 때
- 개인 학습 커리큘럼을 자동화하고 싶을 때
