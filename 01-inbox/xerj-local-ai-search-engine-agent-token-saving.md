# xerj — 단일 바이너리 AI 로컬 검색 엔진

GitHub 별: 5,556

## 핵심 가치

폴더 하나를 가리키면 코드·문서·로그·PDF까지 자동 색인 → **코딩 에이전트가 파일 하나하나 읽으며 토큰을 낭비하는 문제 해결**.

| 효과 | 수치 |
|------|------|
| 에이전트 출력 토큰 절감 | 2.7배 (실제 사례) |
| 최대 절감 보고 | 5배 |

## 설치 및 시작

```bash
# 서버 실행
xerj --insecure --data-dir ./data &

# 프로젝트 색인 (한 번만)
xerj autoindex ~/내-프로젝트
```

## 특징

- **단일 바이너리** — JVM 없음, 별도 의존성 없음
- **플랫폼**: 리눅스·맥·윈도우 (x86/arm64) 미리 빌드 제공
- **기본 임베더**: 오프라인 동작 → 인터넷 없는 환경도 지원
- **의미 검색(신경망 모드)**: 모델 파일 3개를 로컬에 준비해야 함

## 활용 시나리오

- 사내 코드베이스·문서를 에이전트가 효율적으로 탐색
- 인터넷이 차단된 내부망 환경에서 로컬 RAG 구성
- [[opencode-setup-MOC|사내 OpenCode 셋업]]의 Layer 2(knowledge-brain)에 연결 가능
