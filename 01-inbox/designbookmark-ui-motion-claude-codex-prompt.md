# DesignBookmark — 고른 UI 디자인을 Claude·Codex용 프롬프트로 복사해 주는 사이트

> AI로 만든 웹사이트 디자인이 마음에 들지 않는다면 참고할 만한 사이트.
> — @choi.openai (Threads, 2026-11-15)

## 무엇인가

- 버튼, 카드, 입력창, 메뉴 등 다양한 UI 디자인을 모아 놓은 사이트
- 마음에 드는 디자인을 고르면 그 디자인을 구현하는 **프롬프트를 복사**할 수 있다
- 복사한 프롬프트를 Codex나 Claude에 붙여넣으면 된다
- 디자인을 미리 확인할 수 있고, 프롬프트를 고쳐 원하는 스타일로 바꿀 수 있다

## Motion 페이지 (글에 첨부된 영상 첫 화면 기준)

- 소개 문구: "Animated components, running live. Copy one for Claude or Codex, paste it into your project, and it builds it for you."
- 필터: All · Buttons · Inputs · Navigation · Cards · AI · Text · Saved
- 카드마다 `Claude`, `Codex`, `Copy code` 버튼이 있다
- 보이는 예시: Plan switch(월간·연간 요금 전환), Letter limit(글자 수 제한 입력창), Pull cord(당기는 줄 조명 토글)
- 왼쪽 메뉴에 Motion 외에도 Design, AI, Skills, Development, No-Code & Web 등의 카테고리와 Mac·Windows 앱, Chrome 확장 목록이 있다
