# Appllama Skills — 상위 매출 앱 UI 패턴 기반 모바일 개발 에이전트 스킬

GitHub: [Appllama/appllama-skills](https://github.com/Appllama/appllama-skills)

## 왜 AI가 만든 모바일 앱은 어색한가

AI 에이전트에게 "예쁜 모바일 앱 만들어줘"라고 해도 결과가 어색한 이유:  
**잘 팔리는 앱이 왜 그렇게 설계됐는지**를 에이전트가 모르기 때문.

## Appllama Skills의 접근

상위 매출 앱의 실제 설계 지식을 Skill로 주입.

### 처리 흐름

```
상위 매출 앱 화면·플로우·UI 패턴 조사
→ 디자인 언어 추출
→ Expo·React Native 화면 구현
→ 네비게이션·모션·네이티브 컨트롤 점검
→ 실제 시뮬레이터에서 전체 플로우 검증
```

## 주요 특징

- 시장 검증된 UI 패턴 기반으로 구현
- 정적 화면이 아닌 **실제 앱 수준의 네비게이션·모션** 포함
- 시뮬레이터 검증까지 자동화

## 지원 코딩 에이전트

Claude Code, Cursor, Codex
