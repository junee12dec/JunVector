# 랜딩페이지 몰입감을 높이는 3D 리소스 4가지

피피팀 비비(@bibibi.designer)가 소개한, 랜딩페이지나 작업물의 몰입감을 확 더해주는 3D 리소스 모음.

---

## 1. 3dassets.one

🔗 https://3dassets.one

- 무료 3D 텍스처 및 에셋을 한 곳에서 탐색
- 라이선스 필터로 오픈소스 자료도 바로 확인 가능

---

## 2. Aleto (Figma 플러그인)

🔗 https://figma.com/community/plugin/1543188922868813589

- 피그마 안에서 2D 레이어를 AI로 3D 변환하는 플러그인
- 별도 3D 툴 없이 피그마에서 바로 작업 가능

---

## 3. Badge Generator

🔗 https://workbench.suna.design/apps/badge

- 로고나 SVG 파일을 3D 메탈 뱃지로 변환
- 소재, 색상, 질감 등 커스텀 및 내보내기 가능 (PNG, HTML 등)

---

## 4. AI Particle Simulator

🔗 https://workbench.suna.design/apps/badge

- 도형 혹은 이미지를 바탕으로 3D 입자 시스템 자동 생성
- React 또는 Three.js 코드로 바로 내보내기 가능
