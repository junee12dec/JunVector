# Koboyo — 손그림 스타일 무한 캔버스 다이어그램 도구

사이트: [koboyo.com](https://koboyo.com)  
아이콘 라이선스: [koboyo.com/icons/license](https://koboyo.com/icons/license)

## 개요

텍스트·도형·화살표·표·차트를 자유롭게 배치해 손으로 그린 듯한 다이어그램과 프레젠테이션을 만드는 무한 캔버스 도구. 결과물은 PNG와 SVG로 저장.

## 핵심 기능

### 무한 캔버스
- 텍스트, 도형, 화살표, 표, 차트 자유 배치
- 손그림(hand-drawn) 스타일 렌더링
- PNG·SVG 내보내기

### 손그림 SVG 아이콘 9만 개+
- AI·비즈니스·교육·인물·인포그래픽 등 다양한 카테고리
- **무료 제공** — 상업적 이용 가능, 출처 표기 불필요
- 라이선스 세부 사항: [koboyo.com/icons/license](https://koboyo.com/icons/license)

### MCP 연동
Claude Code, Cursor, Codex와 MCP로 연결해 AI가 자동으로 필요한 아이콘을 검색·삽입 가능.

## 활용 시나리오

- 강의 자료·슬라이드 제작
- 업무 흐름도·아키텍처 다이어그램
- SNS 도해·인포그래픽
- AI 에이전트가 자동으로 아이콘을 찾아 다이어그램 완성
