# Icon Explorer — 무한 캔버스로 탐색하는 아이콘 브라우저

**GitHub**: https://github.com/BroKarim/icon  
**웹사이트**: https://icons.brokarim.com  
**기반**: icones 포크 — 표시 방식을 무한 캔버스로 교체

> "아이콘을 탐색하는데 무한 캔버스처럼 사방으로 스크롤할 수 있게 만든 사이드 프로젝트"

---

## 핵심 특징

**무한 캔버스 탐색**: 일반 리스트가 아닌 2D 공간을 자유롭게 이동하며 아이콘 탐색  
**Iconify 200,000개+** 아이콘 전체 지원

---

## 기능

| 기능 | 설명 |
|------|------|
| **무한 캔버스** | 상하좌우 자유 스크롤, 2D 공간 탐색 |
| **전역 검색** | 퍼지 매칭 기반 빠른 검색 |
| **크기 조정** | 32–128px 범위 슬라이더 |
| **컬러 피커** | 아이콘 색상 실시간 변경 |
| **다운로드** | SVG, PNG, Vue, React 컴포넌트 형식 |
| **PWA 지원** | 오프라인 설치 가능 |
| **다크 모드** | 라이트/다크 전환 |
| **키보드 단축키** | 빠른 조작 지원 |

---

## 기술 스택

Vue 56% / TypeScript 39% / CSS 4%  
Vite + UnoCSS + shadcn
