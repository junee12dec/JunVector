# DSPy — 프롬프트 자동 최적화 스탠포드 프레임워크

GitHub: [stanfordnlp/dspy](https://github.com/stanfordnlp/dspy)  
출처: Stanford NLP

## 핵심 개념

> '프롬프팅'이 아니라 **'프로그래밍'**

LLM 호출을 파이썬 코드로 모듈화한 뒤, 알고리즘이 최적의 프롬프트를 자동으로 찾아낸다.

## 무엇을 자동화하는가

| 기존 방식 | DSPy 방식 |
|-----------|-----------|
| 프롬프트 문구를 사람이 수동 수정 | 데이터셋 입력 → 알고리즘이 자동 탐색 |
| Few-shot 예시를 수작업으로 선별 | 알고리즘이 최적 예시 자동 생성 |
| RAG·에이전트 프롬프트 반복 튜닝 | 파이프라인 코드만 정의 → 자동 최적화 |

## 주요 활용

- **RAG 파이프라인** 프롬프트 최적화
- **AI 에이전트** 지시문 자동 정밀 조율
- LLM 체인 성능을 데이터 기반으로 개선

## 한 줄 요약

데이터셋만 주면 알고리즘이 최고 성능의 프롬프트를 작성해준다. 수작업 프롬프트 노가다에서 벗어나는 가장 구조적인 방법.
