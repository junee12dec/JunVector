# COREVIS Library — AI를 위한 디자인 자료실

사이트: [lib.corevisos.com](http://lib.corevisos.com)

## 수록 자료

도트 게임 이펙트 · UI 부품 · 모션그래픽 · 아이콘 · 3D — **1,273점** (계속 증가 중)

---

## 6가지 특징

### 1. 토큰이 덜 든다

AI용 목차 `llms.txt` 제공 — 선반 14개, 개수, 주소가 **약 8천 자 한 장**.  
AI가 인터넷을 뒤지지 않고 목차 한 장 보고 바로 해당 선반으로 이동.

### 2. 대충 말해도 알아듣는다

전문 용어 몰라도 됨. "확 다가오는 카메라"라고만 해도 달리 인·푸시 인·줌 인·크래시 줌을 찾아 줌.  
카메라 기법 62개는 같은 장면을 카메라만 바꿔 촬영해서 차이가 바로 보임.

### 3. MCP로 붙이면 코드째 가져온다

구독 후 MCP 연결 → "로그인 화면에 쓸 토글 찾아 줘"만 해도 소스코드째 가져옴.  
(화면에서 직접 받는 건 가입 없이 무료)

### 4. 설치 없이, 선택한 디자인 코드만 받는다

오픈소스 통째 설치 없이, **고른 디자인 하나의 코드만** 다운로드.  
코어비스 팀이 직접 작성·검수한 코드, 각 자료마다 참고 출처와 라이선스 명시.

### 5. 받기 편하다

가입 없음 → 자료 열기 → 사람 확인 → 받기 버튼.  
**React / HTML / CSS**로 제공, 색만 바꿔서 바로 붙이기 가능.

### 6. 계속 늘어난다

코어비스 팀이 직접 큐레이션해서 지속 추가 중.
