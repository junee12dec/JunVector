# Claude Code로 마케팅 에이전트 팀 구축하기 — 4단계 실전 파이프라인

> "AI한테 '카드뉴스 5장 만들어줘' 한 마디면 브랜드 맞춤 콘텐츠가 자동 완성"

---

## 1단계 — 환경 설정 & 브랜드 맥락 주입

Cursor 또는 VS Code에 Claude Code 확장 설치 후 폴더 구조 세팅:

```
📁 Context/   → 브랜드 가이드, 디자인 스타일, 사업 소개
📁 Template/  → 카드뉴스, 뉴스레터, PPT 레퍼런스
```

- 핀터레스트에서 원하는 레이아웃 미리 저장
- 유튜브·웹사이트 스크린샷 → MD 파일로 정리해서 AI에 브랜드 학습

## 2단계 — 시스템 표준화 (CLAUDE.md = 프로젝트 SOP)

`CLAUDE.md` 파일 하나가 전체 프로젝트의 SOP(업무 규약).  
AI가 에이전트로서 어떻게 움직일지 여기서 정의.

- 앤트로픽 공식 스킬 설치 → 정해진 서식에 맞는 결과물 자동 생성
- 공식 스킬 레포: http://github.com/anthropics/skills

## 3단계 — 에이전트 팀 구성 & 기술 연동

Google AI Studio MCP 연결로 이미지 생성 기능 탑재.

| 에이전트 | 역할 |
|---------|------|
| 리서치 에이전트 | 주제 조사, 자료 수집 |
| 콘텐츠 제작 에이전트 | 글·카피 작성 |
| 디자인 에이전트 | 시각 자료 생성 |
| 검수 에이전트 | 품질 검토, 브랜드 일관성 확인 |

## 4단계 — 자동 생성 & 배포

```
"ATM 비즈니스 소개 카드뉴스 5장 만들어줘"
```

→ 리서치 → 콘텐츠 → 디자인 → 검수 파이프라인 자동 실행 → 결과물 출력

---

## 핵심 인사이트

> "실제 실행 시간보다 브랜드 가이드라인과 규칙 세팅, 즉 **하네스(Harness) 세팅에 95%의 시간을 쏟아야** 결과물 퀄리티가 달라진다."

AI는 준비된 만큼만 잘한다.
