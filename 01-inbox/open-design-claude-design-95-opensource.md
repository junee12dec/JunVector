# Open Design — Claude Design 95% 재현 오픈소스

**GitHub**: https://github.com/nexu-io/open-design

---

## 개요

Claude Design의 설계 철학·템플릿을 **95% 이상의 완성도**로 재현한 오픈소스.  
72시간, 18,700줄 이상의 코드로 제작 — Claude Code를 위한 순수 디자인 구현체.

## 핵심 기능

| 항목 | 내용 |
|------|------|
| **디자인 스킬** | 30+ 개 — 트위터에서 검증된 정교한 템플릿 |
| **브랜드 시스템** | 71+ 개 브랜드 디자인 시스템 |
| **호환성** | 모든 Code Agent 지원 |
| **스케치 모드** | 지원 |
| **무료** | 오픈소스, 누구나 Claude 수준 디자인 품질 활용 가능 |

## 포지셔닝

Huashu Design(Claude Design 역설계)과 같은 카테고리지만 더 큰 규모:
- 30+ 스킬 템플릿
- 71+ 브랜드 시스템 (awesome-design-md의 69개와 비슷한 수준)
- 스케치 모드 추가
