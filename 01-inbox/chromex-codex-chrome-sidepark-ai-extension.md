# Chromex — Codex 기반 Chrome 사이드패널 AI 어시스턴트

**GitHub**: https://github.com/GENEXIS-AI/chromex  
100% 오픈소스. Gemini in Chrome처럼 Codex를 크롬 사이드패널에서 사용.

---

## 핵심 기능

| 기능 | 설명 |
|------|------|
| **이미지 프롬프트 추출** | 클릭 한 번으로 이미지 생성 프롬프트 획득 |
| **웹페이지 요약** | YouTube·뉴스·PDF·논문 등 현재 탭 내용 요약 |
| **인포그래픽·PPT** | 웹 내용 기반 슬라이드·인포그래픽 생성 |
| **음성 모드** | 음성 전사 + 실시간 음성 대화 |
| **브라우저 제어** | 워크플로우 자동화 |
| **다중 탭 참조** | "@" 선택기로 여러 탭 동시 참조 |
| **검색 이력 기반 질문** | 내 브라우저 맥락을 활용한 AI 질의 |

---

## 설치 방법

1. GitHub 최신 릴리스에서 `chromex-unpacked-extension.zip` 다운로드
2. 압축 해제
3. `chrome://extensions` 열기
4. 개발자 모드 활성화
5. "압축 해제된 확장 프로그램 로드" → 폴더 선택

---

## 주요 특징

- **MV3 사이드 패널** — 탭 전환 없이 항상 열려 있는 AI 사이드바
- **`/` 선택기** — 프로필(역할) 전환
- **`@` 선택기** — 여러 탭 선택해서 컨텍스트로 주입
- **파일 지원** — PDF, DOCX, 이미지 등 다양한 포맷
- **로컬 이력** — 선택적으로 채팅 기록 로컬 저장
- **마크다운 렌더링** — 응답 결과를 깔끔하게 표시
