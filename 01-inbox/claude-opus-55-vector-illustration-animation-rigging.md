# Claude Opus 5.5로 정지된 일러스트를 캐릭터 애니메이션으로

## 핵심 기능

**정지된 벡터 일러스트 → 움직이는 캐릭터 애니메이션**

캐릭터 관절 꺾기(리깅)를 에프터이펙트 없이도 Claude가 처리.

## 동작 방식

| 복잡도 | 처리 방식 |
|--------|-----------|
| 간단한 움직임 | 에프터이펙트 없이 Claude 단독 처리 |
| 복잡한 리깅 | Claude가 에프터이펙트를 직접 열어서 작업 |

## 지원 입력 포맷

벡터 방식 파일:
- `.ai` (Adobe Illustrator)
- `.eps`
- `.svg`

## 소스 찾는 곳

- **Magnific** — 벡터 일러스트 소스가 많음
- [[skillry-opus-55-viral-videos-389-prompts|skillry.dev/ai-videos]] — Opus 5.5 창작 사례 모음과 함께 참고

## 활용 포인트

- AI 크리에이터가 에프터이펙트를 몰라도 캐릭터 애니메이션 제작 가능
- 기존 일러스트 자산을 움직이는 콘텐츠로 재활용
- 쇼트폼 영상·소셜 콘텐츠용 캐릭터 모션 빠르게 제작
