# Y2K 다마고치 픽셀 변환 프롬프트 — GPT Image 2

사진 → 90년대 다마고치 액정 화면 8비트 픽셀 스타일로 변환.  
인물·상황 유지하면서 레트로 감성 픽셀 이미지 생성.

---

## 버전 1 — 레트로 UI 풀버전

> 이미지를 90년대 Y2K 다마고치 액정 화면 스타일로 바꿔줘. 원본의 인물과 상황은 유지하되, 귀엽고 하찮은 8비트 픽셀 캐릭터와 배경으로 단순화해 재해석해줘. 밝고 사랑스러운 파스텔 LCD 팔레트(크림, 핑크, 민트, 라벤더 중심), 도트 매트릭스 질감, 큼직한 픽셀, 4색 제한, 평면적인 액정 표현으로 만들어줘. 배터리 아이콘, 상태창, 메뉴 아이콘, 하트, 레벨, 날짜/시간, 짧은 픽셀 텍스트 같은 레트로 UI를 함께 넣고, 다마고치 기기 본체나 버튼, 베젤, 프레임은 보이지 않게 해줘. 오직 액정 화면 내부만 꽉 차게 보이도록, 노스탤지어 강하고 사랑스러운 다마고치 픽셀 화면처럼 만들어줘.

**특징**: 레트로 UI 요소 풍부 (배터리·상태창·하트·레벨·날짜), 4색 팔레트, 파스텔 LCD

---

## 버전 2 — 말풍선 + 원본 색상 간소화 버전

> 첨부한 이미지를 90년대 Y2K 다마고치 액정 화면 스타일로 바꿔줘.
> 
> - 원본 인물과 상황은 유지
> - 귀엽고 하찮은 8비트 픽셀 캐릭터와 배경으로 단순화
> - 색상은 원본과 비슷하되, 파스텔 톤으로
> - 도트 매트릭스 질감, 큼직한 픽셀, 평면적인 액정 표현
> - 다마고치 기기 본체, 버튼, 베젤, 프레임은 제외
> - 픽셀 말풍선을 넣고, 그 안에 텍스트를 넣기
> - 텍스트는 [텍스트]

**특징**: UI 요소 제거, 원본 색감 유지 (파스텔 보정), 픽셀 말풍선으로 텍스트 삽입 가능
