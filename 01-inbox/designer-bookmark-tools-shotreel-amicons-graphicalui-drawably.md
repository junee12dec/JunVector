# 디자이너 북마크 도구 — shotreel·amicons·graphicalui·drawably

@maengle.lab (Threads, 2026-11-18)이 "직접 다 들어가서 확인하고 쓸 만한 것만 추린" 디자인 도구 7개 중, 볼트에 없던 4개.

| 도구 | 하는 일 | 가격 |
|------|---------|------|
| **shotreel** — https://shotreel.app | 스크린샷을 넣으면 루프 영상으로 바꿔 준다. 템플릿 70개 | 720p 무료, 워터마크 없음 |
| **amicons** — https://amicons.design | 아이콘 760개 × 스타일 4종 | 300개는 무료로 바로 받아 씀 |
| **graphicalui** — https://graphicalui.com | 색·글꼴·간격·모션까지 디자인 시스템 테마를 만들어 준다. 코딩 에이전트에게 바로 넘길 수 있다 | 유료 |
| **drawably** — https://drawably.dev | 펜으로 그린 느낌의 UI 컴포넌트. 버튼, 체크박스, 입력창 전부 손그림 느낌 | 글에 표기 없음 |

나머지 3개는 볼트에 이미 있다:
- appllama (앱스토어 상위 앱 1,500개 화면을 화면 단위로 보기) → [[appllama-skills-mobile-ui-pattern-agent]]
- prompt-motion (Claude로 만든 모션 영상 모음, 프롬프트 공개) → [[claude-motion-skills-10-hyperframes-reference]]
- designbookmark (디자인 도구 2,500개 이상, 매주 업데이트) → [[designbookmark-ui-motion-claude-codex-prompt]]
