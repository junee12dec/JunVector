# GitDiagram — GitHub 레포지토리 아키텍처 다이어그램 자동 변환

## 사용법

GitHub URL 주소창에서 `github`을 `gitdiagram`으로만 바꾸면 된다.

```
https://github.com/user/repo
→
https://gitdiagram.com/user/repo
```

복잡한 프로젝트 구조가 즉시 아키텍처 다이어그램으로 변환된다.

## 주요 기능

- **인터랙티브 다이어그램**: 특정 요소를 클릭하면 해당 소스 파일로 바로 이동
- **내보내기**: Mermaid 코드 또는 PNG 파일로 저장 가능
- **Private 레포 지원**: 토큰 연결 시 Private 레포지토리도 지원
- **오픈소스**: 100% 오픈소스, 직접 셀프호스팅 가능

## 기술 스택

- GPT-4.1 mini 기반으로 작동

## 활용 시나리오
