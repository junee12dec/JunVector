# n8n — 블록을 이어 AI 에이전트와 자동화 흐름을 만드는 도구

- 저장소: https://github.com/n8n-io/n8n
- 소개 글: @sinbaktem.lab (Threads, 2026-11-20) — 출처로 GitHub README(11/20 확인)를 밝힘

## 핵심

- 화면에서 **블록을 이어** AI 에이전트와 자동화 흐름을 만든다.
- 연동 1,500개 이상, 템플릿 9,000개 이상 (README 기준).
- 내 컴퓨터에 직접 깔아도 되고 클라우드로 돌려도 된다.
- OpenAI·Anthropic·구글·오픈소스 모델을 바꿔 끼울 수 있다.
- 규모: 별 211,506개 (글 작성 시점, 하루 새 별 315개).

**맞는 사람**: 반복 업무를 자동 흐름으로 묶고 싶은 사람.
